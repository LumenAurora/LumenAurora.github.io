# 研究方法论总览

> 研究方法论这 12 篇原本平铺在侧边栏，读者不知从哪进。本页把它们分成论文写作 / 评测与审稿 / 方向与地图三条线，并标出阅读顺序，与顶部「研究品味」五篇构成同一主题的两种切面——研究品味教你怎么「选得好、写得有趣」，方法论教你怎么「做得扎实、经得起审」。

## 一、这份导读在做什么

"研究方法论"这 12 篇，原本平铺在侧边栏里，读者不知道从哪进。本页把它们分成三条线——**论文写作 / 评测与审稿 / 方向与地图**——并标出阅读顺序。它们和「研究品味」五篇（见顶部导航）是同一主题的两种切面：研究品味教你怎么"选得好、写得有趣"，方法论教你怎么"做得扎实、经得起审"。

## 二、三条线怎么读

### 线 A · 论文写作（想发顶会先读这些）

- [Benchmark 论文写作](./benchmark-writing)：从心理测量学借一套方法论，适合做 benchmark 方向的人。
- [方法类论文的 Idea 生成](./idea-generation)：故事线框架，把"idea 从哪来"系统化。
- [AI 算法设计的底层逻辑](./algorithm-design)：从生物启发到数学分析的底层逻辑。
- [方法类文章的实验观](./method-paper)：方法类论文的实验该做到什么程度才算合格。
- [如何框定研究问题](./problem-scoping)：把模糊的好奇心收成可研究的问题。

> 顺序建议：先 `problem-scoping` 定问题 → `idea-generation` 定故事 → `method-paper` 定实验标准 → 动手写时参考 `benchmark-writing` / `algorithm-design`。

### 线 B · 评测与审稿（投稿前后必读）

- [可靠性 Benchmark 研究](./reliability-benchmark)：可靠性评测的方法论与坑。
- [审稿维度的系统梳理](./review-dimensions)：ICLR / ICML / NeurIPS 官方审稿维度 + 实证揭示的隐藏标准。

> 这两篇配合「研究品味 / 顶会分析论文做对了什么」一起读，能建立"审稿人怎么挑刺"的完整心智模型。

### 线 C · 方向与地图（迷茫时读这些）

- [研究方向地图](./research-directions-map)：不动预训练还能做什么——一份穷举式方向地图。
- [推理时优化方法分类体系](./training-free-inference-taxonomy)：推理时即插即用优化的完整分类法。
- [本科生如何开启科研](./starting-research)：给低年级学生的实操路线。
- [辨别真研究与跟风](./real-research-vs-padding)：区分"真问题"和"跟风式工作"。

## 三、和研究品味五篇的关系

顶部导航的「研究品味」是这套方法论的"道"：什么是有趣的研究、顶会范本拆解、如何自上而下产生课题、大模型时代的识别问题、分析类论文句法骨架。建议路线：

1. 先读研究品味 `什么是「有趣」的研究` → `顶会分析论文做对了什么`；
2. 回到本页线 C 定方向、线 A 写故事；
3. 投稿前读线 B 自检。

## 四、如果你只想挑一篇

- 不知道做什么方向 → `research-directions-map` + `辨别真研究与跟风`。
- 有 idea 但不会写成论文 → `method-paper` + `idea-generation`。
- 准备投稿 / 审稿 → `review-dimensions` + 研究品味 `审稿维度`（若有）。
