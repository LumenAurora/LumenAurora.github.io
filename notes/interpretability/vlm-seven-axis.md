# VLM 可解释性研究的七轴穷举框架

> 把一篇 VLM 可解释性论文看成在七个轴上各取一个值的组合：研究对象、分析粒度、研究问题、研究方法、目标现象、验证任务、对比维度。本文给出七轴定义、组合矩阵与评估研究价值的速查表，并附一份从穷举到精选的新手 SOP。

### 全局视角：一篇论文 = 在7个轴上各选一个（或几个）值的组合

```
论文 = f(研究对象, 分析粒度, 研究问题, 研究方法, 目标现象, 验证任务, 对比维度)
       × (模型选择, 数据选择)  ← 这两个是执行层，不算研究设计轴
```

理论组合空间 = 各轴取值数的乘积。但绝大多数组合要么trivial、要么不可行。**新手的核心技能是在这个空间中快速识别"非空且有价值"的格子。**

---

### 轴1️⃣：研究对象（WHAT — 你解释模型的哪个部分？）

> **MECE逻辑：** 按VLM的信息流路径，从输入到输出，不重不漏地切分所有组件。

| 编号 | 研究对象 | 具体指什么 | 当前热度 |
|------|---------|-----------|---------|
| 1.1 | **视觉编码器** (Vision Encoder) | ViT/CLIP视觉塔内部的表征、attention、patch处理 | ⭐⭐⭐ |
| 1.2 | **模态投影层** (Projector/Adapter) | MLP/Q-Former/Cross-attention等将视觉特征映射到语言空间的模块 | ⭐⭐⭐⭐ |
| 1.3 | **语言解码器** (LLM Decoder) | LLM backbone的transformer layers | ⭐⭐⭐ |
| 1.4 | **跨模态注意力** (Cross-modal Attention) | 文本token对图像token的attention（prefix-fusion）或cross-attention | ⭐⭐⭐⭐⭐ |
| 1.5 | **残差流** (Residual Stream) | 隐状态在各层之间的信息传递通道 | ⭐⭐⭐⭐ |
| 1.6 | **输出层** (LM Head / Logits) | 最终的logit分布、概率、采样行为 | ⭐⭐ |
| 1.7 | **多模态统一表征** (Unified Representation) | 不区分模态的联合隐空间（如原生多模态模型Chameleon/Emu3） | ⭐⭐⭐⭐ |
| 1.8 | **外部推理模块** (External Reasoning) | CoT文本、ReAct工具调用、RAG检索结果、视觉crop/zoom | ⭐⭐⭐⭐⭐ |

#### 组合提示：
大多数论文只选1-2个对象。**高价值论文倾向于选"交互界面"而非单一组件**——比如1.4（跨模态注意力）天然比1.3（纯LLM层）更有趣，因为它是VLM的独特之处。

---

### 轴2️⃣：分析粒度（SCALE — 你在什么分辨率下观察？）

> **MECE逻辑：** 从宏观到微观，覆盖所有可能的观察尺度。

| 编号 | 粒度 | 含义 | 典型操作 |
|------|------|------|---------|
| 2.1 | **模型级** (Model-level) | 比较不同模型/不同规模/不同训练阶段 | Scaling law分析、跨模型对比 |
| 2.2 | **模块级** (Module-level) | 对比Vision Encoder vs Projector vs LLM | 分模块ablation、模块贡献度 |
| 2.3 | **层级** (Layer-level) | 按Transformer层深度分析 | 层间探针、逐层干预 |
| 2.4 | **头级** (Head-level) | 分析单个attention head的行为 | Head importance、specialized heads |
| 2.5 | **神经元/通道级** (Neuron/Channel-level) | MLP中间层单个神经元或通道 | Sparse probing、feature visualization |
| 2.6 | **Token级** (Token-level) | 单个token（image patch或text token）的贡献 | Token ablation、attention weight per token |
| 2.7 | **特征/方向级** (Feature/Direction-level) | 隐空间中的特定方向或子空间 | Representation engineering、concept vectors |
| 2.8 | **时间步级** (Timestep-level) | 按生成过程的先后顺序分析 | 生成过程中的attention演变 |

#### 组合提示：
**好的论文通常在两个粒度上做分析**——比如在2.3（层）× 2.8（时间步）上做二维sweep（这正是Osaka论文的核心设计！）。单一粒度往往只够发workshop。

---

### 轴3️⃣：研究问题（WHY — 你想回答什么认知层次的问题？）

> **MECE逻辑：** 按认知深度从浅到深排列，覆盖从"是什么"到"怎么办"的完整问题谱系。

| 编号 | 问题类型 | 核心问句 | 证据要求 | 发表难度 |
|------|---------|---------|---------|---------|
| 3.1 | **描述** (Description) | "模型内部发生了什么？" | 可视化、统计 | ⭐（低） |
| 3.2 | **定位** (Localization) | "哪个组件/层/头负责什么功能？" | 探针、归因 | ⭐⭐ |
| 3.3 | **因果** (Causation) | "组件X是否导致了行为Y？" | 干预实验 | ⭐⭐⭐ |
| 3.4 | **机制** (Mechanism) | "模型通过什么算法/电路实现功能X？" | Circuit discovery | ⭐⭐⭐⭐ |
| 3.5 | **比较** (Comparison) | "模型A和模型B（或训练前后）的内部差异是什么？" | 对比分析 | ⭐⭐ |
| 3.6 | **边界** (Boundary) | "模型的某个能力在什么条件下失效/成立？" | 系统性压力测试 | ⭐⭐⭐ |
| 3.7 | **预测** (Prediction) | "能否从内部状态预测模型行为/性能？" | 探针→行为相关性 | ⭐⭐⭐ |
| 3.8 | **改进** (Improvement) | "基于机制理解，如何设计更好的模型/推理策略？" | 方法设计+验证 | ⭐⭐⭐⭐ |

#### 组合提示：
3.1（描述）单独使用几乎无法发顶会。**顶会论文至少要到3.3（因果）或3.4（机制）**。最聪明的策略是：用3.1做引子，3.3做核心，3.8做贡献。

---

### 轴4️⃣：研究方法（HOW — 你用什么技术手段获取解释？）

> **MECE逻辑：** 按"是否干预模型"和"干预什么"做正交分类。

#### 4A. 观察类方法（不干预，只看）

| 编号 | 方法 | 做什么 | 证据强度 |
|------|------|--------|---------|
| 4A.1 | **Attention分析** | 看attention weight分布、flow、pattern | 弱（相关≠因果） |
| 4A.2 | **线性/非线性探针** (Probing) | 在隐状态上训练分类器检测特定信息 | 中（信息存在≠模型使用） |
| 4A.3 | **表征相似度分析** (RSA/CKA/SVCCA) | 比较不同层/模型/模态的表征几何结构 | 中 |
| 4A.4 | **特征可视化** | 最大化激活的输入图案、t-SNE/PCA降维 | 弱（定性） |
| 4A.5 | **Logit Lens / Tuning-free** | 将中间层隐状态直接投射到词汇表看预测 | 中 |
| 4A.6 | **行为分析** (Behavioral) | 通过精心设计输入观察输出变化 | 中（黑盒） |

#### 4B. 干预类方法（主动改变，看效果）

| 编号 | 方法 | 做什么 | 证据强度 |
|------|------|--------|---------|
| 4B.1 | **输入消融** (Input Ablation) | 遮挡/替换图像区域或文本token | 中 |
| 4B.2 | **组件消融** (Component Ablation) | 关掉特定层/头/MLP | 中-强 |
| 4B.3 | **激活替换** (Activation Patching) | 将某处的激活替换为另一个输入的激活 | 强（因果追踪） |
| 4B.4 | **注意力掩码** (Attention Masking) | 阻断特定Q→K的attention路径 | 强（如Osaka的sweep） |
| 4B.5 | **表征操控** (Representation Steering) | 在隐空间中加减特定方向/概念向量 | 强 |
| 4B.6 | **路径/电路修补** (Path/Circuit Patching) | 在计算图中替换特定路径的信息流 | 很强 |

#### 4C. 归因类方法（量化贡献）

| 编号 | 方法 | 做什么 | 证据强度 |
|------|------|--------|---------|
| 4C.1 | **梯度归因** (GradCAM/Integrated Gradients) | 用梯度衡量输入对输出的贡献 | 弱-中 |
| 4C.2 | **扰动归因** (SHAP/LIME) | 系统性扰动输入拟合局部解释模型 | 中 |
| 4C.3 | **信息论归因** (Mutual Information) | 用互信息量化信息流 | 中 |

#### 组合提示：
**方法本身不决定论文质量，方法和问题的匹配度决定质量。** 4A.1（attention分析）+ 3.1（描述）= 平庸论文。4B.4（attention masking）+ 3.3（因果）= Osaka这样的顶会论文。

### 轴5️⃣：目标现象（PHENOMENON — 你关注VLM的什么行为/问题？）

> **MECE逻辑：** 按VLM的核心能力和已知缺陷分类。

| 编号 | 现象 | 具体表现 | 热度 |
|------|------|---------|------|
| 5.1 | **视觉幻觉** (Visual Hallucination) | 生成与图像矛盾的内容、编造不存在的物体 | ⭐⭐⭐⭐⭐ |
| 5.2 | **注意力衰减/懒惰** (Attention Decay/Laziness) | 对图像token的attention随生成递减 | ⭐⭐⭐⭐ |
| 5.3 | **CoT效果不一致** (Inconsistent CoT Gains) | CoT有时helpful有时harmful | ⭐⭐⭐⭐⭐ |
| 5.4 | **模态偏见** (Modality Bias) | 过度依赖文本先验、忽视视觉信息（language prior） | ⭐⭐⭐⭐ |
| 5.5 | **位置偏见** (Position Bias) | 对图像不同空间位置的关注不均匀 | ⭐⭐⭐ |
| 5.6 | **跨模态对齐质量** (Alignment Quality) | 视觉和语言特征是否真正融合 | ⭐⭐⭐ |
| 5.7 | **知识冲突** (Knowledge Conflict) | 视觉证据与参数化知识（parametric memory）矛盾时的行为 | ⭐⭐⭐⭐ |
| 5.8 | **规模效应** (Scaling Effects) | 模型规模/数据量变化对内部机制的影响 | ⭐⭐⭐ |
| 5.9 | **指令遵循** (Instruction Following) | 模型如何理解和执行复杂多模态指令 | ⭐⭐⭐ |
| 5.10 | **安全/越狱** (Safety/Jailbreak) | 多模态输入下的安全对齐失效 | ⭐⭐⭐⭐⭐ |
| 5.11 | **Test-time Compute** | 推理时计算量增加如何影响内部机制 | ⭐⭐⭐⭐⭐ |

---

### 轴6️⃣：验证任务/数据集（WHERE — 在什么任务上验证你的发现？）

> **MECE逻辑：** 按任务复杂度和数据来源分类。

| 编号 | 任务类型 | 代表数据集 | 特点 |
|------|---------|-----------|------|
| 6.1 | **受控合成任务** | CLEVR、自生成的matplotlib图 | 变量精确可控，诊断性最强 |
| 6.2 | **简单VQA** | VQAv2、GQA、OK-VQA | 广泛使用，可比较性好 |
| 6.3 | **视觉推理** | MathVista、MMMU、ScienceQA | 需要多步推理 |
| 6.4 | **空间/关系推理** | What'sUp、SpatialBench | 测试空间理解 |
| 6.5 | **物体检测/定位** | RefCOCO、Object365 | 测试视觉grounding |
| 6.6 | **幻觉检测** | POPE、MMHal-Bench、HallusionBench | 专门测试幻觉 |
| 6.7 | **多轮对话** | LLaVA-Bench、MM-Vet | 测试动态交互 |
| 6.8 | **视频理解** | VideoMME、MVBench | 时序多模态 |
| 6.9 | **OCR/文档理解** | DocVQA、ChartQA | 细粒度视觉感知 |
| 6.10 | **多模态安全** | MM-SafetyBench | 安全对齐 |

#### 组合提示：
**新手最佳策略：6.1（合成数据做主实验）+ 6.2/6.3（真实数据做泛化验证）。** 合成数据让你精确控制变量，真实数据让审稿人相信你的发现有外部有效性。

### 轴7️⃣：对比维度（COMPARE — 你的发现相对于什么产生meaning？）

> **MECE逻辑：** 按对照实验的变量类型分类。没有对比就没有meaning。

| 编号 | 对比维度 | 具体对比 | 产生的故事 |
|------|---------|---------|-----------|
| 7.1 | **Direct vs CoT** | 直接回答 vs 思维链推理 | "CoT改变了什么内部机制？" |
| 7.2 | **小模型 vs 大模型** | 3B vs 7B vs 32B vs 72B | "Scaling如何改变内部机制？" |
| 7.3 | **训练前 vs 训练后** | Pretrained vs SFT vs RLHF | "训练阶段如何塑造内部机制？" |
| 7.4 | **不同架构** | Prefix-fusion vs Cross-attention vs Native multimodal | "架构设计如何决定信息流？" |
| 7.5 | **不同模态输入** | 只有文本 vs 只有图像 vs 图文联合 | "模态之间如何竞争/协作？" |
| 7.6 | **正确 vs 错误** | 模型答对的case vs 答错的case | "失败时内部机制有什么不同？" |
| 7.7 | **真实输入 vs 对抗输入** | 原始图像 vs 扰动/对抗样本 | "模型的鲁棒性边界在哪？" |
| 7.8 | **不同层/不同时间步** | Early layers vs Late layers / Early tokens vs Late tokens | "信息如何在深度/时间上演变？" |
| 7.9 | **不同视觉属性** | Color vs Shape vs Size vs Position vs Angle | "不同感知维度的处理机制有何差异？" |

#### 组合提示：
**对比维度是story的核心发动机。** 同一个方法+同一个对象，换一组对比维度就是一篇新论文。Osaka的核心对比是7.1（Direct vs CoT）× 7.8（不同层）× 7.9（不同属性），三维交叉产生了极强的story。

### 📊 七轴组合矩阵：快速评估研究价值

将上面的轴组合后，可以用这个评估矩阵快速判断一个组合是否值得做：

```
价值 = 新颖性 × 技术可行性 × So-What深度 × 计算成本可控性

         低新颖性                高新颖性
      ┌──────────────┬──────────────────┐
低成本 │ 练手/Workshop │ ⭐ 新手最佳入口   │
      │ (重复已有方法  │ (新方法+老问题    │
      │  在新对象上)   │  或老方法+新组合) │
      ├──────────────┼──────────────────┤
高成本 │ ❌ 不要做      │ ⭐⭐ 顶会冲刺    │
      │ (花大钱做没    │ (高投入高回报     │
      │  新意的事)     │  需要强story)    │
      └──────────────┴──────────────────┘
```

```
Day 1-3: 文献扫描
  → 用上面的7轴标记你读到的每篇论文（填入表格）
  → 目标：标记30-50篇论文

Day 4-5: 空白格识别  
  → 将标记结果可视化为7维矩阵的投影
  → 找出"空白的格子"——没有论文覆盖的组合

Day 6-7: 空白格过滤
  → 对每个空白格，问三个问题：
    (a) 这个组合在技术上可行吗？（能否拿到模型权重/隐状态？）
    (b) 这个组合的So-What是什么？（如果发现了有趣的结果，谁在乎？）
    (c) 这个组合的成本可控吗？（1张GPU、4周内能出初步结果吗？）

Day 8-10: 最小可行实验 (MVE)
  → 选通过过滤的Top-3组合
  → 每个设计一个1周、1GPU的最小实验
  → 跑完结果，选信号最强的那个

Day 11+: 深挖
  → 围绕选定的组合，扩展实验、写story
```

### ⚠️ 最后的警告：穷举的陷阱

穷举法能帮你**快速入门**和**找到空白**，但它有一个致命陷阱：

> **空白 ≠ 有价值。** 一个格子空着，可能是因为它很难（值得做），也可能是因为它很无聊（不值得做）。

所以穷举之后，**必须用之前讨论的"五层过滤器"（反常检测 → 认知杠杆 → 必然性链条 → 可行性 → So What深度）来精选**。穷举给你候选池，过滤器给你最终选择。

**穷举是"发散"，过滤是"收敛"。好的研究 = 极致的发散 + 极致的收敛。**
## 可解释性研究的方法论：从"观察"到"好故事"的系统化路径

你精准地指出了核心矛盾：

> **组合空间是指数级的，但好故事是稀疏的。怎么在O(N²)的组合中，快速定位到值得做的那几个？**

这不是靠灵感，而是有可系统化的判断框架。让我从底层讲起。
