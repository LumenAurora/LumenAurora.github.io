# 特权基：为什么 Transformer 的某些坐标轴是可解释的

> 向量空间的坐标轴本来是任意贴上去的，但非线性操作（逐元素激活、Softmax）会打破旋转对称性，从而「挑出」某些特殊方向 —— 这就是特权基。本文说明它为何让逐神经元分析重新变得有意义。

### 非线性变换带来特权基
这就引出了一个重要但常令人困惑的概念：特权基。我们声称残差流没有特权基，这使它难以解释。拥有一个向量空间，你需要一组基来理解内部发生了什么。有些技术（如 PCA）能找一组合理的基，但如果能先验地知道什么是正确的基，那解释模型就从面对一个巨大的、无法理清的权重和激活乱麻，变成了面对一堆数字，并且希望每个数字都有独立的意义。有些模型组件更可能拥有特权基，有些则不太可能。

从数学角度想，向量空间是几何对象，坐标轴完全是任意的。必须有某些特殊的东西，才能认为存在特权基——那就是非线性。由于所有与残差流交互的操作都是线性的，残差流本身没有理由存在特权基。我们并不是说残差流很特殊，而是说所有向量空间默认都没有特权基，而模型中有些组件之所以有，是因为它们包含非线性。

具体来说，我认为模型中确实有特权基的组件是：

输入 token：显然，词表就是基。

输出 logits：词表。

MLP 激活值：算有，但是个大乱局。想深究可以看 Transformer Circuits 系列的第四篇关于叠加的玩具模型。

注意力头的注意力模式：内在有意义，因为它直接表示模型如何在不同位置（位置本身有意义）间移动信息。

我们框架的核心目标就是：把模型分解为一系列“路径”，这些路径连接着内在可解释且理想上拥有特权基的组件（token、注意力模式、MLP 激活值、输出 logits），然后去理解连接它们的那些线性部分。

**一句话先抓住核心**：所谓"特权基"（privileged basis），指的是向量空间里存在某一组特别的坐标轴，使得"沿这根轴的那个数字"本身就携带了某种语义——而不是随便挑一组坐标轴、再事后用 PCA 凑出来的。残差流之所以没有特权基，是因为它身上发生的所有读写操作都是线性的，而线性变换对坐标系的选择完全无动于衷；只有当某个操作是非线性的（尤其是逐元素的非线性，比如 ReLU / GELU），它才会"挑出"一组特定的坐标轴，让这组轴变得特殊。

下面按照"向量空间与基 → 为什么默认没有特权基 → 线性为什么不挑轴 → 非线性为什么挑轴 → Transformer 各组件逐个对照 → 这套框架的实际用途"的顺序，一步步把这件事讲透。

---

#### 一、向量空间与基：坐标轴本来就是"任意贴上去的"

向量空间是一个**几何对象**：它里面的元素是箭头（方向＋长度），有加法和数乘，仅此而已。**它本身并没有坐标**。

"坐标"是人为引入的工具：你先在空间里挑 $n$ 个线性无关的方向 $\{e_1, e_2, \dots, e_n\}$，管它们叫"基"，然后任何一个向量 $v$ 都能写成这组基的线性组合：

$$v = c_1 e_1 + c_2 e_2 + \dots + c_n e_n$$

这一串数 $(c_1, \dots, c_n)$ 才是 $v$ 在这组基下的"坐标"。

关键点：**换一组基，同一个向量的坐标就完全变了。** 在二维平面上，向量 $v$ 在标准基 $\{(1,0),(0,1)\}$ 下坐标是 $(1,1)$；如果你把坐标轴旋转 45°，它的坐标就变成 $(\sqrt{2}, 0)$。向量本身（那个箭头）没动，动的只是我们贴上去的刻度尺。

所以从纯数学角度，**任何一组基都和任何另一组基一样"合法"，没有哪组天生比别组更特殊**。这就是"默认无特权基"的起点。

---

#### 二、"特权基"到底是什么：需要架构层面的理由

Neel Nanda 的解释里给了一个精确的区分：

- **可解释的基**（interpretable basis）：你事后通过某种手段（PCA、SVD、稀疏自编码器……）从权重或激活里"找"出来的一组方向，每个方向看起来对应某个语义。换个随机种子重训一遍，这组基可能完全变样。
- **特权基**（privileged basis）：你**不需要看训练后的权重，只看网络架构**就能预言"这组坐标轴是有意义的"。它是一个**先验**性质。

换句话说，特权基不是说"这组基碰巧可解释"，而是说"架构本身把这一组轴摆到了一个特殊的位置上，使得我们有理由期待特征会沿着这组轴对齐"。

为什么这件事对可解释性至关重要？因为如果存在特权基，那么"解释模型"就退化成"读数字"：每个坐标轴对应一个意义，看激活值的第 $i$ 个分量大不大，就知道第 $i$ 个特征在不在。如果没有特权基，那么激活向量的第 137 个分量可能只是某个随机方向的投影，根本没语义——你面对的就是一个"无法理清的权重和激活乱麻"。

---

#### 三、线性操作为什么不挑轴：旋转不变性

这是整个推理的引擎。我们用一个最干净的方式说明它。

##### 1. 残差流是什么

Transformer 的残差流是一个高维向量空间（小模型几百维，大模型几万维），每一层都做两件事：

- **读**：用一个矩阵 $W_{in}$ 把残差流 $x$ 映射成这一层的输入 $W_{in} x$；
- **写**：算完之后，用一个矩阵 $W_{out}$ 把结果映射回残差流维度，再**加**回去：$x \leftarrow x + W_{out}(\cdot)$。

注意"加"这个动作：残差流本身不处理信息，它只是一个所有层都往里读、往里写的**通信通道**，而且读和写都是**线性变换**。

##### 2. 关键引理：线性变换满足"换基共轭"

设 $R$ 是任意一个可逆矩阵（你可以把它想成"换一组新的坐标轴"）。如果我把残差流整体换成 $x' = R x$，那么只要我把所有跟残差流打交道的矩阵也相应地换掉：

- 原来的读矩阵 $W_{in}$ 换成 $W_{in} R^{-1}$（先在新坐标里读）；
- 原来的写矩阵 $W_{out}$ 换成 $R W_{out}$（把写出来的结果再变回新坐标）。

那么整个网络的计算结果**一模一样**：

$$x'_{\text{new}} = R x_{\text{old}}, \quad W'_{in} x' = W_{in} R^{-1} R x = W_{in} x, \quad R W_{out}(\cdot) \text{ 写回后 } = R(x_{\text{old,new}}).$$

也就是说，残差流里发生的所有计算，在"老坐标"和"新坐标"下是**完全等价**的，函数行为不变。

##### 3. 一个具体的小例子

假设残差流是 2 维，某层读矩阵 $W_{in} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$，写矩阵 $W_{out} = \begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$。残差流里某个向量 $x = (1, 1)$。

这一层写回去的增量是 $W_{out} W_{in} x = (2, 3)$，新残差流是 $(3, 4)$。

现在我把坐标轴旋转 90°，即 $R = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$。在新坐标下，同一个向量 $x$ 表示为 $x' = R x = (−1, 1)$。按规则，读矩阵变成 $W_{in} R^{-1} = R^{-1}$（因为 $W_{in}=I$），写矩阵变成 $R W_{out}$。你算一遍：写出的增量在老坐标下还是 $(2,3)$，在新坐标下是 $R(2,3) = (-3, 2)$，新残差流在新坐标下是 $(-1,1)+(-3,2)=(-4,3)$，再换回老坐标 $R^{-1}(-4,3) = (3,4)$。

**完全一样。** 旋转坐标系，什么都没变。这说明残差流里的"第 1 维""第 2 维"这种说法没有任何内在含义——你旋转一下，"第 1 维"就变成了原来"第 2 维的负方向"，而网络照常工作。

##### 4. 推论

既然对残差流可以做任意可逆线性变换而不改变网络行为，那么"残差流里第 $i$ 个坐标轴"这个概念就是**任意**的，没有任何架构层面的理由让它比别的方向更特殊。**所以残差流没有特权基。**

更一般地，Neel Nanda 给出一个干净的判据：

> 如果一段计算只涉及线性代数（加法、矩阵乘、点积……），那么它对坐标系的选择是完全不变的，**不存在特权基**。要找特权基，必须找一个作用在这个向量空间上的**非线性操作**。

还有一个等价的、非常有用的视角：**低秩分解的中间产物没有特权基**。如果计算是 $u = A(Bv)$，中间那个 $w = Bv$ 所在的空间就是"夹在两个线性变换之间的瓶颈"。因为 $A' = AR,\ B' = R^{-1}B$ 时 $A'B' = AB$ 不变，而中间量变成了 $w' = R^{-1} w$——中间空间的坐标是任意的。残差流正是这种"中间空间"的极致版本。

---

#### 四、非线性为什么挑轴：逐元素操作打破对称性

现在看另一边。ReLU 是一个**逐元素**的非线性函数：

$$\text{ReLU}(x)_i = \max(0, x_i)$$

"逐元素"三个字是全部魔法所在：它对向量的**第 $i$ 个分量**单独操作，跟其他分量无关。

##### 1. 标准基下 ReLU 是"坐标独立"的

在标准基 $\{e_1, \dots, e_n\}$ 下，ReLU 就是把每个坐标单独 clip 到非负：$(−1, 2, −3) \to (0, 2, 0)$。每个轴被独立处理，第 $i$ 个轴的行为只取决于第 $i$ 个坐标。这就让标准基变得**特殊**了：在这种基下，"第 $i$ 个神经元"是一个有独立意义的计算单元。

##### 2. 换基之后 ReLU 变成什么？

如果你把坐标轴旋转 45°，原来标准基下的 ReLU 在新基下变成什么？它不再是"对每个新坐标独立 clip"，而是变成一个奇怪的、把多个新坐标耦合在一起的非线性操作。几何上，ReLU 在标准基下是一个"沿坐标轴方向折叠"的折面（像折起来的纸）；旋转之后，这个折面也跟着转，它不再对齐新坐标轴了。

也就是说，**ReLU 这个操作本身"记住"了标准基**。你没法通过换基把 ReLU 变成另一个等价的、对新基逐元素的 ReLU——除非你用的"换基"是一个置换矩阵（只交换坐标轴，不旋转），或者更严格地说，是一个能让 ReLU 形式不变的特殊变换（基本上只有带正负号的置换）。

##### 3. 用数学语言说

设 $f(x) = \text{ReLU}(x)$ 是逐元素 ReLU。如果存在可逆矩阵 $R$ 使得对所有 $x$ 都有

$$f(R x) = R f(x)$$

也就是"先换基再 ReLU"等于"先 ReLU 再换基"，那么 ReLU 就跟坐标系无关、没有特权基。但这个等式对一般的 $R$ **不成立**。例如取 $R = \begin{pmatrix} 1/\sqrt2 & -1/\sqrt2 \\ 1/\sqrt2 & 1/\sqrt2 \end{pmatrix}$（旋转 45°），$x = (1, 0)$：

- 左边：$R x = (1/\sqrt2, 1/\sqrt2)$，ReLU 之后还是 $(1/\sqrt2, 1/\sqrt2)$；
- 右边：$\text{ReLU}(x) = (1, 0)$，再 $R$ 作用得到 $(1/\sqrt2, 1/\sqrt2)$。

这个例子碰巧相等。换 $x = (-1, 1)$：

- 左边：$R x = (2/\sqrt2 \cdot (-1+1)/\sqrt2, \dots)$……算了，直接算：$R x = ((-1-1)/\sqrt2, (-1+1)/\sqrt2) = (-\sqrt2, 0)$，ReLU 后是 $(0, 0)$；
- 右边：$\text{ReLU}(-1, 1) = (0, 1)$，$R(0,1) = (-1/\sqrt2, 1/\sqrt2)$。

$(0,0) \neq (-1/\sqrt2, 1/\sqrt2)$。**等式不成立。** 这就证明了 ReLU 不是旋转不变的，它"挑出"了标准基。

##### 4. 直观总结

线性操作是"全局搅拌"：你旋转输入，输出也跟着旋转，关系不变。非线性（尤其是逐元素的非线性）是"按轴切片"：它只认准某一套坐标轴去切，你换了轴它就不认了。**正是因为逐元素非线性只在一组特定的坐标轴下才有"逐元素"这个简单形式，这组坐标轴才获得了特权地位。**

进一步，因为训练时 ReLU 只在标准基下"干净地"对每个神经元独立作用，梯度下降会**倾向于让特征对齐到这些神经元方向上**——这就是所谓的"特征即神经元"假设，也是特权基真正发挥解释力的地方。

#### 五、对照表：Transformer 各组件的特权基情况

把上面的判据（"夹在两个线性变换之间 → 无特权基；被逐元素非线性碰过 → 有特权基"）套到 Transformer 上，逐个核对：

| 组件 | 有无特权基 | 关键操作性质 | 直观解释 |
|---|---|---|---|
| **输入 token embedding** | 有 | 查表：每个 token id 对应 embedding 矩阵的一行 | 词表本身就是一组离散基，第 $i$ 个 token 就是第 $i$ 个基向量，天然对齐 |
| **输出 logits** | 有 | $W_U x$，$W_U$ 是 unembedding 矩阵 | logits 的每一维对应词表里一个 token，词表结构先验地定义了这组基 |
| **残差流** | 无 | 所有层读写都是线性变换，层与层之间只有加法 | 任意可逆线性变换 $R$ 都可"吸进"读写矩阵而不改变行为，坐标轴完全任意 |
| **MLP 的中间激活值**（ReLU/GELU 之后） | 有 | 经过逐元素非线性 ReLU/GELU | 非线性只认标准基，每个"神经元"是独立计算单元，因此神经元方向是特权的；但实际中由于**叠加**，特征并不一定干净对齐到单个神经元，所以是"有特权基但仍然乱" |
| **注意力头的 OV / QK 电路内部** | 无 | $W_O W_V$、$W_Q^T W_K$ 都是矩阵乘积，中间无非线性 | 中间空间是低秩分解的产物，可任意换基；所以单个 attention head 没有像神经元那样自然的分解 |
| **注意力模式**（attention pattern） | 有 | $\text{softmax}(QK^T/\sqrt{d})$，softmax 在位置维度上逐元素归一化 | 注意力模式直接定义"位置 $i$ 对位置 $j$ 的关注强度"，位置本身有语义（哪个 token 在哪），所以模式是内在可解释的 |
| **LayerNorm 之后** | 部分有，但常被吸收 | LayerNorm 沿特征维度做归一化，是逐元素的 | 理论上引入了一点基依赖，但 Anthropic 的框架把 LayerNorm 折叠进相邻的线性变换里近似处理 |

一个值得注意的细节：Anthropic 后来发现，实际训练的大模型里残差流**确实**会出现一些"异常维度"（某些坐标的值比其他大 20 倍），看起来残差流"偷偷有了"特权基。他们排查后认为这是 **Adam 优化器的逐维度归一化**造成的，而不是架构本身带来的——也就是说，这是优化器引入的副作用，而非残差流"天生"有特权基。这反而印证了上面的理论：架构层面残差流不该有特权基，任何观察到的基对齐都来自某种"打破对称性"的外部因素（非线性、优化器、数值精度等）。

#### 六、这套框架到底想干什么：路径分解

理解了上面的对照表，Anthropic 框架的"路径展开"思路就水到渠成了。

Transformer 的计算图长这样：token →（线性嵌入）→ 残差流 →（线性读 + 注意力 + 线性写）→ 残差流 → … →（线性 unembed）→ logits。中间这一长串残差流，**全是线性操作**，所以可以把它们乘开：

- 任意两层之间的"虚拟权重" $W_I^2 W_O^1$ 直接刻画了"第 1 层写的信息有多少被第 2 层读到"；
- 整个模型从 token 到 logits，可以展开成一系列"路径"的乘积之和，每条路径形如 $W_U \cdot (\text{某层输出}) \cdot W_O^{(l)} \cdot (\text{注意力模式}) \cdot W_V^{(l)} \cdots W_E$。

这些路径的**端点**——token、注意力模式、MLP 神经元激活、输出 logits——**都是有特权基、内在可解释的组件**；而连接它们的那些线性段（残差流、$W_O$、$W_V$ 等）**没有特权基**，但正因为它们线性，可以自由地乘在一起、折叠、重写，而不损失任何信息。

这就是框架的核心策略：**用线性段的可组合性，把模型拆成一条条连接可解释端点的路径，然后分别理解每条路径在做什么**（比如 skip-trigram、induction head 等）。残差流没有特权基，在这里不是障碍，反而是优点——正因为线性、可任意组合，我们才能做这种路径展开。

---

#### 七、一句话收尾

向量空间默认没有特权基，因为坐标轴是人为贴的；线性操作对坐标轴无动于衷，所以夹在线性变换之间的空间（残差流、低秩分解的中间层）没有特权基；逐元素非线性只认准一套坐标轴去"切"，所以被它碰过的空间（MLP 神经元激活、token 词表、logits）有特权基。Transformer 可解释性的整套路径分解框架，就建立在这条简单判据之上。
