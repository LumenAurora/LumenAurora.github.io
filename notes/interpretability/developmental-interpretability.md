# 训练过程的可解释性世界模型：从随机初始化到对齐模型

> 把一次训练看成模型的「发育史」：预训练从混沌到有序的相变序列、Grokking、归纳头的形成、SFT 改变接口不改变底层、RLHF/RLVR 真正改变模型「想要什么」，最后给出各阶段的可解释性视角统一表。

### 壹 · 第一阶段：预训练——从混沌到有序的相变序列

#### 1.1 最底层的物理图像：梯度下降是一个相变过程

预训练不是平滑渐进的知识积累，而是一系列**离散的相变**。

发育可解释性研究的核心主张是：结构通过相变在训练中增量涌现。研究者并不认为训练神经网络中的所有知识和计算都以相变方式涌现，但其工作假说是：足够多的结构以这种方式涌现，使得相变成为可解释性的有效组织原则。

这里有一个关键的物理类比：水结冰不是水分子一个一个慢慢变慢，而是在某个临界温度发生集体性的、不连续的结构转变。训练中的电路形成也是如此——**不是每个参数逐渐调整到位，而是某些计算结构在特定训练步骤突然集体涌现**。

#### 1.2 Grokking：记忆化 → 泛化的相变解剖

Grokking现象是理解预训练动态最干净的窗口。

Grokking指的是这样一种训练机制：模型先过拟合，然后在长时间停滞后，经历向强泛化的突变。这一现象最初在使用AdamW的Transformer上的模块化算术任务中观察到，此后在群论、图像分类等多样化任务和架构中被记录，表明这是一种对优化选择鲁棒的基本训练动态。

它的机械机制是：Nanda等人将一层Transformer在模块化加法上学习到的算法逆向工程为：先对输入执行离散傅里叶变换，再通过余弦乘法恒等式执行加法，并将训练动态分解为记忆化、电路形成和清理三个阶段。

这三个阶段对应一个深刻的竞争动态：Transformer从分布式协同适应过渡到实现算法解的模块化子电路。这种从分布式到模块化的转变涉及密集记忆化电路与稀疏泛化电路之间的竞争，并伴随着向更平坦极小值的景观变化。

**直觉图像**：训练早期，模型用"死记硬背"（记忆化电路）来降低损失，这很有效但很笨拙。与此同时，一套更优雅的"理解算法"（泛化电路）在缓慢成长。当泛化电路足够强大，加上权重衰减惩罚了记忆化电路的高复杂度，系统发生相变：记忆化电路被压制，泛化电路胜出——这一刻就是Grokking。

#### 1.3 信息论视角：Grokking的序参量

Grokking对应于神经网络训练中真实的涌现相变。一个信息论的协同性度量（synergy）作为严格的序参量涌现出来：协同性被定义为将一组神经元视为整体时获得的额外互信息，超过它们各自贡献之和。协同性在记忆化阶段保持低位，然后在转变点急剧跃升，重现了物理学中相变动力学的特征。

更具体地，训练被划分为：特征学习（冗余主导）、涌现（协同性快速增长）、分歧（过拟合/衰减）、延迟涌现（第二次协同性跃升）等阶段。

#### 1.4 归纳头的形成：第一个被完整记录的电路发育史

归纳头是目前文献中**被最完整地从诞生到成熟全程追踪的计算结构**，是理解预训练动态的最佳案例。

Olsson等人的研究根植于机械可解释性，展示了上下文学习的涌现如何与特定训练相变相关联，将微观变化（归纳头）与宏观可观测量（训练损失）连接起来。

归纳头不是单独形成的：这些电路的发育不是整体性的，而是通过更简单子电路的交互分阶段涌现。Singh等人使用因果框架识别出关键子电路，它们的相互作用导致了训练期间归纳头的突然形成。

而且数据分布直接决定了这个涌现的时机：这种涌现本身也关键地依赖于训练数据；特定的分布属性，如突发性（burstiness）和类别不平衡，被证明是这种能力的关键驱动因素。

**直觉图像**：归纳头的形成就像胚胎发育中的器官形成——不是凭空出现，而是由更简单的"前体结构"（子电路）相互交互，在特定的"发育信号"（训练数据分布）触发下，突然组装成具有完整功能的器官。

#### 1.5 发育可解释性的数学工具：奇异学习理论（SLT）

奇异学习理论（SLT）由Watanabe发展，为理解过参数化模型的行为和泛化提供了严格框架。通过局部学习系数（LLC）来量化模型复杂度，SLT为学习相变和模型中结构的涌现提供了洞察。

将精化的局部学习系数（rLLC）应用于双层注意力Transformer的各个组件，可以对注意力头在训练过程中的逐步分化和专业化获得新颖洞察。

发育可解释性强调数据中的分布结构、损失景观的几何结构、学习动态中的结构，以及模型中由此产生的计算结构之间的相互作用。

**直觉图像**：SLT提供了一个"测温计"——LLC就像热力学中的序参量，可以在相变发生之前就探测到系统内部复杂度的变化，从而预测相变的到来。

#### 1.6 事实知识的获取：不是你想象的那样

实验揭示了事实知识获取动态的几个重要洞察。首先，事实知识的获取通过每次遇到含有该知识的小批量时概率的小幅累积增加来实现。其次，与早期阶段的检查点相比，后期阶段的检查点在获取记忆化和泛化方面没有显著差异。另一方面，7B模型的效能大于1B模型，表明扩大模型规模和预训练token数的收益在事实知识获取方面是质性不同的。

而且存在一个重要的频率效应：LLM对更热门的知识积累对数概率的速度更快，因此这类知识的获取会在相对较早的预训练阶段就体现在模型的输出生成中。知识在预训练数据中的流行程度，影响着这一知识在预训练期间多早开始在生成序列中"显现"，长尾知识因低流行度而遇到间隔较长，因此显现较晚。

**直觉图像**：知识不是一次性习得的，而是通过**重复曝光的概率累积**。每次见到某个事实，模型对它的"置信度"就微微上升一点，直到超过某个阈值才真正"会说"。流行知识的阈值被快速越过，长尾知识可能永远越不过去。

#### 1.7 表征的层级涌现：从语法到语义的时间序

可以通过跨训练检查点追踪概念级别特征的演化，揭示表征何时以及如何涌现。一条平行研究路线通过模型性能、参数变化和跨训练步骤的激活模式来检视模型的学习轨迹。

跨模型的比较揭示了一个收敛趋势：一些研究将这些动态与认知信号（如大脑活动）对齐，或追踪知识随时间的获取。但更关键的是，我们缺乏对特定语言能力何时以及如何在预训练中涌现的清晰理解——如果能弥合这一差距，将使我们能够在概念层面更好地理解LLM的预训练。

### 贰 · 预训练中的电路竞争：统一图景

综合以上，预训练可以被理解为一场**多套电路同时竞争同一参数空间的演化博弈**：

```
训练步骤 →

早期：
  [记忆化电路]████████████████▓▓▓▓░░░░
  [泛化电路]  ░░░░░░░░▓▓▓▓████████████

              ↑
          Grokking相变点
          （当泛化电路效率超过记忆化电路
            且权重衰减惩罚复杂性时）

中期：
  [浅层语法电路]    先涌现（低频次即可）
  [归纳头/ICL电路]  中期涌现（需要数据分布的burstiness触发）
  [深层语义电路]    晚期涌现（需要大量样本积累）

晚期预训练（长上下文/高质量数据）：
  [跨文档推理电路]  最晚涌现
  [元认知相关结构]  可能从未完全涌现（需要post-training）
```

一项研究对LLM在持续预训练过程中如何获取、保留和遗忘概念进行了统一分析，将输出行为与电路级可解释性整合，并将知识学习的研究从孤立事实扩展到知识内部及概念间的结构化相互关系，以及这些关系如何驱动干扰和协同。

分析揭示：概念电路在持续预训练中呈现阶段性时序模式——先期增加，随后逐渐减少并趋于稳定；学习收益较大的概念在后续训练中也往往表现出更大的遗忘。

### 叁 · 第二阶段：SFT——改变接口，不改变底层

#### 3.1 SFT做了什么（和没做什么）

监督微调（SFT）通过最大化专家示范的似然来使LLM与下游任务对齐，本质上是执行模仿学习或行为克隆。然而，SFT会过拟合训练分布，对分布外输入的泛化较差。

从机械可解释性的视角看，SFT的作用更精确地描述为：后训练模型被期望保留预训练期间学习的知识，提高真实性，增强对有害输入的拒绝，并显示与基础模型不同的置信度水平。具体包括通过全部后训练阶段的最终instruct模型，以及仅在基础模型上进行监督微调的SFT模型。

**关键直觉**：SFT更像是**训练模型的"对话格式化层"和"任务接口层"**，而不是重新训练底层的知识表征。

#### 3.2 微调增强既有机制，而非创造新机制

这是理解SFT最重要的实证发现：微调倾向于**增强和调整预训练中已经形成的机制**，而非从头创建新的计算结构（Prakash等人，ICLR 2024，"Fine-tuning Enhances Existing Mechanisms: A Case Study on Entity Tracking"）。

这有深刻含义：如果预训练没有形成某个电路，SFT很可能也无法凭空创造它。SFT是在已有地基上装修，不是重建地基。

#### 3.3 指令调整改变了什么

从预训练语言建模到指令跟随的行为转变中，模型改变了什么？我们缺乏对特定语言能力何时以及如何涌现的清晰理解——类似地，对于SFT具体改变了哪些内部机制，某些视角，如推理和指令跟随，涉及当前可解释性工具尚不能很好捕捉的复杂多步过程。

这是一个**当前的主要空白**：SFT的内部机制远比RLHF研究得更少。

### 肆 · 第三阶段：RLHF/RLVR——真正改变模型"想要什么"

#### 4.1 RLHF的深层问题：行为对齐 vs 内部对齐

当前对齐方法主要依赖RLHF，通过人类偏好反馈对模型进行微调。虽然对改善表面行为有效，RLHF对于模型是否真的内化了期望价值、还是仅仅学会了模仿对齐行为，提供的洞察非常有限。

这是整个可解释性与对齐交叉领域的核心张力：**RLHF改变了模型说什么，但我们不知道它是否改变了模型"想"什么**。

行为对齐方法——如RLHF和各种提示策略——已显示出实际成功，但它们将模型视为黑盒，对泛化到新情境或对抗性输入提供有限的保证。机械可解释性提供了互补的范式：理解LLM在训练期间学习到的内部算法和表征。

#### 4.2 RLHF在内部做了什么：安全神经元的发现

识别可解释神经元长期以来是Transformer机械可解释性研究的目标。Geva等人提出将Transformer中的前馈网络视为键值记忆，为解释提供了新方向。

对于RLHF的对齐机制，可解释性研究揭示了一个关键的方向性结构：研究者学习了一个"拒绝方向"（类似于隐表征空间中的真实性方向）。发现这种拒绝方向的可迁移性只在反向（从后训练模型到基础模型）有效，而非正向（从基础模型到后训练模型）。

**这个不对称性极其深刻**：你可以从对齐后的模型提取出"拒绝方向"并把它注入到基础模型，但不能反过来从基础模型提取并注入到对齐模型——说明对齐训练创造了一种新的方向结构，而这个结构在基础模型中并不以清晰形式存在。

#### 4.3 RLHF对齐的可解释性框架

强化学习是一个关键前沿，考虑到其在高级AI训练（如RLHF）中的角色。RL可解释性应该研究奖励/目标表征、对齐算法引起的电路变化，以及涌现的子目标或代理，如内部奖励模型。

从机械层面，对齐算法的作用可以被理解为：可解释性使得精确干预成为可能。电路编辑、头消融或表征重加权等技术已被用于抑制不期望的行为（如毒性或偏见），同时保留任务相关功能。通过定位和修改负责失对齐行为的子图，可解释性能够实现精确的行为纠正，避免无差别的微调。

#### 4.4 RLVR（强化学习用于推理）：新的可解释性前沿

RLVR（如DeepSeek-R1、o1背后的训练范式）是当前最前沿也最不透明的训练阶段。

实证研究证实，基于RL的微调在推理密集型任务上产生更优的鲁棒性，使得SFT-RL的泛化差距成为核心对齐挑战。

从可解释性视角，RLVR最关键的开放问题是：强化学习到的推理能力，是在内部创造了新的计算电路，还是只是更好地利用了预训练中已有的电路？目前文献尚无清晰答案，这是可解释性研究最有价值的空白之一。

### 伍 · 各训练阶段的统一动态图景

现在可以把三个阶段整合成一张完整的"发育时间线"：

```
══════════════════════════════════════════════════════════════════
                    模型的"发育时间线"
══════════════════════════════════════════════════════════════════

【预训练阶段】：从混沌到有序的相变序列

Step 0 (随机初始化)
  → 所有权重随机，没有任何有意义的电路

Step 早期（语法期）
  → 浅层语法电路率先形成（低频次即可触发）
  → 局部词法模式的记忆化电路大量形成
  → 损失快速下降

Step 中期（归纳期）
  → 归纳头在特定数据分布触发下突然涌现（相变！）
  → 上下文学习能力在这一刻获得
  → 开始形成跨位置的信息路由能力
  → 事实知识通过重复曝光逐步积累

Step 晚期（语义期）
  → 泛化电路逐步超越记忆化电路（Grokking式相变）
  → 深层语义抽象特征涌现
  → 世界模型结构在激活空间中形成
  → 高频知识已稳固，长尾知识仍在积累

【SFT阶段】：改变接口，增强机制

  → 对话格式化层建立（问答结构的接口习得）
  → 既有电路被增强和调整，而非重建
  → 特定任务的注意力模式被强化
  → 底层知识表征基本保持不变
  → 新能力有限：只能激发预训练中已有的潜力

【RLHF/RLVR阶段】：改变"想要什么"

  RLHF：
  → 拒绝方向在残差流中形成（可提取的方向向量）
  → 安全相关的神经元/特征获得更强激活权重
  → 有害行为电路被抑制，但未被删除（可能被激活规避）
  → 表面行为改变 >> 内部价值改变（对齐的根本困难）

  RLVR：
  → 推理质量的系统性提升（机制尚不清楚）
  → 可能：强化了预训练中已有的推理电路
  → 可能：创造了新的多步推理结构（待验证）
  → 内部CoT忠实性可能提升（但未证实）

══════════════════════════════════════════════════════════════════
```

### 陆 · 三个阶段的可解释性视角统一表

| 维度 | 预训练 | SFT | RLHF/RLVR |
|---|---|---|---|
| **主要变化** | 电路从无到有，经历相变 | 调整接口，增强现有电路 | 修改目标表征，抑制部分电路 |
| **变化单位** | 整个模型的权重 | 接口层和任务相关层 | 特定方向向量和神经元权重 |
| **时间结构** | 非线性：平静期+相变点 | 相对平滑的行为漂移 | 奖励驱动的跳跃性变化 |
| **可解释性工具** | LLC/SLT追踪相变；检查点间的SAE比对 | 微调前后的电路对比；表征漂移分析 | 拒绝/安全方向提取；行为特征定位 |
| **主要开放问题** | 如何预测相变的时机和内容？ | SFT究竟改变了哪些内部机制？ | RLHF是内化价值还是表面模仿？RLVR的内部机制是什么？ |
| **对齐含义** | 预训练中如果没有形成电路，后续无法补救 | SFT安全可能很脆弱（底层能力未改变） | 对齐表面行为≠对齐内部目标 |

### 柒 · 对你的研究的直接启示

理解了这个发育图景，有三个对可解释性研究者特别重要的认识：

#### 启示一：电路的"年龄"决定了它的稳健性

预训练早期形成的电路（如归纳头、语法电路）经过了大量训练步骤的强化，对SFT和RLHF的改变具有高度抵抗力。预训练晚期或SFT期间形成的结构则相对脆弱。这解释了为什么"越狱"往往能绕过SFT的安全训练——发育可解释性的一个关键动机是研究安全关键模式的普遍性，旨在理解欺骗等能力有多深入固化，从而对安全微调有多大抵抗力。

#### 启示二：数据分布是电路涌现的"触发器"

发育可解释性强调数据中的分布结构、损失景观的几何结构、学习动态中的结构，以及模型中由此产生的计算结构之间的相互作用。

这意味着：**如果你想理解为什么某个模型有某个特定的能力（或没有），你必须追溯到预训练数据的分布特性**。能力不是凭空出现的，而是被特定的数据分布触发和塑造的。

#### 启示三："可解释性"本身需要区分"静态"和"发育"视角

机械可解释性强调特征和电路作为分析的基本单位，通常旨在理解完全训练好的神经网络。而发育可解释性追问的是这些特征和电路**为什么**是现在这个样子——它们是在什么条件下、通过什么过程形成的。

两者缺一不可：静态分析告诉你"器官的结构"，发育分析告诉你"器官为什么长成这样"。对于理解训练失败、能力缺失、对齐脆弱性，发育视角往往更有解释力。

---

### 终 · 一句话整合

> **预训练是一部通过相变序列从混沌到有序的发育史，数据分布是发育的激素信号，电路的涌现是器官形成；SFT是青春期的社会化训练，在不改变底层神经结构的前提下习得了社会接口；RLHF/RLVR是成年后的价值观塑造——但我们不知道它改变的是真实的内部价值观，还是只是给已有的行为系统加了一层过滤器。可解释性研究的终极使命，就是区分这两种可能。**
