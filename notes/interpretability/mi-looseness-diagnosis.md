# 机制可解释性的「松散」：一个精确的诊断

> 机制可解释性常让人感觉「松散」、不成体系。本文精确诊断这种松散：它是否真是问题、松散之下是否藏着统一性、学习力学（learning dynamics）又能如何帮助「收紧」它，以及你该如何在松散中给自己定位。

#### 1.1 前文所述的"松散"到底是什么？

> 让我尝试把你模糊的感受变成精确的陈述：

**学习力学**有一个清晰的"学科结构"：

```
研究对象：训练过程（参数随时间的演化）
核心语言：微分方程、概率论、统计物理
核心方法：建模 → 求解 → 预测 → 验证
核心问题：一个（训练动力学是什么？）
评价标准：预测是否被实验验证
```

**机制可解释性**没有这样的统一结构：

```
研究对象：？？？（特征？回路？算法？能力？行为？）
核心语言：？？？（线性代数？信息论？认知科学？工程直觉？）
核心方法：？？？（SAE？激活修补？消融？探针？因果干预？）
核心问题：？？？（理解？编辑？安全？科学？）
评价标准：？？？（可复现？有预测力？有工程价值？）
```

> **你的感受可以精确表述为**：机制可解释性缺乏一个**统一的范式**（paradigm）——没有库恩意义上的"常规科学"结构。

---

### 二、为什么会这样？（结构性原因）

#### 2.1 五个结构性原因

| 原因 | 说明 |
|------|------|
| **① 对象太复杂** | 真实网络有数十亿参数，无法像物理系统那样"写出方程" |
| **② 缺乏"第一性原理"** | 没有类似牛顿定律的起点，无法从公理推导 |
| **③ 目标多元** | 有人要理解，有人要编辑，有人要安全，有人要科学 |
| **④ 方法驱动而非问题驱动** | 很多研究是"我有了SAE这个工具，看看能发现什么" |
| **⑤ 处于"前范式"阶段** | 库恩意义上的：还没有一个被广泛接受的框架 |

#### 2.2 与学习力学的对比

| | 学习力学 | 机制可解释性 |
|---|---|---|
| 对象 | 参数空间中的轨迹（低维、可写方程） | 网络内部的结构（高维、难以穷举） |
| 第一性原理 | 有：架构 + 数据 + 优化器 → 梯度流方程 | 无：没有"从架构推出回路"的方程 |
| 目标 | 统一：理解训练动力学 | 多元：理解/编辑/安全/科学 |
| 驱动力 | 问题驱动（"为什么会Grokking？"） | 方法驱动（"SAE能发现什么？"） |
| 范式 | 有（动力系统 + 统计物理） | 无（前范式） |

#### 2.3 一个精确的类比

> **机制可解释性现在的状态，类似于18世纪的博物学。**

| 18世纪博物学 | 2020年代机制可解释性 |
|-------------|---------------------|
| 收集标本、描述物种、画解剖图 | 收集特征、描述回路、画激活图 |
| 没有统一理论（进化论还没出现） | 没有统一理论（学习力学还没成熟） |
| 方法多样：分类学、解剖学、胚胎学、生态学 | 方法多样：SAE、探针、消融、因果干预 |
| 研究者各做各的，缺乏共同语言 | 研究者各做各的，缺乏共同框架 |
| 林奈：分类（命名系统） | Anthropic/OpenAI：发现（特征/回路目录） |
| 达尔文：统一理论（自然选择） | ？？？：统一理论（学习力学？） |

> **关键**：18世纪博物学的"松散"不是缺陷——它是**探索阶段的必然特征**。你不可能在还没收集够标本的时候就建立统一理论。

### 三、但"松散"之下有隐藏的统一性

#### 3.1 所有机制可解释性研究的隐含共同结构

> 尽管看起来五花八门，所有机制可解释性研究都在做**同一件事**：

```
所有机制可解释性研究的统一形式：

  给定一个网络 N 和一个行为 B，
  找到一个"简化描述" D，
  使得 D 能解释/预测/控制 B。

  其中 D 的"粒度"和"语言"因研究而异。
```

| 研究 | N | B | D（简化描述） | 粒度 |
|------|---|---|--------------|------|
| SAE特征发现 | GPT-2 | 生成文本 | "层6有'金门大桥'方向" | 单个特征 |
| 回路发现 | GPT-2 small | Induction | "头1.5→头2.1的回路" | 组件间连接 |
| 激活修补 | GPT-4 | 事实回忆 | "层12的MLP是关键" | 层/模块 |
| 模型编辑 | LLaMA | 知识更新 | "修改层17的MLP权重" | 参数子集 |
| 行为分析 | Claude | 拒绝有害请求 | "拒绝由特定回路介导" | 功能模块 |
| 涌现分析 | 不同规模模型 | 能力出现 | "能力在X规模突然出现" | 规模/能力 |

> **统一性在于**：所有研究都在做 **"从复杂系统中提取简化描述"**。
> **多样性在于**：简化描述的**粒度**、**语言**、**目的**不同。

#### 3.2 一个更精确的框架：三个层次

> 机制可解释性的"松散"其实是因为它同时包含了**三个不同层次**的研究，而这三个层次的目标和方法完全不同：

```
层次1：发现（Discovery）
  "网络里有什么？"
  方法：SAE、探针、可视化
  产出：特征目录、回路图谱
  类比：博物学家收集标本
  评价：覆盖率、可复现性

层次2：理解（Understanding）
  "这些东西为什么存在？它们如何协作？"
  方法：因果干预、消融、计算分析
  产出：算法描述、功能解释
  类比：解剖学家理解器官功能
  评价：解释力、预测力

层次3：控制（Control）
  "如何修改/引导网络的行为？"
  方法：模型编辑、RLHF、对抗训练
  产出：编辑方法、对齐技术
  类比：外科手术
  评价：有效性、副作用
```

> **你的"松散感"来源于**：这三个层次经常被混在一起讨论，但它们实际上是**不同的科学活动**。

| 层次 | 科学类型 | 对应学科 |
|------|----------|----------|
| 发现 | 描述性科学 | 分类学、博物学 |
| 理解 | 解释性科学 | 生理学、解剖学 |
| 控制 | 工程 | 外科学、药理学 |

> 一个"发现"论文（"我们发现了X特征"）和一个"控制"论文（"我们可以编辑Y行为"）看起来都在做"机制可解释性"，但它们实际上是**完全不同的科学活动**。

### 四、这种"松散"是问题吗？

#### 4.1 是问题的方面

| 问题 | 表现 |
|------|------|
| **缺乏累积性** | 每个发现都是孤立的，难以形成"知识体系" |
| **缺乏预测力** | 发现了很多特征/回路，但无法预测"下一个会发现什么" |
| **评价标准模糊** | 什么算"好的"可解释性研究？没有共识 |
| **难以证伪** | "这个回路负责X"——如何证明它是错的？ |
| **工具驱动** | "SAE能做什么"比"我们需要回答什么"更常见 |

#### 4.2 不是问题的方面

| 方面 | 为什么不是问题 |
|------|---------------|
| **探索阶段的必然** | 你不可能在还没收集够数据时就建立理论 |
| **对象的复杂性** | 真实网络确实比物理系统复杂得多 |
| **多样性是健康的** | 多种方法并行探索，增加发现概率 |
| **工程价值独立于理论** | 即使没有统一理论，模型编辑也有价值 |

#### 4.3 精确的判断

> **机制可解释性的"松散"不是缺陷，而是"前范式阶段"的特征。**

> 库恩在《科学革命的结构》中说：
> - **前范式阶段**：多种方法并行，没有统一框架，研究者各做各的
> - **常规科学阶段**：有统一范式，研究者在范式内"解谜"
> - **革命阶段**：旧范式被新范式取代

> **机制可解释性现在处于"前范式→常规科学"的过渡期。**
> 学习力学（如果成功）可能提供那个"范式"。

### 五、学习力学如何帮助"收紧"机制可解释性？

#### 5.1 学习力学能提供的统一性

| 机制可解释性的"松散" | 学习力学能提供的"收紧" |
|---------------------|----------------------|
| 发现是孤立的 | 理论预测"应该存在什么" → 发现变成"验证" |
| 无法预测 | 理论给出定量预测 → 可证伪 |
| 评价标准模糊 | "预测是否被验证"成为清晰标准 |
| 工具驱动 | 问题驱动："理论预测X，我们去验证" |
| 三个层次脱节 | 统一框架：动力学 → 结构 → 功能 → 控制 |

#### 5.2 一个具体的例子

```
没有学习力学的机制可解释性：
  "我们用SAE发现了'金门大桥'特征。"
  → 然后呢？为什么有这个特征？为什么在这个层？
  → 无法回答。

有学习力学的机制可解释性：
  "理论预测：在训练数据中频率>阈值的概念，
   会在第L层形成线性可表示的特征，
   其中L由数据的层次结构决定。"
  → 发现'金门大桥'特征 = 验证理论预测
  → 如果没发现 = 理论需要修正
  → 有方向感、有预测力、可证伪
```

#### 5.3 但学习力学不能完全"收紧"机制可解释性

> **重要的限制**：

| 学习力学能做的 | 学习力学不能做的 |
|---------------|-----------------|
| 预测"什么类型的机制会形成" | 预测"具体哪个神经元编码什么" |
| 解释"为什么有这个回路" | 告诉你"这个回路的具体权重是什么" |
| 给出统计性预测 | 给出个体性描述 |
| 类比：进化论预测"会有翅膀" | 类比：进化论不能预测"这只鸟的翅膀具体长什么样" |

> **所以**：即使学习力学完全成功，机制可解释性的"发现"层次（层次1）仍然需要。
> 学习力学提供的是**"为什么"和"预测"**，不是**"具体是什么"**。

### 六、对你的意义：如何在"松散"中定位自己

#### 6.1 所感受到的"松散"其实是一个机会

> **正因为机制可解释性缺乏统一框架，所以"提供框架的人"会有巨大的影响力。**

| 如果你只是做"发现" | 如果你做"收紧" |
|-------------------|---------------|
| "我发现了X特征" | "我提出了一个框架，预测了X特征的存在" |
| 影响：一个数据点 | 影响：一个研究纲领 |
| 可替代性：高（别人也能发现） | 可替代性：低（框架是独特的） |
| 类比：收集标本的博物学家 | 类比：提出进化论的达尔文 |

#### 6.2 你可以做的"收紧"工作

```
方向1：为"发现"提供理论指导
  不是"用SAE看看能发现什么"
  而是"理论预测应该有X，我们用SAE验证"
  → 把发现从"钓鱼"变成"验证"

方向2：为"理解"提供定量框架
  不是"这个回路负责induction"
  而是"这个回路的形成可以用以下ODE描述，
       其临界点由学习率和数据复杂度决定"
  → 把理解从"定性"变成"定量"

方向3：为"控制"提供预测
  不是"我们编辑了这个神经元，行为变了"
  而是"理论预测编辑这个神经元会导致X行为变化，
       实验验证了/否证了这个预测"
  → 把控制从"试错"变成"设计"

方向4：建立"发展可解释性"的子领域
  把三个层次统一在"时间"维度上：
  训练过程中，机制如何逐步形成？
  → 这本身就是"收紧"的工作
```

#### 6.3 一个精确的自我定位

> **你不需要"选择"做机制可解释性还是学习力学。**
> **你可以做的是：用学习力学的语言重新表述机制可解释性的问题。**

```
旧表述（松散的）：
  "我们用SAE发现了'金门大桥'特征，它在层6，
   方向是v，激活强度与输入中'金门大桥'的出现相关。"

新表述（收紧的）：
  "在训练过程中，数据中'金门大桥'概念的频率超过了
   特征形成的临界阈值（由学习率和宽度决定），
   导致在第6层形成了一个线性可表示的特征方向v。
   这个形成事件发生在训练的第N步，
   对应于损失景观中的一个分岔点。"

→ 同样的发现，但有了"为什么"和"预测力"。
```

### 七、总结

| 你的观察 | 我的回应 |
|----------|----------|
| 机制可解释性比学习力学松散 | ✓ 完全正确 |
| 难以形式化概括 | ✓ 因为它是"前范式"阶段 |
| 研究思路和层次不同 | ✓ 因为它混合了发现/理解/控制三个层次 |
| （隐含）这是问题吗？ | 部分是：缺乏累积性和预测力。部分不是：探索阶段的必然 |
| （隐含）怎么办？ | 学习力学可以提供"收紧"的框架，但不能完全替代"发现" |

> 💡 **最精确的一句话**：
> 
> 机制可解释性是**自然史**（收集、描述、分类），学习力学是**理论生物学**（解释、预测、统一）。
> 
> 自然史不是"差的科学"——它是理论科学的**必要前提**。没有达尔文之前几代博物学家的标本收集，就没有进化论。
>
