# 可解释性方法论的统一图景：以残差流为主干

> 为什么可解释性的方法让人感觉「不统一」？本文以残差流为唯一本体论基底，把方法归到四个层次问题：残差流里存着什么（特征/表征）、这些特征长什么形状（流形/几何）、如何翻译成人话（解码）、谁写进去又怎么流动（电路），并画出各方法的逻辑依赖图。

### 壹 · 唯一的本体论基底：残差流

所有方法的共同研究对象，是同一个东西：

$$\mathbf{r}_t^{(\ell+1)} = \mathbf{r}_t^{(\ell)} + \operatorname{Attn}_t^{(\ell)} + \operatorname{MLP}_t^{(\ell)}$$

在标准的Transformer电路框架中，每一层将其贡献写入一个共享向量空间。对于位置$t$、第$\ell$层，残差流表示$\mathbf{r}_t^{(\ell)}$通过每个子层（自注意力和MLP）的加法更新来演化。

注意力层和MLP层都通过线性投影从残差流中"读取"输入，然后通过加回一个线性投影将结果"写入"残差流。

这个方程是所有可解释性方法的共同基底。**所有方法的分歧，仅仅来自于：你想问关于这个方程的哪个层次的问题。**

理解了这一点，那头大象就出现了：

```
残差流 r_t^(ℓ)
    │
    ├── 它里面存着什么？         ← 【特征/表征研究】
    │
    ├── 这些东西长什么几何形状？  ← 【流形/几何研究】
    │
    ├── 如何把它翻译成人话？      ← 【解码研究：Logit Lens / SAE】
    │
    └── 谁写进去的、怎么流动的？  ← 【电路研究】
```

**这四个问题不是并列的替代方案——它们是对同一个对象从不同角度追问的递进层次。**

### 贰 · 第一层问题：残差流里存着什么？（特征/表征研究）

#### 2.1 线性表征假说：最基础的信念

线性表征假说提出，神经网络将有意义的概念编码为激活空间中近似线性的方向，称为"特征"。叠加假说进一步表明，高维激活空间包含许多近乎正交的方向，使模型能够通过将特征打包进重叠子空间，表示超过环境维度的特征数量。

这是**最底层的信念**——几乎所有其他方法都以此为前提。SAE相信它，才去学稀疏方向；Logit Lens相信它，才去做线性投影解码；电路研究相信它，才去追踪方向向量在层间的传递。

线性表征假说（LRH）是许多机械可解释性方法的工作假设。例如，SAE被构建为恢复线性编码的单语义"特征"的超完备基；LRH同样是对比激活引导（activation steering）的基础，它假设单个方向向量直接指向某个概念到其对比面。

#### 2.2 超越线性：几何假说的动物园

但LRH只是一个起点，更精确的几何描述正在发展：

在LRH之外，还有若干更精细的假说，包括框架表征假说（Frame Representation Hypothesis）、格状表征假说（Lattice Representation Hypothesis）和柏拉图表征假说（Platonic Representation Hypothesis）。

这些假说的关系是：**LRH是最粗的近似，越往后越精确，适用范围越窄**。研究者应根据研究对象选择合适的假说层次，而不是争论谁"对"谁"错"。

### 叁 · 第二层问题：这些特征长什么形状？（流形/几何研究）

流形和几何分析，是对"残差流里的东西"做的**形状描述**。它不独立于特征研究，而是特征研究的一个维度。

实证研究揭示了具体的算法机制：grokking沿傅里叶型结构演进，算术通过三角嵌入在螺旋流形上涌现，时空结构通过可识别的神经元编码。

#### 3.1 几何研究与特征研究的关系

这两者的关系是：
- **特征研究**问的是"这个方向代表什么概念"（语义问题）
- **几何研究**问的是"这些概念如何在空间中组织"（结构问题）

它们是互补的：你可以用SAE找出"星期几"这个特征，然后用几何分析发现这个特征在空间中沿圆形流形排列。两者结合，才能得到完整的画面。

#### 3.2 流形的直觉意义

**关键直觉**：流形分析告诉你的是**计算的约束条件**。如果某类概念被约束在低维流形上，那么处理这类概念的电路就必然只在这个低维空间里操作——这反过来约束了你能提出的电路假说的形式。

几何研究是**电路研究的先验**：先知道空间的形状，才能更好地理解计算的路径。

### 肆 · 第三层问题：如何把残差流翻译成人话？（解码研究）

这一层的方法，是在给定"残差流里有东西"之后，问**如何把这些东西读出来**。

#### 4.1 Logit Lens / Tuned Lens：用输出层解码

Elhage等人的框架突出了残差流作为各组件间工作记忆和通信信道的核心角色，暗示了具有不同功能的子空间概念。Logit Lens最初由Nostalgebraist提出，此后被多项解释研究使用和扩展。

Logit Lens的逻辑是：**把中间层的残差流直接用最终的unembedding矩阵投影到词表上**，观察"如果计算在这一层停止，模型会预测什么词"。这是一种**用输出端的线性解码器去读残差流**的方法。

**它依赖的假设**：残差流在中间层已经部分地包含了最终预测所需的信息，且这些信息以线性方式与词表向量对齐。

**它的局限**：它只能读出"接近词表的"那部分信息。残差流里大量以叠加方式存在的、与词表不对齐的特征，Logit Lens完全看不见。

#### 4.2 Probing（探针）：用任务特定的解码器

探针是训练一个小型分类器，在某一层的残差流上预测某个概念是否存在。这比Logit Lens更灵活——你可以问任何问题，只要有标注数据。

**它依赖的假设**：同样是线性表征假说。探针就是在寻找那个方向向量，验证它是否存在。

**探针与Logit Lens的关系**：Logit Lens是用一个固定的、有语义的探针（unembedding矩阵）去解码；普通探针是用一个任务定制的探针去解码。前者的优点是有语义解释，后者的优点是任务灵活。

#### 4.3 SAE：用稀疏字典解码

当许多特征竞争有限的表示容量时，它们可能会缠绕在一起，导致多语义表示。这些假说促使人们使用字典学习，恢复一组基方向，使内部激活可以被重构为特征方向的稀疏线性组合。

SAE的逻辑是：**不用任何外部标签，完全靠无监督的稀疏性约束，从残差流中解压出尽可能多的单语义特征**。

**它依赖的假设**：线性表征假说 + 叠加假说。SAE假设残差流是大量单语义特征的稀疏线性叠加，然后去学这个叠加的字典。

SAE是被训练为将模型内部表示分解为可解释构件的神经网络。当语言模型处理文本时，每一层产生一串数字，编码模型在该位置"知道"的内容。SAE将这些数字重新表达为特征的组合，每个特征对应一个单一的可识别概念。

#### 4.4 三种解码方法的统一关系

```
                    残差流 r_t^(ℓ)
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
     Logit Lens         Probing          SAE
   (词表空间投影)    (任务特定方向)    (稀疏字典解压)
          │               │               │
    "模型此刻在       "某个概念        "此刻激活了
     想说什么词"    是否存在于此"     哪些语义特征"
          │               │               │
          └───────────────┴───────────────┘
                          │
               都是在回答同一个问题：
           "残差流里此刻装着什么语义内容"
               只是解码器的假设不同
```

**关键认识**：这三种方法**不是竞争关系，而是覆盖不同语义频谱的互补解码器**。

- Logit Lens：只能看见"即将说出口的词"——高频、表层语义
- Probing：只能看见你事先想到要问的概念——覆盖面取决于你的想象力
- SAE：可以发现你事先没想到的概念——但受到稀疏性假设的约束

### 伍 · 第四层问题：谁写进去的、怎么流动的？（电路研究）

电路研究是在问：**这些写入残差流的增量$\Delta\mathbf{r}$，到底是由哪些头和MLP产生的，它们之间如何串联**？

#### 5.1 经典电路研究：在组件层面追踪

机械可解释性通过将Transformer内部逆向工程为电路、特征和算法来追求这个目标。Anthropic的Transformer Circuits项目系统地编目可重用的计算子程序。

电路框架确立了Transformer的计算可以被理解为在共享残差流上操作的可解释电路的组合。这一视角将残差流框架为一个通信信道，注意力头从特定子空间读取并写入。

经典电路研究的单位是**组件**：注意力头、MLP层、神经元。电路就是这些组件之间的有向依赖图。

**它的问题**：先前工作中识别的电路由多义性的、难以解释的单元（如注意力头或神经元）构成，使它们不适合许多下游应用。

注意力头是多义性的（一个头参与多个任务），神经元更是严重多义性的，所以经典电路虽然定位了"哪些头重要"，却无法清晰说明"这些头在做什么"。

#### 5.2 稀疏特征电路（Sparse Feature Circuits）：统一电路与SAE的关键一步

稀疏特征电路（SFCs）是Marks等人（2024年）引入的方法，用于识别和分析SAE特征的因果子图，以解释特定的模型行为。这种方法将SAE的可解释性优势与因果分析结合，以揭示语言模型行为背后的机制。

具体做法是：

方法论涉及以下关键步骤：用SAE将模型激活分解为稀疏特征；计算每个特征对目标行为的间接效应（IE）；基于IE阈值识别一组因果相关特征；通过分析这些特征之间的连接来构建电路。

结果就是稀疏特征电路：一个以可解释特征为节点、以因果影响为边的图。SAE的误差项（SAE捕获的内容与模型实际计算之间的差距）在电路中也有自己的节点。

**这是你问的"电路与其他方法的统一"的核心答案**：稀疏特征电路把SAE（特征层面的解码）和电路（因果流动的追踪）**焊接**在了一起。节点是SAE特征（有语义），边是因果影响（有方向）。

#### 5.3 Circuit Fingerprints：统一电路发现与激活引导

Circuit Fingerprints将电路发现和激活引导统一为同一几何结构上的对偶操作——读和写——展示了它们是同一底层结构的两种视角。

**这解决了另一个"不统一"**：为什么activation steering（用一个方向向量直接干预）和电路追踪（找出因果路径）看起来是两套不同的工具？答案是：它们是对同一几何对象的读操作和写操作。

#### 5.4 特征跨层演化：连接电路与几何

为了理解特征如何跨层演化以及模型的决策过程，近期工作提出了特征匹配（feature matching）方法，旨在寻找一个SAE在某一层的特征与另一层SAE特征之间的映射，使得映射特征具有相似的语义含义。

这意味着：**特征不只是静态地"存在于某层"，而是在层间演化**。特征匹配是连接"解码研究（SAE）"和"流动研究（电路）"的桥梁——它追踪的是同一个语义概念如何在不同层的残差流中变形和传递。

### 捌 · 一个深层的认识论问题：为什么感觉不统一

一项新工作尝试将LLM研究中若干不同方向——线性表征假说、概念几何、分段线性细分、基于lens的隐表示阐明以及上下文学习——统一在单一的Laguerre几何框架内。在此过程中，它挑战了两个流行假设：LRH下基于向量的概念定义，以及隐表示缺乏原则性基准真相的问题。

这说明**"统一"本身就是当前领域的前沿开放问题**，没有人完全解决它。你感受到的不统一是真实的——不是因为你理解不够，而是因为这个领域确实处于碎片化的状态。

根本原因在于：**不同方法回答不同类型的问题，而这些问题之间的逻辑依赖关系从来没有被显式地梳理清楚**。上面给出的四层框架，就是对这个逻辑依赖关系的一次尝试性梳理。

### 玖 · 对研究假说的直接启示

这个统一图景对你的研究有三个直接的方法论启示：

**1. 确定你的问题属于哪个层次**
提出假说之前，先问自己：我的假说是关于"存什么"（层次一）、"怎么组织"（层次二）、"如何读出"（层次三），还是"如何流动"（层次四）？不同层次的假说需要不同的实验设计。

**2. 注意层次间的逻辑依赖**
如果你的假说在层次四（电路），但依赖的解码工具在层次三（SAE），你需要先验证SAE的解码质量——稀疏特征电路的误差节点（SAE error term）就是为了追踪这个不确定性而设计的。

**3. 把"不统一"当作研究空间**
SAE特征图谱揭示了特征存在于哪里，但没有揭示特征如何跨网络深度因果交互。理解特征间的因果关系是机械可解释性的核心问题。——层次三（解码）和层次四（因果流动）之间的gap，正是当前最大的研究机会。

这个问题问得极好——它触碰的其实是一个**科学哲学层面**的问题，而不只是技术问题。让我认真回答。

## "研究残差流"这件事，到底trivial不trivial？
