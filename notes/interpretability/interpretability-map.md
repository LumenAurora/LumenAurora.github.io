# 可解释性研究的全景框架

描述性，因果性，功能性
本质目标是把叠加压缩的拆开并且实现精准干预，无论是残差向量还是权重矩阵。
注重case study，先尝试简单方法，如提示、阅读思维链或训练线性探针。
可解释工具：可解释费劲的点在于驾驭复杂，如果能够帮助人更高效地分析就好了。因果性是最难的，包括每个token或者注意力的因果，需要做梯度或扰动，《Real-Time Visual Attribution Streaming in Thinking Model》就想到用模型来预测注意力因果。大规模宏大的可解释工具-SAE（产生稀疏化的特征feature）、transcoder（简化MLP用的）、归因图（attribution graphs）、QK attributions（Anthropic系列在稀疏特征上额外训出的简化网络），《Sparse Weight Decomposition for Efficient Circuit Extraction》将权重矩阵分解为两个稀疏矩阵。
测量量：注意力，token归因，残差几何、logit-lens、probe，熵、不确定性
注意模型架构区别：MoE架构增添了对专家路由的研究（《Seeing but Not Thinking: Routing Distraction in Multimodal Mixture-of-Experts》），有些VLM有特殊的attention处理会影响注意力分析
研究对象与干预手段：token归因-关键token干预，注意力头-利用头的能力
针对注意力分析：注意力只是相关不是因果，所以干预实验是有必要的，尽管成本更高。另外，尽管平均注意力可以反映模型一部分的观察，但是可能会更为混乱，有些特定的注意力头对于信息提取会更好。
可解释性的系列研究：发现一个神奇现象——分析行为层面原因（输入输出，CoT文本）——分析向量静态表示层面原因（存在一个特殊方向）——分析注意力的动态原因（随层与时间步的变化，knock out特定查询的注意力）——电路分析——这种特殊方向或者注意力结构是如何在训练中形成的、训练时为啥没有学到其他可能甚至更符合直觉的可能——如何改进（推理时，训练时，即插即用）。推理可解释以及定性一次性观察的学习力学（什么比较好训，空间正交性等）都可以用来原因分析。
正确性：跨架构跨模型，即使是你主打即插即用方法也得先指出问题对于不同模型普遍存在，否则会被质疑模型版本问题；测试性能一定要用知名度高的公认榜，改评分协议格式都是不合理的；启发式规则效力有限，需要用因果加强证据。
数据生成：用YOLO去标物体位置，然后看注意力区域与YOLO框的重合程度。
需要考虑到模型的能力是被训练出来的，而各家模型都有异构性和绝活，尤其是后训练各家都不一样，所以CoT的风格不大一样，有的时候机制泛化性就难。而且后训练属于是哪里不行点哪里，出了小问题用后训练增强一下即可，比如之前的strawberry几个r、VLM counting。
注重case study，否则就是瞎猜，尤其是CoT之类的设计了一大推消融实验、但是应该先看一看文本语义层面是不是符合你的假设。多进行最详尽的可视化，比如注意力时间步和层都表现出来，形成为网格。
1. **信息存在**：从激活中能读出真/假；
2. **模型使用**：改变该信息会改变模型答案；
3. **机制解释**：我们知道哪些组件以什么顺序完成了计算，并能预测新条件下的行为。
假设probe能从第20层激活预测图片中物体数量。要证明VLM在回答计数问题时真正使用该数量表示，还需要：
- 在图像只改变数量、文本保持相同时，probe值按方向改变；
- 干预该表示会特异性改变计数答案；
- 干预无关方向不会产生同等损害；
- 把正确数量表示恢复进去能恢复答案；
- 该机制能预测未用于发现的新计数任务。
研究：先确定一个模糊的领域，比如研究9B模型比2B模型多出了什么，为什么能力会强。探索阶段——关注一切可以关注的奇怪细节和能拿到的信息，没有计划没关系，走一步看一步，看data、定量结果、定性结果、case study。研究阶段——提出假说并进行严格的实证。小研究可以只做一个模型观察，但是发表的研究必须要做多个模型。比较也能提升研究的质感。
目前大模型可解释性文章主要以下几类：1.研究表示向量如何解读，有语义化、稀疏化特征、表示几何学。2.研究注意力的动态演化。3.研究注意力头（QK电路看哪了，OV电路写什么）和MLP的电路分析。4.稀疏化+电路分析，SAE特征电路。还有新增一种对比不同模型（比如大模型和小模型、稠密网络和剪枝后的稀疏网络等等）的搜索空间。
分解是interpretability的核心策略
可解释论文如果跟进有两种思路，第一种是说前人是相关性、我们是因果性、再推进一步，第二种是推翻前人、认为贡献原因不大、还有更重要的原因。可解释分为两个目标，一个是针对模型组件逆向为人类可理解的对象以实现模型编辑，另一个是建立输入到输出更为细粒度的因果解释以实现推理干预。是针对推理时研究，研究为什么该输入会导致该输出，输出性能被什么影响了。认同前人的研究就得构建对大模型的直觉理解，不认同的话就得拿某个现象驳倒、建立新的理解。
单纯做实验与学习是两码事，对于AI来讲可能可以执行实验，但是让它教人需要好好提问。所以最好自己先看本领域的综述，然后再让AI挑一些与课题紧密相关的论文，节约精力。理论的终极目的是为了预测，通过预测结果来验证是否证伪。
共识假设：线性可表示性、稀疏性、局部性、组合性。（可以挑战它们了！）目前可解释性还更多的是静力学而非动力学。可解释往往关心将大模型的机制用语义化或者人类能够理解的方式找出来，或者寻找一些任务对应的组件从而可以进行模型编辑。
不同抽象层次：学习力学与学习理论（物理学和化学），机制可解释（生物学），行为可解释（心理学）。不仅对于模型，数据理论也很重要。测量科学，经验科学，理论科学。而且还需要统一，有的术语界定不清晰，大家各说各的，甚至还会有貌似矛盾的结论得出。
大模型要素：token，attention，MLP，residual flow
可解释性：有训练（需要数据）vs无训练（直接看权重）。不同微观层次。就是看关联，做改变看影响。
训练动力学，Scaling law
按任务：感知任务，推理任务，自省任务；单任务，复杂任务，一心多用的多个无关任务。好的输入能够观察到神奇的现象。
按组件：VLM-vision encoder，projector，LLM backbone，残差流、token表征，神经元、神经元电路、神经元拓扑图，attention数值，注意力头，位置编码，MLP，生成动力学，预训练与后训练
按推理时动态：单步前向传播，多步自回归动态；prefill阶段，CoT阶段，回答阶段。我们需要意识到即使是一个元件也是高维张量，因为有层数、推理生成到哪一步这两个必然的变量，而且比方说注意力还有多头注意力、不同token，不同的切面来观察会有不同的研究路径。
世界模型：VLM隐状态里有信息，但模型嘴上说不出来。将大模型的高维向量视为一种思维空间，像是内部的想法、全局的意识空间，中间层像草稿纸，模型需要在不同层不断执行各种任务，用lens可以查看语义化的解释。而注意力层整合token信息、MLP recall事实信息，在这个草稿纸上不断书写，不过草稿纸似乎每一时刻都有几个核心关注的概念，这就是全局意识空间。隐状态算是一个小的草稿纸，然后CoT之类的写出token来是模型学会了利用文本打草稿而不是仅仅靠心算。表征和注意力都会随着自回归的过程不断演化，在单次前向传播过程中不同层也不同。所以要想象模型自回归推理的过程，要用动态演化的视角来看一次自回归发生了什么，不断进行自回归发生了什么，这两种思路不完全一样，这样才深刻。单看表示以及token的演化，拟人化相当于模型正在处理任务。而一次前向传播的过程就是一个阶段，在不同层处理着不同的任务，attention汇合上下文信息，MLP汇合固有知识能力，CoT和堆层数都是把大任务拆解为小任务，给模型足够长的机会和步骤来完成大任务，甚至模型可以用交替的方式来模拟并行处理任务。可解释的作用就是静态方面分析模型哪一部分提供了哪些信息，动态方面分析推理进程中模型何时需要哪些信息。事实上，我们需要意识到，VLM相当于在LLM上拼装，而CoT是在本来的推理动态上拼装，对于新装上去的东西应该研究它在其中是如何工作的，它对性能的影响是怎样实现的。VLM的LLM经过对齐后，增加了处理视觉信息的能力，也是值得关注的。平均后的残差流有助于识别抽象的模型表示，例如[人格向量（persona vector）](https://www.anthropic.com/research/persona-vectors)。Anthropic很喜欢搞念头vs文本，也就是模型想到什么和模型输出什么的区分；这个挺重要的，因为只从答案输出角度也判断不了，比如一个程序都实现了完美排序，但一个是快速排序一个是冒泡排序，时间复杂度不一样，但是我们的观测太粗糙了，混淆了。
有没有发现，attention是交互对应层的以前时间步生成的token的KV cache，但是每次最后一层都要经历采样变为token，然后重新做标准的词嵌入进行下一轮循环，也就是最后一层斩断了不同时间步的残差流继承关系，因为残差流生成的表征是远远多于标准词嵌入的。于是，latent CoT的创新点是跳过了最后一层采样变为文本token然后重新嵌入开始这一步，跳过了最后一层隔断不同token残差流的一步，使得残差流可以轻松地跨着不同token流动，使得不需要每次都需要从头开始混合视觉信息，减轻了attention的压力。不过，代价就是这玩意儿你没觉得有点像RNN吗，也就是token和token之间产生了时序的依赖关系，训练的时候没法用teacher forcing并行。从信息的角度来考量，信息的来源就是输入和模型的权重本身，模型的权重矩阵存储了很多信息，可以写入到残差流中，也可以读取残差流中的信息、读取是投影到一个子空间所以有所谓读取方向问题，《Gathered, Not Admitted: How Attention Brings a Latent Variable into Verbalizable Form》就在区分信息到底是有无还是扩大幅度，前者认为某一步是把信息旋转了一下对齐方向、收音机调频，后者认为是某一步是增幅器。
一个诡异但极其有用的事实是：我们对残差流的所有读写操作都是**线性**的——写入是通过加法，读出是通过应用线性映射来获得各层的输入。这极其重要，因为这意味着你能把残差流看作是所有层输出的总和，进而把任何一层的输入，分解成来自网络中不同组件的一系列项的和。残差流的重要之处在于，信息不必经过每一个层，模型可以选择只走其中几个层，其余信息则通过残差连接“直通”。模型利用残差流实现不同组件间的“组合”。模型每一层或每个组件，从残差流中“投影”（我不喜欢“读”这个词）信息，并“嵌入”（不喜欢“写”）回残差流。“读”和“写”直觉上像一对逆操作，实则大相径庭。“投影”是从残差流这个大空间映射到头的内部小维度，大部分方向的信息会被丢弃，头只能聚焦在少数有意义的方向上。除非完全正交，一切信息都会对头有些微影响。“嵌入”是从小空间映射回大空间，本质上是在残差流中选择一组方向，并把信息写入。未来组件可以选择去读那些写入的方向来获取信息。我们认为，模型在 768 维残差流里压缩了远多于 768 维的特征，这就是“叠加”。这在另一篇关于叠加的玩具模型论文里有详细阐述。大致意思是：假如我想把 10000 个向量压缩进 1000 维空间，想完全保持线性无关或正交是不可能的。但如果能接受向量之间的点积虽非零但很小，就能塞进多得多的向量。这和随机矩阵理论有关，能在 N 维空间存指数级数量的向量。
矛盾：模型的残差流的隐状态想法和它最终表达成token的显式想法，有了CoT之后更加复杂；注意力放置的位置vs这个注意力真正起到的效果。
心理学：角色扮演是需要的，那是因为后训练让模型扮演一个助手（assistant）的角色。
静态解读：向量减去某种中性的白噪音底子，比如减去一批随机词的激活均值。
用魔法打败魔法：残差流本身很复杂，那应对复杂的就再引入一个黑盒，微调一个LLM去解读它。
尊重复杂：我们对单次前向传播内的残差流已经有了相当的理解，但对**跨越多个token、多个推理步骤、多轮对话的动态演化**几乎一无所知。SFT和RLVR的发育可解释性研究不是很充分。
对于LLM的手法，我们解读残差流可以还原为词元；那对于VLM的LLM backbone也能这么干吗，它处理视觉信息的方式也是以语言的形式吗，虽然投影对齐过，但是这个backbone视觉微调过程是增加了视觉能力的，logitlens还奏效吗，视觉信息从哪里来（此处残差vs token残差）、视觉信息是用什么方式被处理的。

rebuttal
1. **因果归因要做"双向验证"**：不仅证明"A错→输出错"，还要证明"A对→输出对"且排除语言bias
2. **主动声明scope limitation**：与其让审稿人质疑"为什么不做复杂关系"，不如在Introduction就定义清楚"本文聚焦基础空间关系的线性机制"

注意力：注意力数值，干预注意力-knocking out。《LVLM-Intrepret: An Interpretability Tool for Large Vision-Language Models》

probing：在Transformer各层的残差流上训练线性分类器，测的是大模型各层残差流，目的是观察特定信息（如图像实体类别）在哪个层级出现，属于**相关性分析**。

patching：将干净样本的特定层激活值替换到腐样本的前向传播中，测的是VLM早期层，目的是通过观察输出是否恢复正确来严格验证该部位的因果作用，是区分相关与因果的**金标准**。

**Attribution disturbing（归因干预）**：通过对输入嵌入加入高斯噪声构建腐样本，计算KL散度损失对中间层输出的梯度，测的是大模型各子层（MLP/Attention），通过梯度和激活差值的乘积快速估计各层对输出的因果贡献度。

因果性：
第三层：反事实（Counterfactuals）
  "如果当时没做A，B会怎样？"
  → 想象、反思、归因

第二层：干预（Intervention）
  "如果我主动做A，B会怎样？"

第一层：关联（Association）
  "看到A时，B的概率是多少？"
  → P(B|A)，被动观察

如果你想使用SAE，请使用Gemma 3和Gemma Scope 2。
Dictionary learning library：一个比SAELens更可破解、更精简的替代方案。如果你想做任何不寻常的SAE训练，我推荐使用这个而不是SAELens。
Qwen 3.5和3.6系列是良好的默认模型，尤其是密集型号如4B、9B和27B，它们质量相当高。  
如果你想对高能力模型进行可解释性研究，deepseek v4 flash 0731是个好选择，你可以在这里找到它的J-Lenses。
