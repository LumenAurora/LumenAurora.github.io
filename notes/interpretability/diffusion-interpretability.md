# 扩散模型的可解释性

### 零 · 最高层的认知重置：扩散模型和LLM是根本不同的计算范式

在建立任何直觉之前，必须先做一个认知重置。因为**把LLM的直觉直接搬到扩散模型上，是可解释性研究中最危险的陷阱**。

| 维度 | LLM | 扩散模型 |
|---|---|---|
| **推理轴** | 自回归：token一个一个生成，时间轴是序列 | 去噪：从噪声到图像，时间轴是噪声水平 |
| **"隐状态"** | 残差流：高维向量，层间累积叠加 | 双重隐状态：噪声图像$x_t$（外部）+ 去噪网络内部激活（内部） |
| **信息流** | 单向：从输入token到输出token | 迭代：每步去噪都重新过一遍整个网络 |
| **条件融合** | 统一的注意力机制 | 分离的：cross-attention融合文本，self-attention处理图像内部结构 |
| **"思考"的类比** | 每层是一个计算步 | 每个去噪时间步是一个计算步，每步内部还有层级结构 |

在扩散模型中，潜变量$x_1,...,x_T$不是数据的低维抽象——它们与观测变量$x_0$共享同样的维度，代表其逐渐加噪的版本。扩散模型的潜空间对应的是不同的噪声水平，而非语义压缩。

**这是理解扩散模型可解释性的第一块基石**：扩散模型有**两种完全不同意义的"隐空间"**，混淆它们会导致所有后续分析出错。

---

### 壹 · 扩散模型的两种隐空间：必须区分清楚

#### 1.1 第一种隐空间：噪声轨迹空间（外部的、跨步骤的）

扩散模型由两个紧密耦合的过程构成：前向扩散过程$q$逐步向数据添加噪声；反向去噪过程$p_\theta$学习逐步移除这些噪声。前向过程由设计固定，反向过程由神经网络参数化并从数据中学习。

这个噪声轨迹空间$\{x_T, x_{T-1}, ..., x_1, x_0\}$是**扩散模型独有的、LLM完全没有对应物的结构**。

**直觉图像**：想象一张照片被逐渐覆盖雪花——$x_T$是完全被雪覆盖（纯高斯噪声），$x_0$是清晰的原始照片，中间的$x_t$是部分被雪覆盖的状态。采样/推理就是**逆着这个过程，从纯雪开始，一步步擦去雪花，露出下面的图像**。

关键认识：由于DDIM的确定性，可以在潜变量中做语义上有意义的插值。这意味着这个噪声轨迹空间本身就具有语义几何结构——两张图像的中间噪声状态，对应的是两张图像语义上的"中间"。

#### 1.2 第二种隐空间：去噪网络的内部激活（内部的、每步之内的）

每执行一步去噪，都要把当前的$x_t$送入去噪网络（UNet或DiT），网络内部产生的所有激活，构成了**第二种隐空间**。

一个被称为"h-space"的扩散模型语义潜空间，可以以类似GAN的方式支持语义图像编辑。h-space由去噪网络在扩散过程所有时间步上的瓶颈层激活构成。

这个内部激活空间——特别是h-space——才是扩散模型可解释性研究的主战场，相当于LLM中的残差流。

### 贰 · 去噪网络的架构：两种主要范式

#### 2.1 UNet：空间层级的信息处理器

扩散模型利用UNet架构在每个时间步预测噪声或其他信号。这个UNet包含编码器和解码器在不同分辨率（从8×8到64×64）上的多个块，每个块都有残差块、自注意力和交叉注意力模块。

UNet的空间层级结构，使其具有独特的**多尺度语义组织**：

已有研究揭示了UNet中注意力块的功能分工：**高分辨率块主要聚焦于细节提取，而中低分辨率块对应于布局结构和语义理解**。后续工作进一步表明，UNet在不同去噪时间步上也以不同粒度关注特征。

**直觉图像**：UNet像一个沙漏——进去的时候把图像压缩到越来越小的空间（编码器），出来的时候再逐步放大（解码器）。最小的那一层（瓶颈层，bottleneck）是语义最浓缩的地方，越靠近输入/输出的层处理越细粒度的纹理。

#### 2.2 DiT：Transformer的到来与新的可解释性挑战

在DiT（Diffusion Transformer）架构中，VAE潜空间被分块为token序列，由堆叠的Transformer块处理；每个块对文本token应用交叉注意力，时间步条件通过共享的adaLN注入。

DiT的出现带来了新的可解释性机遇：探索DiT架构中的交叉注意力机制，提供了对基于扩散的模型可解释性的关键洞察。但也带来了新困难——UNet的空间层级结构消失了，h-space的概念需要重新定义。

### 叁 · 扩散模型的双重注意力：可解释性的两个主战场

这是扩散模型可解释性中最重要的分工，与LLM的单一注意力体系截然不同：

#### 3.1 Cross-Attention：文本如何"指导"图像

cross-attention图谱在Stable Diffusion中通常包含物体归因信息（哪个词对应哪个图像区域），而self-attention图谱则在变换过程中对保留原始图像的几何和形状细节起关键作用。

通过修改少数几个cross-attention层中的文本输入，可以稳定地改变风格、物体或事实等属性——这说明视觉属性的知识被定位在了特定的cross-attention层中。

DAAM方法通过在去噪子网络中上采样并聚合cross-attention的词-像素分数来生成像素级归因图，直接把文本token的影响力可视化为图像上的热力图。

**直觉图像**：Cross-attention是**文本的手**——文本中的每个词通过cross-attention"触摸"图像的某个区域，告诉那个区域"你要生成什么样的内容"。DAAM就是可视化这只手在图像上的触摸痕迹。

#### 3.2 Self-Attention：图像内部的结构组织

Self-attention在图像内部的patch之间建立关系，负责**结构一致性和形状保持**。

自注意力层分析图像内部的关系结构；cross-attention层将文本与视觉元素连接，使模型能够解释文本提示并将其翻译为连贯的图像。

**两种注意力的功能分离**正是扩散模型图像编辑的核心机制：想改变**内容/语义**，操纵cross-attention；想改变**布局/结构**，操纵self-attention。这在LLM中没有对应物。

### 肆 · H-Space：扩散模型的"残差流类比"

#### 4.1 H-Space的基本性质

H-space中的特征图具有最低的空间维度/分辨率和最多的通道/高层语义。因此，h-space是编码紧凑且语义有意义信息的最佳位置。H-space具有三个关键性质：语义方向跨样本泛化、方向幅度控制编辑强度、多个方向可以线性组合实现多属性操控。

UNet瓶颈特征（"h-space"）已被证明充当语义潜空间，支持线性的、可解释的编辑。

这三个性质，正是LLM残差流的线性表征假说在扩散模型中的对应物：**方向可解释（特征是方向向量）、强度可控（方向的幅度）、可线性叠加（多属性同时编辑）**。

#### 4.2 H-Space的SAE分析：概念的涌现与演化

最新的2025年NeurIPS Spotlight工作直接将SAE框架应用到扩散模型：

研究者利用SAE框架探索文本到图像扩散模型的内部工作机制，在激活中发现了多种人类可解释的概念。研究发现，**甚至在第一个反向扩散步骤完成之前**，通过观察激活概念的空间分布，就可以非常准确地预测场景的最终构成。

在一步蒸馏的SDXL-Turbo扩散模型的激活上训练SAE，证明了SAE可以在模型特定块中检测到可解释特征，并对其进行因果干预。

**这是一个极其重要的发现**——它意味着扩散模型的"决定"（最终会生成什么）在去噪过程的极早期就已经在内部隐式确定了，后续步骤更多是细节的精化而非全局构成的改变。

#### 4.3 H-Space在不同去噪步骤的语义变化

尽管h-space提供了语义上有意义的表征，但在标准扩散生成过程中直接观测到的激活是有噪声的，且高度依赖于去噪时间步。**不同时间步编码不同的语义尺度：早期时间步影响更粗粒度的属性，而后期时间步聚焦于高频成分。**

这揭示了h-space的一个关键特性：它不是时间步无关的静态空间，而是随去噪进程**动态变化的语义空间**。

### 伍 · 去噪时间轴的语义阶段结构：最核心的直觉

这是整个扩散模型世界模型中**最重要的直觉**，也是与LLM层级结构最直接的类比。

#### 5.1 三阶段模型：从全局到局部

扩散模型在早期去噪步骤中预测语义元素，然后将其扩散到更大范围用于细节处理。

在每个去噪步骤中，模型预测不同的视觉概念来生成最终的高保真图像——不同时间步对应不同的视觉概念。

更精确地，整个去噪轨迹可以划分为三个功能性阶段：

```
去噪时间步：  T（纯噪声）────────────────────→ 0（清晰图像）

阶段一（早期，高噪声水平）：
  → 全局构成决策（场景中有什么，在哪里）
  → 颜色和亮度的总体分布
  → 最粗粒度的语义内容
  → SAE特征：场景级别的概念（"室内场景"、"人物"）

阶段二（中期，中等噪声水平）：
  → 物体间关系和空间布局
  → 物体类别和属性的具体化
  → 文本-视觉对齐的精化
  → SAE特征：物体级别的概念（"椅子"、"蓝色"）

阶段三（后期，低噪声水平）：
  → 纹理细节和高频信息
  → 边缘、材质、光照的精化
  → 与提示的细粒度一致性检查
  → SAE特征：纹理级别的概念（"木纹"、"皮肤纹理"）
```

#### 5.2 UNet空间层级 × 去噪时间步：二维的语义组织

这是扩散模型可解释性特有的、比LLM更复杂的结构——信息组织在**两个独立的轴**上：

研究者分析了丰富的视觉语义信息如何在不同扩散架构的不同层和去噪时间步中被表征，并通过k-SAE揭示出单语义可解释特征。

研究揭示了语义视觉信息如何根据测试数据集的表征粒度，在不同扩散层、去噪时间步、模型架构和预训练数据中以不同方式打包。

**直觉图像**：把扩散模型的信息组织想象成一张**二维地图**：

```
        去噪时间步 T→0
        粗粒度←────────→细粒度
        
UNet    编码器  ────── 局部纹理特征
层级    瓶颈层  ────── 全局语义特征（h-space）
        解码器  ────── 空间结构特征
```

任何对扩散模型的可解释性分析，都需要在这个二维地图上定位自己：**你在研究哪个时间步、哪个层级**？

### 陆 · 采样过程的可解释性：去噪是一个决策序列

#### 6.1 分数函数（Score Function）：每步去噪的物理本质

理解采样的可解释性，需要先理解每步去噪在数学上做了什么：

利用条件和无条件扩散核估计之间的差异，可以有效地将反向过程引导到条件下更可能的样本。使用Tweedie公式，去噪模型可以近似条件和无条件分数函数$s_\theta(s_t, t, x) \approx \nabla_{s_t}\log p(s_t|x)$。

**直觉图像**：分数函数就是在噪声空间中的**梯度场**——它告诉你从当前位置往哪个方向走，能更快地到达高概率的（清晰的、符合提示的）图像区域。每步去噪就是沿着这个梯度场走一步。

#### 6.2 分类器自由引导（CFG）：条件与无条件的拔河

CFG是文本到图像生成中最重要的推理时控制机制，其可解释性意义深刻：

**条件分数** = "符合提示的图像方向"  
**无条件分数** = "任意真实图像方向"  
**CFG** = 无条件分数 + 引导强度 × （条件分数 - 无条件分数）

这个公式的直觉含义是：**CFG在语义方向上放大了条件信息的影响**，就像是用放大镜把提示的效果放大了。引导强度越高，越严格地遵循提示，但代价是降低多样性和可能产生失真。

#### 6.3 采样作为马尔可夫决策过程：推理时控制的新视角

从相同的预训练去噪器和标准反向过程出发，学习到的采样策略可以决定何时加强引导、何时注入随机性、或何时回到早期噪声水平。这个视角至关重要：**去噪器本身没有被修改，但去噪过程中走过的轨迹被改变了。**

**直觉图像**：去噪器是固定的地形（梯度场），而采样策略是在这个地形上走路的方式——同样的地形，不同的步法，会到达不同的地方。这为推理时干预提供了一个完全独立于模型权重的控制维度。

### 柒 · 扩散模型的可解释性工具箱：与LLM工具的对比统一

现在可以把扩散模型的工具与LLM工具进行系统性对比：

| LLM工具 | 扩散模型对应工具 | 对应关系 |
|---|---|---|
| **残差流** | H-space（UNet瓶颈激活） | 最语义浓缩的内部表征 |
| **SAE（特征解压）** | SAE on UNet/DiT activations | 从激活中解压出单语义视觉概念 |
| **Logit Lens** | 直接解码$x_0$预测 | 在每步去噪后预测最终清晰图像 |
| **Probing** | 视觉属性分类器（性别、风格等） | 在特定层/时间步探测特定属性是否存在 |
| **Activation Steering** | H-space方向加法 | 向h-space中添加语义方向向量实现属性编辑 |
| **电路追踪** | 层/时间步的因果消融 | 找出哪些层/时间步对哪些视觉属性负责 |
| **归纳头** | 暂无直接对应，电路研究刚起步 | **当前最大的研究空白** |

通过几何和稀疏性视角检视扩散模型的内部表征，已经在U-Net瓶颈中识别出语义潜空间，并通过SAE将模型激活分解为可解释特征——但从电路层面理解扩散模型如何实现离散计算规则，目前尚无系统性工作。

### 捌 · 与LLM的根本性结构差异：三个核心不对称

理解了扩散模型的整体图景，现在可以精确地描述它与LLM在可解释性维度上的三个根本性差异：

#### 差异一：两个时间轴 vs 一个时间轴

LLM的推理有且只有一个时间轴：**自回归序列**（token的生成顺序）。

扩散模型有**两个独立的时间轴**：
1. **去噪时间轴**（$T \to 0$）：噪声水平的变化，每步都是完整的网络前向传播
2. **网络层级轴**（浅层→深层）：每步去噪内部的UNet/DiT层级

这两个轴都有独立的语义意义，且语义内容在两个轴上都会变化——这是LLM研究者最容易忽视的核心差异。

#### 差异二："迭代精化"vs "单向累积"

LLM的残差流是**单向累积**的——每层写入的信息永久保留，永远向前流动。

扩散模型的去噪过程是**迭代精化**的——每步去噪得到的$x_t$是下一步的完整输入，不存在"累积"的概念，只有"精化"。每一步去噪后的状态是完全独立重算的，而不是在上一步的基础上叠加。

扩散模型的内部机制，尤其是在整个生成过程中内部表征的演化，在很大程度上仍然是一个谜。

#### 差异三："叠加压缩"问题的形式不同

LLM的叠加问题：太多概念被压缩进同一个高维残差流，概念以非正交方式叠加。

扩散模型的叠加问题：扩散模型有时在叠加状态下生成多语义词（"薛定谔的猫"现象）。这是在**生成过程**中的叠加——模型在某个中间步骤可能同时"考虑"多个语义可能，在后续步骤才坍缩到单一含义。

### 终 · 一句话的整合，以及对研究者的最终提示

> **扩散模型是一台在双轴坐标系（时间步轴×层级轴）上工作的迭代精化机器：去噪时间步决定了语义的粗细粒度，UNet层级决定了空间的整体与局部；文本通过cross-attention在每步每层"触摸"图像的不同区域，而图像的全局语义在极早期步骤的瓶颈层h-space中就已暗中决定，后续步骤只是这个决定的逐步物质化。LLM的残差流是时间累积的河流，扩散模型的h-space是每步重画的草图——前者叠加，后者精化；前者有记忆，后者只有当下。**

对可解释性研究者的最终提示：尽管已有大量研究，对文本到图像扩散模型中特定组件所学习的具体功能和特征的详细解释仍然非常有限。目前没有工作从电路层面对扩散模型如何实现离散计算规则给出机制性解释。这意味着扩散模型的可解释性研究，**远比LLM的可解释性研究更原始、更开放**——这既是困难，也是机遇。

## 单步去噪的内部世界：架构、表示与可解释性的分叉路口

> **核心追问**：扩散轨迹的时间步演化已有清晰图像，但当我们"放大"到单个时间步，问：**这一步里，神经网络究竟做了什么？** 此时架构的差异性浮现，内部表示的问题变得核心，而这正是扩散模型可解释性与LLM可解释性真正汇流之处。

---

### 一、问题的重新定位：从"轨迹"到"截面"

前文讨论的是扩散过程的**纵截面**——沿时间步 t 演化的语义涌现。但现在我们切换视角，看**横截面**：在某个固定的时间步 t，当带噪潜变量 $x_t$ 进入去噪网络，到输出噪声预测 $\hat{\epsilon}_\theta(x_t, t, c)$ 这段时间里，**网络内部发生了什么？**

这个问题与LLM可解释性的核心问题高度同构：
- LLM问：token进入Transformer，经过注意力头和MLP，如何涌现出"知识"和"推理"？
- 扩散模型问：含噪图像patch进入去噪网络，如何涌现出对"应该消除什么噪声"的判断？

然而，尽管扩散模型取得了巨大的实证成功，将噪声逐步转化为语义丰富图像的内部机制在很大程度上仍然不透明。理解扩散模型如何执行这一逐步转化，是提升其可靠性、可控性和安全性的关键开放性挑战。

**关键的认识论转折**：这一差距在很大程度上源于扩散模型对不同去噪层级的潜在空间变换的依赖，这使得分析其内部机制的工作变得复杂。特别是，对这些模型内部潜在激活的理解几乎没有获得关注，留下了我们解读其过程能力上的重大空白。

---

### 二、架构决定了"内部世界"的形状：U-Net vs DiT vs MM-DiT

这是问题的核心：单步去噪并非在真空中进行，它由**架构**具体实现。不同架构，内部信息流的拓扑结构截然不同，因此"内部表示"的含义也根本不同。

#### 2.1 U-Net：层次化的空间归纳偏置

U-Net是扩散模型的第一代骨干。其核心特征是**编码器-解码器结构+跳跃连接**，形成了天然的空间层次。

在U-Net中，中心"瓶颈"层提取语义内容特征，而较早的层学习风格特征。

这一分工在空间上是**明确的**：

- SD-1.5（U-Net架构）的 `bottleneck`、`up_ft0`、`up_ft1` 层以不同粒度捕获空间局部化信息，而DiT特征在不同块之间则缺失这一性质。

这引出了U-Net最重要的可解释性发现——**h-space**：

- 扩散模型存在一个语义潜在空间，被称为"h-space"，它由DDM去噪器在扩散过程所有时间步上的瓶颈激活所构成。

- 对扩散模型语义潜在空间属性的详细分析验证了其**均匀性、线性性、鲁棒性以及跨时间步的一致性**。

- 研究观察到，由U-Net瓶颈层定义的 H 空间展现出局部线性结构。这使得我们可以在 H 上采用欧式度量。

进一步，扩散模型被训练为在每个扩散时间步 t 从潜变量 $x_t$ 中推断噪声 $\epsilon_t$。每个 $x_t$ 在不同 t 时具有不同的内部表示 $h_t$，即U-Net的瓶颈表示。

我们考虑切空间之间的线性映射 $T_x \to T_h$，这一线性映射可由雅可比矩阵 $J_x = \nabla_x h$ 描述，它决定了向量 $v \in T_x$ 如何被映射为向量 $u \in T_h$，通过 $u = J_x v$ 实现。

**直觉总结（U-Net）**：U-Net的单步去噪内部，是一个**从空间细节到全局语义、再从全局语义返回空间细节**的信息漏斗。瓶颈就是"思考"发生的地方，跳跃连接是"记忆"的通道。

---

#### 2.2 DiT：等向性的Transformer，空间层次消失

与使用卷积U-Net网络的扩散模型不同，DiT使用Vision Transformer块作为去噪模型。Transformer将图像的潜在patch（由VAE编码器生成）作为一系列输入token处理，配以与ViT相同的位置嵌入。

与U-Net骨干不同，这种patch化允许一种类似Vision Transformer的**等向性Transformer结构**，舍弃了显式的空间层次。每个patch嵌入与正弦位置编码相加。

这意味着：DiT的"内部世界"不再有U-Net那样的空间归纳偏置。这使得模型能够在图像扩散过程的每一步利用自注意力来捕获全局上下文。

但这带来了新的可解释性挑战：尽管可解释性技术已在U-Net框架下得到大量开发，类似的工作在DiT中几乎缺席。更广泛地说，扩散模型的可解释性研究显著落后于GAN，尽管扩散模型在生成建模中的地位日益突出。

DiT引入了一个关键机制——**AdaLN-zero调制**，用于将时间步 t 和条件信号注入每个Transformer块：

DiT利用AdaLN-zero调制来注入全局条件，类似于U-Net的AdaGN。它在使用RF（Rectified Flow）公式时在潜空间生成中被证明特别有效。

**这正是单步去噪的时间感知机制**：网络通过AdaLN不断被"提醒"当前处于哪个噪声水平，从而调整其内部计算。

---

#### 2.3 MM-DiT：双流架构，文本与图像在关注中相遇

最前沿的架构（Stable Diffusion 3、FLUX）采用了**双流MM-DiT**，这是目前最值得关注的单步去噪内部结构：

多模态扩散Transformer块（MMDiT Block）是现代最先进扩散模型的基本架构单元。MMDiT块通过统一的时间条件自注意力机制，在拼接的潜在token序列上融合来自多种输入模态的信息。

**双流的具体工作方式**：

FLUX通过引入两种专门的块类型扩展了MM-DiT：双流块（Double-Stream Block）和单流块（Single-Stream Block）。双流块对文本和图像token使用独立的Q、K、V投影矩阵和调制层；而单流块则在两种模态之间共享这些层。FLUX在前19层采用双流块，在余下38层采用单流块。

在双流块中，图像特征 z 和文本嵌入 e 通过不同的线性、缩放和归一化层分别处理，之后被拼接并通过注意力操作。在单流块中，图像特征和文本嵌入由相同的Transformer处理。

**单步去噪时的跨模态交互问题**：

目前仍缺乏理解语义信息如何在去噪步骤间传播、以及文本与图像表示如何在双流MM-DiT架构内部交互的工具。现有方法仅提供部分洞见：注意力图只能展现token交互的有限视图，而稀疏自编码器虽然可以发现可解释特征，但无法直接揭示这些特征如何通过非线性MLP层被变换和组合。

在双流块和单流块中，模态之间都没有特权化的跨注意力路径，这使得"文本与图像在哪里相遇"这一问题变得非平凡。

这揭示了MM-DiT可解释性的核心困难：**文本-图像融合是分布式的，不在单一层，而是在整个注意力操作中涌现。**

---

### 三、单步内部的信息流：注意力头做了什么？

#### 3.1 注意力图的早期语义锁定

在基于扩散的文本-图像模型中，初始去噪步骤主要建立全局结构一致性和粗粒度空间布局，后续步骤则细化局部属性。我们的核心洞见将跨注意力机制识别为这一生成过程的透明且早期的诊断探针。我们观察到，对于文本token，跨注意力图迅速形成紧凑、稳定的空间焦点，表明对象的早期基础定位——这使得跨注意力成为在无需完整合成的情况下预测最终图像质量的理想信号。

更进一步：即使在高噪声去噪状态下，语义显著的对象token也能可靠地在高度局部化的区域诱发清晰定义的高注意力。这些初现的注意力焦点勾勒出初步的空间轮廓，确认了对象的快速初始基础定位。这种早期聚焦行为在初始时间步间保持稳定，并在更深的DiT块中逐渐锐化。

**失败案例的信号价值**：当最终生成图像表现出低质量或语义失败（如缺失对象、变形、属性不匹配）时，相应的早期注意力模式明显呈弥散和碎片化状态。

#### 3.2 MM-DiT中跨模态注意力的系统性偏差

这是一个重要的结构性问题，揭示了单步去噪中存在的内在张力：

这一问题源于视觉token和文本token数量之间的数值不对称（$N_x \gg N_c$），在注意力权重分布中造成了系统性偏差。每个视觉token在文本token上的注意力权重（$Q_{vis}K_{txt}^T$）必须在softmax分母中与视觉-视觉交互（$Q_{vis}K_{vis}^T$）竞争。

在初始去噪步骤对于建立图像全局布局至关重要的阶段，负责整合文本信息的跨注意力机制应当比视觉自注意力获得更大权重。MM-DiT的静态加权策略因此限制了其最优利用文本引导和适应去噪过程变化需求的能力。

### 四、单步内部表示的可解释性工具

#### 4.1 SAE：从多义神经元到单义特征

稀疏自编码器（SAE）已成为自回归大型语言模型中机械可解释性的广泛使用工具，能够提取稀疏的、对人类有意义的特征，帮助揭示内部表示。

Surkov等人（2024）在一步蒸馏的SDXL-Turbo扩散模型的激活上训练了SAE，证明SAE可以在模型特定块内检测到可解释特征，并对这些特征实现因果干预。

关键发现：利用SAE框架探测文本-图像扩散模型的内部工作机制，在其激活中发现了多种人类可解释的概念。有趣的是，即使在第一步逆向扩散步骤完成之前，通过观察激活概念的空间分布，就能以令人惊讶的精度预测最终场景的构图。

然而，现有SAE方法在应用于扩散模型时面临显著限制，特别是在激活层层面。扩散模型因其时间动态性而呈现出独特挑战：与以自回归方式处理静态token的语言模型不同，DiT在时间步之间迭代地细化潜在表示，同时整合来自文本编码器的多模态输入。

#### 4.2 Transcoder与电路追踪：从SAE到因果回路

SAE只能告诉你"激活了什么特征"，但无法告诉你"特征如何被变换和组合"——这正是MLP层的黑箱核心。

DifFRACT训练了时间步条件化的transcoder，忠实地近似FLUX.1[schnell]中MLP子层的输入-输出行为。通过用transcoder替换MLP并线性化剩余计算，可以获得精确的特征到特征归因，并恢复紧凑的、可解释的电路。

该工作开发并适配了电路追踪算法，使得发现"扩散电路"成为可能——即揭示图像生成关键方面（如对象放置、风格一致性、语义组合和跨流交互）的可解释特征因果路径。通过大量实验，证明该方法成功恢复了有意义的电路，并在去噪时间步之间产生了对生成过程的新见解。

#### 4.3 Logit Lens移植：来自LLM的失败尝试与启示

LLM中最直觉的可解释性工具是**logit lens**：在每个中间层后直接解码，观察"此时模型预测什么"的演化。那么这个工具能否移植到扩散模型？

一个具体的起点是研究logit lens；然而在去噪步骤之间的中间层上让logit lens有效工作是困难的——为什么会这样？也许经过调优的tuned lens会更有效？一个相关问题是patchscope是否在DiffusionGemma上效果更好，因为它的训练使其更天然地将向量作为输入。

这个"失败"本身就是一个深刻洞见：**扩散模型的中间层表示不直接对应于去噪目标空间**，不像LLM的中间层表示与词汇表保持连续对齐。这意味着我们需要全新的"解码探针"。

---

### 五、像素空间 vs 潜空间：双重嵌套的"内部世界"

现代扩散模型实际上有两个层次的"潜空间"，必须区分：

**第一层：VAE潜空间（外层）**

DiT是一个纯粹的潜在扩散模型。高分辨率图像被编码为紧凑的潜变量（通过VAE），然后被patchify以便Transformer操作。

通过在这一降维的潜空间中进行扩散，DiT实现了显著的效率提升——与更小的像素空间模型相比，能够以相当的资源需求处理更高分辨率。

**第二层：去噪网络内部表示（内层）**

由于DeepFloyd-IF直接在像素空间操作，我们认为每一步去噪都在底层语义结构中引入了比潜空间更大的偏移，这导致了架构间的差异。

这意味着：**像素空间扩散与潜空间扩散的单步去噪内部语义动态是根本不同的**。在潜空间中，VAE编码器已经完成了一次语义压缩，网络操作的是更高层次的表示；而像素空间模型每步都需要同时处理低层纹理和高层语义。

先前工作通过几何和稀疏性视角检视了扩散模型的内部表示，在U-Net瓶颈中识别出语义潜在空间，并通过稀疏自编码器将模型激活分解为可解释特征。

---

### 六、与LLM可解释性的深层对比：同构与断裂

| 维度 | LLM（Transformer） | 扩散模型去噪网络 |
|---|---|---|
| **输入单元** | 离散token | 连续patch/像素 |
| **内部表示对齐** | 中间层→词表（logit lens有效） | 中间层→噪声预测空间（需特殊探针） |
| **时间条件** | 无（或位置编码） | 显式 t 注入（AdaLN/调制） |
| **特征提取** | SAE成熟 | SAE刚起步，需时间步条件化 |
| **电路追踪** | Transcoder成熟 | 刚扩展到MM-DiT（DifFRACT 2026） |
| **注意力含义** | 信息路由（语义关联） | 信息路由 + 空间定位（双重） |
| **功能模块化** | Attention heads分工已有研究 | 刚开始（ConceptAttention等） |

扩散本质上并非不可解释：在文本-图像模型中，SAE暴露了因果概念因子，并支持可靠的概念编辑。

先前工作在几何和稀疏性视角、组合泛化视角下审视了扩散模型内部表示，但这些工作都没有涉及算法泛化，也没有提供扩散模型如何实现离散计算规则的电路级机制账户。

### 七、单步去噪的统一直觉框架

综合以上所有分析，我们可以建立一个关于单步去噪的**多架构统一直觉模型**：

```
输入：x_t（含噪潜变量）+ t（时间步） + c（条件文本/类别）
           │
           ▼
    ┌──────────────────────────────────────┐
    │         时间步注入层                  │
    │  (AdaLN-zero / Sinusoidal Embed)     │  ← "我现在在轨迹的哪里？"
    │  调制网络权重，感知当前噪声水平        │
    └──────────────┬───────────────────────┘
                   │
           ┌───────┴────────┐
           ▼                ▼
    [U-Net路径]        [DiT/MM-DiT路径]
    编码器→瓶颈→解码器   patch token序列处理
    空间层次明确         等向性全局注意力
    h-space = 语义中心  语义分布于所有层
           │                │
           └───────┬────────┘
                   ▼
    ┌──────────────────────────────────────┐
    │      注意力机制（跨模态交互核心）      │
    │  文本token ↔ 图像token               │  ← "语义在哪里落地？"
    │  早期步骤：建立空间基础定位           │
    │  晚期步骤：细化纹理细节              │
    └──────────────┬───────────────────────┘
                   │
           ┌───────┴────────┐
           ▼                ▼
      MLP子层           跳跃连接
    （非线性知识存储）  （空间记忆，仅U-Net）
           │                │
           └───────┬────────┘
                   ▼
    输出：ε_θ（预测噪声） 或 x_0（预测干净图像）
```

#### 七个核心认识

1. **时间步 t 不是装饰**：它通过调制机制改变网络每层的计算权重，决定"此步关注全局还是细节"
2. **U-Net的瓶颈是语义集中地**：h-space线性、均匀、鲁棒，是最"GAN-like"的表示空间
3. **DiT的语义是分布式的**：没有单一的"瓶颈"，语义通过全局注意力在所有patch间流动
4. **MM-DiT的文本-图像融合是隐式的**：没有特权的跨注意力路径，融合在拼接的注意力中发生
5. **注意力图是早期语义承诺的证据**：即使在第一步，空间基础定位就已发生
6. **MLP是特征变换的黑箱核心**：SAE揭示了"有什么特征"，Transcoder才能揭示"特征如何被变换"
7. **像素空间 ≠ 潜空间**：两者单步语义动态根本不同，不可类比

---

### 八、结语：数学的优雅实现在架构里，不在公式里

扩散模型的数学框架（SDE、score matching、ELBO）确实数学优雅。但这套优雅的数学规定了**目标**（预测噪声/score），却没有规定**路径**（网络内部如何计算出这个预测）。

特征可解释性旨在揭示神经网络如何通过内部表示编码功能，在语言模型中取得了显著成功，尤其是通过稀疏自编码器。这些工具将多义神经元分解为稀疏的、人类可解释的特征。

**数学设计规定了损失函数的形状；架构决定了网络"选择"如何解决这个问题；可解释性研究则试图事后重建那条"选择的路径"。**

这正是为什么单步去噪的内部世界如此重要：它是数学优雅与工程实现之间的**界面层**——在这里，抽象的score function变成了具体的特征激活、注意力权重、MLP变换。理解这一界面，才是真正理解扩散模型"如何思考"的关键所在。
