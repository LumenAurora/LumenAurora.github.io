# VLM 评测基准梳理（以 GLM-5V-Turbo 为例）

> 以一篇 VLM 技术报告为线索，梳理视觉编码器、RL 训练、多模态 Agent 各阶段常用的评测基准，并归纳出基础感知、跨模态对齐、多模态推理、多模态编码 / 工具使用、端到端 Agent 五大能力维度。

## VLM
下面向读者梳理 GLM-5V-Turbo 论文中提到的所有数据集和 benchmark，并简要介绍它们的用途。

---

### 一、Vision Encoder 评估基准（用于 CogViT 对比）

| 名称 | 简介 |
|------|------|
| **ImageNet-1K (Zero-Shot)** | 经典的 1000 类图像分类基准，零样本设置下测试视觉编码器的通用物体识别能力。 |
| **38 CLIP Bench (Mean)** | 38 个 CLIP 风格评估任务的平均表现，测试视觉-语言对齐和跨模态理解能力。 |
| **14 General Obj Bench (Mean)** | 14 个通用物体识别基准的均值，涵盖多种场景下的物体检测与分类。 |

---

### 二、RL 训练阶段评估基准（感知、推理、Agent 能力）

| 名称 | 类别 | 简介 |
|------|------|------|
| **RefCOCO-avg** | 2D 图像定位 | 指代表达理解基准，要求模型根据文本描述定位图像中的特定物体（avg 表示 RefCOCO 系列多个子集的平均）。 |
| **PointBench** | 2D 指向 | 测试模型通过指向（pointing）动作与图像交互的细粒度定位能力。 |
| **MVBench** | 视频理解 | 多模态视频理解基准，评估模型对视频内容的时间推理和事件理解。 |
| **SUNRGBD** | 3D 定位 | 室内场景 3D 物体检测与定位数据集，测试模型在三维空间中的 grounding 能力。 |
| **OCRBench** | OCR | 光学字符识别综合基准，测试模型从图像中提取和识别文本的能力。 |
| **CharXiv** | 图表理解 | 学术论文中的图表理解基准，要求模型解读复杂的科学图表和数据可视化。 |
| **MMMU_Val / MMMU_Pro** | STEM 推理 | 大规模多学科多模态理解基准（Massive Multi-discipline Multimodal Understanding），测试科学、技术、工程、数学领域的多模态推理。 |
| **MathVista** | 数学推理 | 数学视觉推理基准，结合数学问题与视觉输入（如图表、几何图形）进行求解。 |
| **LogicVista** | 逻辑推理 | 逻辑视觉推理基准，测试模型在视觉场景中进行逻辑推断的能力。 |
| **OSWorld** | GUI Agent | 操作系统级 GUI 代理基准，要求模型在真实操作系统环境中完成复杂任务（如打开软件、编辑文件）。 |
| **CC-Backend** | 编码 Agent | Claude Code 框架后端编码评估，测试模型在代码库后端开发任务中的表现。 |
| **MMSearch** | 工具使用 | 多模态搜索基准，评估模型使用搜索工具在多模态环境中获取信息的能力。 |

---

### 三、主要多模态 Agent 基准（第 5 节系统评估）

| 名称 | 类别 | 简介 |
|------|------|------|
| **Design2Code** | 多模态编码 | 将视觉设计稿（UI 截图/设计图）转换为可执行前端代码的基准，测试视觉到代码的生成能力。 |
| **Flame-VLM-Code** | 多模态编码 | 多模态代码生成基准，结合视觉输入进行编程任务评估。 |
| **Vision2Web** | 多模态编码 | 端到端视觉网站开发基准，模型需根据视觉参考（如截图、设计稿）完整复现网站，包含功能正确性和视觉一致性验证。 |
| **ImageMining** | 多模态工具使用 | 本文**自研**的视觉中心深度搜索基准。要求模型通过多步工具调用（裁剪、放大、搜索）主动挖掘图像信息，测试"用图像思考、用图像深度搜索"的 agentic 能力。涵盖 7 个领域（社交、娱乐、产品、地点、富文本、自然、科学）和 5 种推理类型。 |
| **BrowseComp-VL** | 多模态工具使用 | 视觉增强的网页浏览理解基准，测试模型在浏览网页时结合视觉信息进行复杂推理和比较的能力。 |
| **MMSearchPlus** | 多模态工具使用 | MMSearch 的扩展版，更复杂的多模态搜索任务，要求模型整合多源信息进行深度检索。 |
| **SimpleVQA** | 多模态工具使用 | 简单视觉问答基准，测试基础的视觉事实性问题回答能力。 |
| **Facts** | 多模态工具使用 | 事实性视觉问答基准，评估模型验证视觉内容中事实准确性的能力。 |
| **V\*** | 多模态工具使用 | 视觉搜索基准，要求模型在图像中查找特定视觉元素或回答需要视觉定位的问题。 |
| **OSWorld** | GUI Agent | 同上，操作系统环境交互基准。 |
| **AndroidWorld** | GUI Agent | 安卓系统 GUI 代理基准，模型需在真实 Android 环境中完成应用操作任务。 |
| **WebVoyager** | GUI Agent | 网页导航代理基准，测试模型作为网页浏览代理自主完成复杂在线任务的能力。 |
| **CC-Bench-V2** | 纯文本编码/Claw | Claude Code 框架综合评估（V2 版），包含后端、前端、代码库探索等子任务。 |
| **PinchBench** | Claw Agent | 代码代理执行基准，测试模型在代码编辑和工具使用框架中的任务完成能力（报告 Best/Avg 分数）。 |
| **ClawEval** | Claw Agent | Claw 框架评估基准，测试模型在开放式代码和工具使用环境中的 pass@k 表现。 |
| **ZClawBench** | Claw Agent | Z.ai 平台的 Claw 代理基准，评估模型在特定框架下的端到端 agentic 能力。 |

### 总结

这些 benchmark 覆盖了 **5 大能力维度**：
1. **基础视觉感知**（ImageNet、RefCOCO、OCRBench）
2. **视觉-语言对齐**（CLIP Bench、CharXiv）
3. **多模态推理**（MMMU、MathVista、LogicVista）
4. **多模态编码/工具使用**（Design2Code、ImageMining、BrowseComp-VL）
5. **端到端 Agent 能力**（OSWorld、AndroidWorld、WebVoyager、Claw 系列）

论文的核心贡献之一是 **ImageMining**（自研视觉深度搜索基准），它强调模型需要主动调用工具（裁剪、搜索、放大）来挖掘图像信息，而非被动回答——这代表了从"静态 VQA"到"主动视觉 Agent"的范式转变。[zai-org/ImageMining](https://github.com/zai-org/ImageMining)
