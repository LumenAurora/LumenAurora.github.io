# 随笔总览

> 随笔这 13 篇主题跨度大、平铺时显得零散。本页按科研心态与方向 / 科学哲学 / 技术与社会三条线重组，并标出每篇适合在什么心境下读；随笔偏「道」与心态，方法论偏「术」与流程，二者搭配可覆盖从方向焦虑到具体执行的完整链路。

## 一、这份导读在做什么

"随笔"这 13 篇，主题跨度大：有科研方向的选择、有科学哲学的辨析、也有技术与社会的关系。平铺时容易显得零散。本页按"科研心态与方向 / 科学哲学 / 技术与社会"三条线重组，并标出每篇适合在什么心境下读。

## 二、三条线

### 线 A · 科研心态与方向（迷茫 / 焦虑时读）

- [如何选择研究方向](./choose-direction)：选方向的框架与陷阱。
- [路在何方](./path-forward)：方向选定后的中长期规划。
- [顶会论文该怎么读](./research-judgment)：大模型时代读论文的方法，附四问清单。
- [什么才算真正的科研贡献](./what-counts-as-research)：区分"真贡献"与"工作量"。
- [复利思想与研究壁垒](./hamming-compound)：用复利视角看研究积累。
- [以小博大的研究案例](./lean-research)：资源有限时如何做出高杠杆工作。

> 这六篇合起来，是一份"怎样成为一个不焦虑的研究者"的手册。建议按顺序读 `choose-direction` → `what-counts-as-research` → `hamming-compound` → `lean-research`。

### 线 B · 科学哲学（想厘清"研究到底是什么"时读）

- [科学与工程的分野](./science-vs-engineering)：科研与工程的根本差异，决定你用哪套标准评价自己。
- [科学作为天职（韦伯）](./science-as-vocation)：韦伯演讲要点，关于"以学术为志业"的心态。
- [尚未解决的开放问题](./big-questions)：本领域值得长期投入的开放问题清单。
- [苦涩教训再解读](./bitter-lesson-inductive-bias)：对 Sutton「苦涩教训」的再思考。

### 线 C · 技术与社会（想跳出来看大图景时读）

- [复杂系统与计算不可约](./complex-systems)：复杂系统的不可约性，对"能否完全预测/控制 AI"有启发。
- [具身智能](./embodied-intelligence)：大脑做什么、小脑怎么做的区分。
- [人的不可替代价值](./human-value-in-ai-era)：大模型时代人还能提供什么。

## 三、和研究方法论的关系

随笔偏"道"与"心态"，方法论偏"术"与"流程"。建议搭配：方向焦虑 → 本页线 A；具体怎么做 → [研究方法论总览](/notes/methodology/hub)；选题品味 → 顶部导航「研究品味」。

## 四、如果你只想挑一篇

- 纠结方向 → `choose-direction`。
- 怀疑自己工作有没有价值 → `what-counts-as-research`。
- 想理解 AI 研究的哲学底色 → `science-vs-engineering` + `bitter-lesson-inductive-bias`。
