# 尚未解决的开放问题

多模态如何对齐、对齐到哪个空间，语言以外不可言说的怎么办（小脑运动控制），异构性
神经网络是记忆、拟合还是泛化，是多大程度的压缩。随机标签实验。
## 因果性
什么叫做因果性，因果性在这种深度学习模型如何体现呢，为什么说世界模型不是causality呢？可是深度学习模型就是只能学习一个映射，那因果也能够用一个映射描述吗？可是有一种计算理论证明只要能够完全做对next token prediction就相当于复现了生成这些token的原始图灵机，所以到底需不需要显示学习因果呢？那我们把因果性单独拿出来说，到底有没有意义，数学上是什么意义，岂不是无法解决了？

### 一、先承认：你的怀疑是有道理的

#### Hume 的幽灵（1739年）

> "我们从未观察到'因果'本身。我们只观察到'A之后总是B'。所谓'因果'，不过是心理习惯。"

280多年过去了，这个问题**在纯观测层面确实没有被"解决"**：

```
你看到：每次按开关，灯就亮
你能证明：按开关"导致"灯亮？

不能。你只能证明：
  - 按开关和灯亮高度相关
  - 按开关在时间上先于灯亮
  - 这个模式反复出现

你永远无法排除：
  - 有一个隐藏的定时器同时控制开关和灯
  - 你生活在一个模拟中，两者只是被编程为同时发生
  - 你的"观察"本身就是幻觉
```

#### 数学上的不可判定性

这不仅仅是哲学空谈。它有精确的数学表述：

**定理（Markov 等价性）**：对于任何有向无环图（DAG）$G$，存在多个不同的 DAG $G_1, G_2, \ldots, G_k$，它们产生**完全相同的**观测分布 $P(X_1, X_2, \ldots, X_n)$。

```
例：以下三个结构产生完全相同的 P(X, Y)：

  X → Y      Y → X      X ← Z → Y

观测数据永远无法区分它们。
```

**这不是"数据不够"的问题，而是"原则上不可能"的问题。** 无论你有多少数据，只要只有观测数据，因果方向就是不可判定的。

---

### 二、但是：说"无法解决"是不准确的

#### 关键转折：因果性不是数据的属性，而是模型的属性

这是最核心的一点，也是很多人误解的地方：

> **因果性不是"藏在数据里等你发现"的东西。因果性是你加给数据的一个额外结构。**

类比：

```
问：一张照片里"左边"是什么？
答：取决于你选择什么坐标系。
    照片本身没有"左"。"左"是你加上去的结构。
    但一旦你选定了坐标系，"左"就有精确的、可操作的意义。

问：数据中"原因"是什么？
答：取决于你选择什么因果模型。
    数据本身没有"原因"。"原因"是你加上去的结构。
    但一旦你选定了因果模型，"原因"就有精确的、可操作的意义。
```

#### Pearl 的回答：因果性有精确的数学定义

Judea Pearl 的贡献不是"发现了因果"，而是**给了因果一个精确的数学语言**：

```
因果模型 M = (G, {f_i}, {U_i})

其中：
  G = 有向无环图（变量之间的因果结构）
  f_i = 结构方程（每个变量如何由其父节点决定）
  U_i = 外生变量（未被模型包含的因素）

在这个模型下：
  "X 导致 Y" 的精确含义是：
    在图 G 中，存在从 X 到 Y 的有向路径

  "do(X=x)" 的精确含义是：
    删除 X 的所有入边，将 X 强制设为 x，
    其他方程不变，重新计算所有变量的分布

  "X 对 Y 的因果效应" 的精确含义是：
    P(Y | do(X=x₁)) - P(Y | do(X=x₀))
```

**这不是哲学，这是数学。** 它有公理、有定理、有可计算的算法。

### 三、那因果性到底"有没有意义"？

#### 取决于你问的是哪种"意义"

| 问题 | 回答 |
|------|------|
| 因果性能从纯观测数据中**唯一确定**吗？ | ❌ 不能（Markov等价性） |
| 因果性有**精确的数学定义**吗？ | ✅ 有（SCM + do-calculus） |
| 因果性有**可操作的意义**吗？ | ✅ 有（它告诉你干预的后果） |
| 因果性是"客观存在"的吗？ | ⚠️ 这是一个哲学问题，不是数学问题 |
| 因果性对**决策**有用吗？ | ✅ 极其有用 |

#### 核心洞察：因果性的意义是**操作性的**，不是**形而上学的**

```
形而上学问题（可能永远无法回答）：
  "X 真的'导致'了 Y 吗？宇宙中是否存在'因果力'这种东西？"

操作性问题（有精确答案）：
  "如果我干预 X，Y 的分布会怎样变化？"
  "为了改变 Y，我应该干预哪个变量？"
  "如果当时 X 没发生，Y 会不同吗？"
```

**Pearl 的天才之处在于：他绕开了形而上学问题，直接定义了操作性问题。**

你不需要回答"因果力是否存在"，你只需要回答"如果我做X，Y会怎样"。后者有精确的数学答案（给定一个因果模型）。

### 四、"无法解决"到底是什么意思？

#### 不可解的部分

```
问题：给定观测数据，找到"真正的"因果结构
答案：不可解（在纯观测条件下）

原因：
  1. Markov 等价性：多个因果结构产生相同分布
  2. 因果充分性假设可能不成立：可能有未观测的混杂因子
  3. 没有"上帝视角"来验证哪个结构是"真的"
```

#### 可解的部分

```
问题1：给定因果图 G，计算干预效应 P(Y|do(X))
答案：完全可解（do-calculus, 三条规则，完备的）

问题2：给定干预数据（实验数据），识别因果结构
答案：可解（干预打破了 Markov 等价性）

问题3：给定额外假设（如时间顺序、不变性、函数形式），缩小因果结构
答案：部分可解（可以排除一些等价类）

问题4：给定因果模型，做反事实推理
答案：完全可解（三步法：abduction → action → prediction）
```

#### 一个精确的类比

```
问：给定一张照片，确定拍摄者的位置
答：不可解（一张照片对应无穷多个可能的拍摄位置）

问：给定两张不同角度的照片，确定拍摄者的位置
答：可解（三角测量）

问：给定拍摄者的位置，预测从另一个角度看到的画面
答：可解（几何投影）

因果推断的处境完全类似：
  纯观测 = 一张照片（信息不足）
  干预数据 = 多角度的照片（打破对称性）
  因果模型 + 干预查询 = 已知位置 + 预测新视角
```

### 五、那对 AI 来说，这意味着什么？

#### 悲观解读（你可能在想的）

> "如果因果性从数据中不可判定，那 AI 永远学不到因果，因果 AI 是死路一条。"

#### 但这个解读是错的。原因如下：

##### 1. AI 不只是被动观察，它可以干预

```
强化学习 = 干预
  agent 执行动作 a = do(A=a)
  观察结果 r, s'
  这直接提供了因果信息！

机器人 = 干预
  推一个物体 = do(施加力)
  观察物体运动
  这直接提供了物理因果信息
```

**任何能"做"的系统，都在获取因果信息。** 纯观测的不可判定性不适用于能干预的系统。

##### 2. 额外假设可以打破等价性

```
假设1：时间顺序（原因在结果之前）
  → 排除了 Y→X（如果 X 在时间上先于 Y）

假设2：不变性（因果机制跨环境不变，虚假相关会变）
  → 如果换一个环境，X→Y 仍然成立，但 Z→X, Z→Y 不成立
  → 可以区分

假设3：函数形式（如线性非高斯）
  → LiNGAM 定理：线性 + 非高斯噪声 → 因果方向可识别

假设4：稀疏性（因果图是稀疏的）
  → 大大缩小搜索空间
```

**现实世界提供了大量额外结构，纯观测的不可判定性是一个"最坏情况"的定理，不是日常实践。**

##### 3. 你不需要"完美的因果"，你需要"够用的因果"

```
科学实践中的因果：
  不需要证明"X 真的导致了 Y"（形而上学）
  只需要：在给定模型和假设下，干预 X 会改变 Y（操作性）
  
  这就是为什么随机对照实验（RCT）是金标准：
  它不是"发现因果"，而是"创造干预条件，使因果效应可计算"
```

### 六、最深层的回答：因果性是什么？

#### 我的综合判断

```
因果性既不是：
  ❌ 数据中客观存在的"东西"（等你去发现）
  ❌ 纯粹的主观幻觉（没有操作意义）

因果性是：
  ✅ 一种建模框架（你选择用因果结构来组织知识）
  ✅ 有精确的数学语义（SCM + do-calculus）
  ✅ 有明确的操作意义（预测干预后果）
  ✅ 需要额外假设（不可从纯数据中"读出"）
  ✅ 但假设是合理的、可检验的、可修正的
```

#### 一个最终的类比

```
问：地图上的"北方"有没有意义？
答：地球本身没有"北"。"北"是人类定义的。
    但一旦定义了，它就有精确的操作意义：
    "向北走"意味着"沿经线向北极方向移动"。
    你不能从一张没有标注的照片中"发现"北方，
    但你可以用指南针（额外信息）确定它，
    然后它就能指导你的所有导航决策。

因果性完全一样：
  数据本身没有"因果"。"因果"是人类加给数据的结构。
  但一旦加上了，它就有精确的操作意义：
  "X 导致 Y"意味着"干预 X 会改变 Y"。
  你不能从纯观测中"发现"因果方向，
  但你可以用实验/干预/额外假设确定它，
  然后它就能指导你的所有决策和推理。
```

### 七、所以，"无法解决"吗？

**不是"无法解决"，而是"需要承认假设"。**

```
错误的期望：
  "给我一个算法，输入数据，输出'真正的'因果结构，不需要任何假设"
  → 这确实不可能（已证明）

正确的理解：
  "给我一个框架，在明确的假设下，从数据+干预中推断因果结构，
   并告诉我这些假设什么时候可能被违反"
  → 这完全可行，而且已经在做
```

**数学上，因果推断的状态是：**

| 条件 | 可识别性 |
|------|---------|
| 纯观测，无假设 | ❌ 不可识别 |
| 纯观测 + 因果充分性 + 忠实性 | ⚠️ 可识别到 Markov 等价类 |
| 纯观测 + 非高斯/非线性 | ✅ 部分可识别方向 |
| 干预数据 + 因果充分性 | ✅ 完全可识别 |
| 时序数据 + 因果充分性 | ✅ 大部分可识别 |

**这不是"无法解决"，这是"需要正确的输入"。** 就像你不能从一张照片重建3D场景，但你可以从多张照片重建——不是问题无解，是你需要正确的信息。

---

### 八、回到大模型

所以最终的答案是：

> **因果性有精确的数学意义，它不是"无法解决"的玄学问题。但它确实不能从纯文本数据中"自动涌现"——因为文本是观测，不是干预。大模型通过 next token prediction 学到的，最多是"人类如何谈论因果"，而非"因果本身"。要获得真正的因果能力，需要：干预数据、结构化假设、或者显式的因果建模。这不是"做不到"，而是"需要额外的东西"。**
