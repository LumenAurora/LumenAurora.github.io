# 如何选择研究方向

如何对目前AI学界的研究领域做不重不漏的分类，以便让本科生能够选好科研方向呢？很多领域分类标准根本不在一个层次上，比如说RL作为方法，套用在LLM、agent等不同对象上，可以实现对齐、抵抗幻觉、智能体博弈等等。比如说RL是学习方法，gpt、扩散模型是大的模型架构，但是u-net、transformer block是模型组件，这些并不矛盾，扩散模型的编码器也可以用transformer而非u-net。我们需要梳理清楚，才不至于感觉什么都新鲜。太阳底下无新事。
目前还在被研究，还在演进的大模型领域，在学习方法上，只有监督学习和强化学习。在生成模型大架构上，只有自回归生成模型和扩散生成模型，老牌CV当然也有文章、那是另一个故事了、不属于大模型。剩下的都是番茄炒鸡蛋，组合而已。当然现在有agent了，agent的调度本质是cs的操作系统。所以更抽象一层是agent的系统，sys研究。
而从研究服务的现实价值，又可以分为仿真与物理模拟加速、传感器等硬件采集（具身智能）、数据、bench评判器、训练与推理效率优化（剪枝、量化、蒸馏、边缘计算、联邦学习等）、训练与推理计算加速（贴近硬件的计算算法，如flash attention等）、训练与推理稳定性（优化器等方向）、现象的机制研究（分析类文章）、可解释性与理论（如Scaling Law等）等等。
只有两种，一种是大模型，另一种是非大模型。前者已经被兼并了，而后者各有各的模型。
永恒的矛盾会导致这个问题永远不会被完全解决，也即永远有刷榜的空间。
选择主流方向竞争激烈，但是未来出路宽，且基础扎实（对前沿模型、dataset、bench、training、finetuning、deployment了解更为清晰）；选择非主流方向虽然可能好发，但是未来对口就业岗位少，只能继续学术发展，不过有的优秀的学术问题后来也能转变为工业需求，这就看眼光了。
**吕凯风**研究机器学习理论、AI安全与对齐、优化；
**贺天行**关注电子游戏研发、多模态生成、社会模拟和AI安全；
**徐梦迪**研究机器学习、机器人学、人机交互与AI安全；
**侯攀宇**则从事离子量子计算和金刚石色心研究。
## 非大模型
这是个很关键的补充——你其实是想先搭好"**模型架构轴**"（Model Architecture Axis），这是我之前提到的正交坐标之一，但值得单独深挖，因为架构选择在很大程度上取决于数据的**几何/物理/因果结构**，而不是语言。让我先确认一些近两年架构演进的最新情况，再给你一个系统性框架。这是个非常好的切入点。要给"模型架构"这一维度做到科学正交，最有理论根基的方式不是"列清单"，而是采用 **Michael Bronstein 等人提出的几何深度学习(Geometric Deep Learning)统一框架**——即架构设计应该由**数据的数学结构/对称性(symmetry)**决定，而不是由任务名称决定。在此基础上，再补充"时间动力学"、"生成式"、"符号"、"生物"等几个框架未完全覆盖的正交轴。下面是一套系统性方案：

### 核心原则
**架构 = 对数据背后某种数学结构的归纳偏置(inductive bias)编码**。图像有网格结构，分子有群对称结构，社交网络有图结构，因此架构应随之而变——这是分类的第一性原理，而不是"这个任务能不能套用Transformer"。

---

### A. 空间/几何结构类（Geometric Deep Learning 母框架）

这是最底层、最正交的一组，按数据所满足的对称性分类：

1. **网格结构 (Grids)** → CNN、U-Net、ConvNeXt（图像、规则网格数据）
2. **群对称结构 (Groups)** → 等变网络 E(3)/SE(3)-Equivariant Networks（分子、蛋白质、点云、物理系统需要旋转/平移不变性）
3. **图结构 (Graphs)** → GNN（GCN、GAT、MPNN、Graph Transformer），用于分子图、知识图谱、社交网络、电路
4. **流形/测地线结构 (Geodesics)** → Mesh Networks、流形学习网络，用于3D形状、蛋白质表面
5. **规范场结构 (Gauges)** → Gauge-equivariant networks，用于球面数据（气象、天文）

### B. 时间/动力学结构类

这一轴关心"状态如何随时间演化"，与空间结构正交：

- **离散递归** → RNN/LSTM/GRU
- **连续时间动力学** → Neural ODE / Neural SDE
- **状态空间模型** → 这是近两年最活跃的方向。State Space Models提供了一种完全不同的数学基础，其根源在于动力系统理论而非成对注意力机制，S4和Mamba这类架构将SSM扩展为实用的、可训练的深度学习系统。其核心优势是通过选择性状态空间机制，Mamba能够基于当前token选择性地传播或忽略信息，并且在序列长度上呈线性扩展，推理速度可达Transformer的五倍。这类架构已经在非语言的时序信号（如心电图ECG、肌电信号EMG）上广泛应用。
- **时序卷积** → TCN、WaveNet
- **时空图网络** → Temporal GNN（交通流预测、金融网络）

### C. 物理约束/科学计算类

专为"已知物理规律但数据稀缺"场景设计，是非大模型领域最活跃的分支之一：

- **物理信息神经网络 PINN**：把PDE残差直接作为loss项，实现无标签/弱监督求解
- **神经算子 Neural Operators**：学习的是"函数到函数"的映射，而非单点映射。两大代表架构各有优势：FNO在解具有强频谱特征且区域规则时表现优异，而DeepONet更适合复杂几何形状或输入函数稀疏采样的场景，对于高雷诺数流动，FNO对光滑函数的谱偏置可能存在问题，此时混合方法有帮助。
- **几何感知神经算子**：针对变化几何形状的场景，最新工作如PI-GANO通过带符号距离函数和参数-几何注意力机制，同时对PDE参数和域几何形状进行泛化。
- **图神经算子**：通过多极展开，将近场（局部）和远场（全局）相互作用分离，用于处理长程相互作用问题。

### D. 无序/集合结构类

数据没有固定顺序或网格，需要置换不变性：

- PointNet、DeepSets、Set Transformer → 点云、粒子系统、多主体状态

### E. 生成式非语言架构类

生成建模不等于LLM/扩散大模型，非语言场景下仍有独立谱系：

- GAN（图像/信号生成、数据增强）
- VAE（表征学习、异常检测）
- Normalizing Flow（精确似然建模，分子构象生成）
- 小尺度/领域专用扩散模型（如材料结构生成、蛋白质结构生成，区别于文生图大模型）
- Energy-Based Models / Hopfield Networks（联想记忆、能量最小化建模）

### F. 生物/神经科学启发架构类（对应前文所述的"生物细胞模型"）

- **脉冲神经网络 SNN**：类脑计算、神经形态芯片，事件驱动而非连续激活
- **神经元胞自动机 Neural Cellular Automata**：模拟细胞分化、形态发生过程，将局部更新规则参数化为神经网络
- **系统生物学微分方程模型 + 神经网络混合**：基因调控网络(GRN)的ODE建模、神经ODE与生物动力学结合
- **Agent-based Models 与神经网络耦合**：多细胞/多主体仿真中用NN学习局部规则

### G. 符号/结构化推理类

- **神经符号系统 (Neuro-symbolic)**：可微分逻辑、程序归纳
- **树/递归网络**：Tree-LSTM、Recursive NN，用于分子式解析、程序语法树、化学反应路径

### H. 决策与控制类架构

专为强化学习/序贯决策设计的网络结构（区别于"学习范式"轴中的RL，这里指具体网络形式）：

- Actor-Critic 双头网络
- World Models（如Dreamer系列，学习潜在动力学模型用于规划）
- Q-network / 基于能量的策略网络

---

### 重要说明：轴与轴之间允许"组合"，但轴本身正交

这套分类法的关键在于：**A-H是互不重叠的"结构维度"，但具体一个模型可以是多个维度的组合**，例如：

- 等变图神经网络 = A2(群) + A3(图)
- 时空图神经网络 = A3(图) + B(时间)
- Neural Operator + 扩散模型融合将神经算子与扩散模型结合可以提升湍流建模中的频谱表示能力 = C(物理) + E(生成)

这样处理的好处是：你不需要担心"这个模型该归到哪一类"产生的归属冲突——因为它本来就应该同时标注在多个正交轴上，就像给一个点标注多维坐标，而不是塞进一棵单一的分类树。
## AI研究领域的MECE分类框架

你的洞察是对的：混乱感来自于**把不同维度/层次的概念平铺在同一张清单上**。解决方案不是更好的树状结构，而是**多个正交轴的笛卡尔积**——任何一篇论文，都能在这几个轴上各取一个坐标。

---

### 核心框架：三轴正交定位

#### 轴一：研究对象的抽象层次（Object Level）

这是最容易混乱的地方。必须先把"层次"理清，层与层之间是**使用/包含**关系，不是并列关系：

| 层次 | 定义 | 典型概念 |
|------|------|----------|
| **L0 计算/硬件** | 芯片、算子、内存访问模式 | CUDA kernel、FlashAttention、内存带宽优化 |
| **L1 模型组件** | 可复用的网络模块 | Transformer block、U-Net、Mamba、MoE |
| **L2 模型范式** | 大的生成框架/训练目标 | 自回归（AR/GPT）、扩散（Diffusion）、Flow Matching |
| **L3 学习范式** | 训练信号的来源与机制 | 监督学习（SFT/预训练）、强化学习（RLHF/GRPO/PPO）、自监督 |
| **L4 系统与智能体** | 模型的编排、调度、协作 | Agent、RAG、Multi-agent、Tool use、Memory管理 |
| **L5 应用场景** | 具体任务领域 | 具身智能、代码生成、科学计算加速、医疗 |

> **关键点**：L4的Agent调用L2的AR模型；L2的扩散模型用L1的Transformer替换U-Net——这完全不矛盾，它们在不同层。RL（L3）可以套在AR模型（L2）上做对齐，也可以套在Agent（L4）上做博弈，对象不同，但方法层次一致。

---

#### 轴二：研究目标（Research Goal）

这是"为了解决什么核心问题"，与轴一正交：

```
能力（Capability）      → 让模型能做更多、做得更好
效率（Efficiency）      → 更快、更省显存、更便宜（量化/蒸馏/剪枝/推理加速）
可靠性（Reliability）   → 减少幻觉、价值对齐、安全、鲁棒性
理解（Understanding）   → 机制解释、涌现分析、泛化理论、可解释性
基础设施（Infra）       → 数据管道、评测基准(Benchmark)、仿真环境
```

---

#### 轴三：研究手段（Contribution Type）

这是"用什么方式做研究"：

```
算法贡献    → 提出新的训练方法、新的目标函数
架构贡献    → 提出新的模型结构或组件
系统贡献    → 工程实现、系统设计、框架搭建
理论贡献    → 定理、证明、complexity分析
实证分析    → 观察现象、消融实验、Scaling law测量（分析类文章）
```

### 用三轴重新理解你举的例子

| 论文/方向 | 轴一（对象层） | 轴二（目标） | 轴三（手段） |
|-----------|---------------|-------------|-------------|
| RLHF / GRPO | L3×L2(AR) | 可靠性·对齐 | 算法 |
| FlashAttention | L0×L1 | 效率 | 系统+算法 |
| 扩散模型换Transformer骨干 | L1×L2 | 能力 | 架构 |
| Agent Tool Use / 多智能体博弈 | L4 | 能力 | 系统 |
| Scaling Law研究 | 跨L2-L3 | 理解 | 实证分析 |
| 具身智能 | L5×L4×L0 | 能力 | 系统+算法 |
| 量化/剪枝/蒸馏 | L1-L2 | 效率 | 算法+系统 |
| 幻觉机制分析 | L2-L3 | 理解 | 实证分析 |
| 优化器研究（Adam变体等） | L3 | 效率+稳定性 | 算法+理论 |

### 进一步细化：轴一L2和L3的内部结构

你提到"学习方法只有监督和强化"，可以再展开：

```
L3 学习范式
├── 预训练阶段
│   ├── 自回归语言建模（Next-token prediction）
│   └── 去噪/Flow（扩散模型的训练目标）
└── 后训练阶段（Post-training）
    ├── 监督微调 SFT
    ├── 偏好学习 → RLHF / DPO / GRPO（本质：RL或其近似）
    └── 持续预训练

L2 生成范式
├── 自回归（AR）：GPT系列、LLaMA
├── 扩散（Diffusion）：DDPM、Stable Diffusion、DiT
└── 流匹配（Flow Matching）：正在取代扩散成为图像/视频新范式
```

> **Flow Matching** 是目前值得单独列出的第三个生成范式（Sora、Flux等都在用），与扩散模型数学上有联系但不完全相同，代表了一个独立演化方向。

### 对本科生选方向的操作建议

**三步定位法：**

**第一步：选轴一（你想在哪个层工作）**
- 喜欢靠近硬件、性能调优 → L0
- 喜欢设计网络结构、数学美感 → L1/L2
- 喜欢训练算法、优化理论 → L3
- 喜欢系统设计、分布式、编排 → L4（这里确实类似OS研究）
- 有具体应用场景驱动 → L5往下找支撑

**第二步：选轴二（你的研究驱动力）**
- "我想让AI更强" → 能力
- "我想让AI更省钱" → 效率
- "我想让AI更安全可信" → 可靠性
- "我想搞懂AI为什么work" → 理解/理论

**第三步：选轴三（你的核心技能）**
- 数学强，喜欢推导 → 理论/算法
- 工程强，喜欢系统 → 系统
- 喜欢做实验、观察规律 → 实证分析

三个坐标一定，方向就清晰了。**所谓"新方向"，不过是这个空间里换了一个坐标点**——比如把RL（L3，对齐）换成RL（L3，Agent博弈），本质工具箱没变，换了应用对象。太阳底下无新事，正在于此。

### 一个常被忽略的维度：模态

上述框架对**模态（Modality）**是隐式处理的，可以作为补充维度：

```
文本（Text）→ LLM主战场
图像（Image）→ 扩散模型主战场  
视频（Video）→ 当前增长最快
音频（Audio）
点云/传感器 → 具身智能入口
多模态融合（Multimodal）→ 跨模态对齐是独立问题
```

模态不改变轴一到轴三的结构，但会影响具体实现。一个研究者可以专注"**L2扩散范式×能力×架构×视频模态**"，这就是视频生成模型架构研究，定位非常精确。
