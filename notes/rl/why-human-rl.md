# 人为什么靠「RL」学会打麻将

## 人类为什么靠"RL"能学会打麻将

先说结论：**人类学习根本不是RL，或者说，人类用的是一个作弊版的RL。**

---

### 一、人类拥有的东西，算法完全没有

#### 1. 预训练好的世界模型

人类坐下来学麻将之前，已经有了：

```
- 数字大小的概念
- 序列和顺序的概念（顺子）
- 集合的概念（刻子）
- 概率的直觉（这张牌还剩几张）
- 对手是有意图的智能体这个认知
- 危险和安全的直觉
```

这些不是从麻将中学来的，是从**几十年的生活经验**中学来的。

神经网络从零开始，什么都不知道：

```
输入：一堆数字
输出：一堆数字
中间：没有任何先验结构
```

**这个差距不是数量级，是本质上的不同。**

#### 2. 人类可以接收语言指导

```
"听到边张不好和"
"对手打出5万要小心他在听牌"
"振听了不能荣和"
```

一句话，直接更新了大量行为规则。

这等价于什么？

```
等价于直接修改策略网络的权重
等价于跳过了数万局的试错
```

RL算法只能从reward信号学，不能接收自然语言指令（除非专门设计）。

#### 3. 人类有因果推理能力

看到对手打出一张9万：

```
人类的推理链：
他打出9万 → 他可能不需要9万 → 他的手牌可能在789万附近没有缺口
→ 或者他在听其他的 → 我手里的8万可能相对安全

这个推理链：
- 是因果的，不是统计的
- 是即时的，不需要从经验中学
- 可以泛化到没见过的情况
```

神经网络做的是统计关联，不是因果推理：

```
"在这类似的状态下，历史上打8万的胜率是X%"
```

两者在数据量需求上差距巨大。

---

### 二、人类的"奖励信号"和算法完全不同

#### 算法的奖励信号

```
一局结束（200步之后）：
赢 → +1
输 → -1 或 0

然后算法要从200步的序列里，
反推哪些步骤是好的
```

#### 人类的奖励信号

人类有**即时的、多层次的内部奖励**：

```
摸到一张牌，凑成了顺子
→ 即时的满足感（多巴胺）
→ 这个行为被立刻强化

差一张听牌
→ 即时的期待感和兴奋
→ 相关的策略被强化

被点炮
→ 即时的懊悔，回溯思考"刚才不应该打那张"
→ 主动做了信用分配
```

人类的信用分配是**主动的、有意识的**：

```
"我刚才不应该打那张牌"
"下次遇到这种情况要保留安全牌"
```

这不是被动等待reward信号反向传播，而是主动推理因果链。

**这直接解决了RL最核心的难题。**

---

### 三、人类的探索策略是有结构的

RL算法的探索：

```
epsilon-greedy：以epsilon概率随机选一个动作
→ 可能打出完全无意义的牌
→ 大量探索是无效的噪声
```

人类的探索：

```
"我从没试过在这种牌型下碰牌，我试试看"
→ 探索是有意图的、有假设的
→ 探索之后会主动分析结果
→ 有效探索比例远高于随机探索
```

人类的探索本质上是**假设驱动的科学实验**，不是随机游走。

---

### 四、人类有层级化的学习

人类不是在"打麻将"这一个层级上学习：

```
层级1：牌的基本组合（顺子、刻子）→ 几分钟学会
层级2：听牌判断 → 几局学会
层级3：安全牌判断 → 几十局学会
层级4：对手意图推断 → 几百局学会
层级5：整体战略（何时攻何时守）→ 几年学会
```

每个层级建立在上一个层级之上，已学会的层级**不会被遗忘**，因为有语言和有意识的记忆巩固。

RL算法是**平坦的**：

```
所有的知识都压缩在神经网络权重里
学了新东西可能覆盖旧东西
没有层级结构
灾难性遗忘是结构性问题
```

---

### 五、一个诚实的总结

```
人类学麻将用的不是纯RL

人类用的是：
预训练世界模型（几十年生活经验）
+ 语言指令（直接策略更新）
+ 因果推理（主动信用分配）
+ 内部密集奖励（多巴胺系统）
+ 有结构的探索（假设驱动）
+ 层级化记忆（不会灾难性遗忘）
+ 少量真实交互

RL算法用的是：
随机初始化
+ 稀疏奖励
+ 被动信用分配
+ 随机探索
+ 平坦的权重存储
+ 大量真实交互
```

**人类的优势不是学习算法更好，而是带着一个预装了几十年知识的世界模型来学一个新游戏。**

这就是为什么说"人类用RL"是一个误导性的类比。更准确的说法是：

**人类用一个带有强先验的、多模态的、层级化的学习系统，处理了一个对纯RL算法来说极度困难的问题。**

AlphaZero之所以能成功，本质上是用MCTS这个结构化先验，部分模拟了人类的因果推理能力，而不是靠纯粹的RL。
