# 领域综述导读

> 领域综述这 7 篇是对几个领域「十年脉络 + 关键转折」的纵向梳理，不是教科书。本页按领域（视觉/多模态、图/序列、大模型能力与安全、会议生态）给一张索引，标出每篇适合在什么场景读，方便按研究方向挑读或在写 related work 前抓取叙事锚点。

## 一、这份导读在做什么

"领域综述"这 7 篇不是教科书，而是对几个领域"十年脉络 + 关键转折"的纵向梳理。本页按领域给一张索引，并标出每篇适合在什么场景下读——避免你在一篇里迷路，也方便按研究方向挑读。

## 二、按领域选读

### 视觉 / 多模态

- [CVPR 十年谈](./cvpr-decade)：按年份梳理 CVPR 十年的技术主线迁移。
- [从 NLP 到 LLM](./nlp-to-llm)：NLP 范式如何滑向大模型，适合做语言/多模态的人建立历史坐标系。

### 图 / 序列 / 结构化数据

- [图神经网络的演进](./gnn-evolution)：GNN 从谱方法到消息传递的演进与瓶颈。
- [时间序列分析](./time-series)：时间序列方法脉络与现状，偏工程落地。

### 大模型能力与安全（热门）

- [学界「抗幻觉」研究全史](./anti-hallucination)：从评测到缓解的完整谱系，做可靠性/对齐的人必读。
- [迁移学习族谱与 TTA 定位](./transfer-learning-tta)：迁移学习四层分类法 + 测试时适应（TTA）在大模型时代的生存现状。

### 会议生态（宏观）

- [ICML 十年脉络](./icml-decade)：ICML 十年的主题变迁，适合把握"社区在关心什么"。

## 三、怎么用这组综述

- **写 related work 前**：挑对应领域的 1–2 篇，提取"转折点在哪"作为你叙事的锚。
- **定方向前**：`ICML 十年脉络` + `CVPR 十年谈` 看大趋势；`抗幻觉` / `迁移学习` 看具体赛道是否饱和。
- **做可靠性 / 对齐**：`抗幻觉` 是主线，`迁移学习` 补"适配"视角。
