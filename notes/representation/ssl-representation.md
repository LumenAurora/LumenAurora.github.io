# 自监督表征学习：从零到精通

生成式模型必须是**等变（Equivariant）** 的（改变输入像素，输出必须跟着变），否则无法重建。而 CLIP/DINO/JEPA 追求的是**不变性（Invariance）**（改变颜色、裁剪、视角，表征 zz 应当保持不变）。这种对“变化”的主动丢弃，是生成式模型做不到的。所以这有点类似判别式学习，归类的思想，目前大多用于编码嵌入向量，例如CLIP（对比学习）和DINO（自蒸馏学习）至今一直应用于visual token的生成，RAG的embedding模型也是基于对比学习的。其实说实话就是看需求，学到抽象表征还是具体表征，如果要抽象表征肯定是服务于特定需求、那类似判别式会更好，如果要学到细粒度具体表征重建输入肯定是生成式。
## Self-Supervised Representation Learning 从零到精通保姆级教程

这是一份系统性的长文教程，我会按照"是什么 → 为什么 → 怎么做 → 代表算法 → 实践与前沿"的顺序，把自监督表征学习（Self-Supervised Learning, SSL）讲透。建议先通读一遍框架，再回头细看每个算法的公式与直觉。


### 二、为什么需要自监督学习？

1. **标注昂贵**：ImageNet 标注了 1400 万张图，但互联网上有几十亿张未标注图片/视频/文本，浪费了海量数据。
2. **监督学习容易过拟合到标签偏差**：模型学到的特征往往只对特定任务有效，泛化性差。
3. **人类/动物的学习方式**：婴儿几乎不靠"标签"学习世界，而是靠观察、预测、感知规律，这正是自监督学习模仿的智能范式（Yann LeCun 一直强调这一点）。
4. **规模化（Scaling）优势**：自监督不受标注瓶颈限制，可以无限扩大数据规模，这也是大语言模型（GPT系列）能够成功的根本原因——它们本质上就是自监督学习。

### 三、自监督学习的整体流程（通用范式）

无论哪个具体算法，都遵循这个两阶段流程：

```
阶段一：预训练 (Pre-training)
  原始无标签数据 → 数据增强/切分/掩码 → 构造 pretext task
  → 训练 Encoder f(·) 使其在 pretext task 上表现好
  （此时不需要任何人工标签！）

阶段二：迁移/评估 (Transfer / Evaluation)
  冻结或微调 Encoder → 接下游任务头（分类头/检测头等）
  → 用少量标注数据训练/微调 → 在下游任务上评测效果
```

评估方式常见有三种：
- **Linear Probing（线性探针）**：冻结 encoder，只训练一个线性分类器，衡量特征本身的线性可分性。
- **Fine-tuning（微调）**：解冻整个网络，用下游标签整体微调。
- **KNN / Attentive Probe**：直接用最近邻或者一个小的注意力探针在冻结特征上评估，DINOv2、V-JEPA 系列常用这种方式做评测。

### 四、自监督学习的三大技术流派

这是理解全局最关键的一张地图。几乎所有算法都能归到下面三类（或其组合）里：

#### 1️⃣ 生成式 / 重建式（Generative / Reconstructive）
**思路**：破坏输入的一部分，让模型重建被破坏的部分。
- 图像领域：自编码器（AutoEncoder）、去噪自编码器（Denoising AE）、**MAE (Masked Autoencoder)**、BEiT
- NLP 领域：**BERT (Masked Language Model)**、**GPT (Next Token Prediction)**
- 语音领域：wav2vec

**优点**：不需要设计负样本，训练稳定；**缺点**：容易学到低层像素/词元细节而非高层语义，计算量大（需要 decoder）。

#### 2️⃣ 对比式（Contrastive Learning）
**思路**：对同一样本做两种不同的"视角"（数据增强），让模型认为这两个视角是"正样本对"，拉近它们在特征空间的距离；同时把它和其他样本（负样本）推远。
- 代表：**SimCLR**、**MoCo**、CPC、InstDisc

**核心难点**：需要大量负样本（大 batch size 或 memory bank），计算/显存开销大。

#### 3️⃣ 非对比式 / 自蒸馏（Non-Contrastive / Self-Distillation）
**思路**：不需要显式负样本，通过架构设计（动量编码器、停止梯度、预测器等）防止模型"塌缩"（collapse，即所有输出都变成同一个常数向量这种平凡解）。
- 代表：**BYOL**、**SimSiam**、**DINO / DINOv2 / DINOv3**、**Barlow Twins**、**VICReg**
- 进阶（架构层面的统一）：**JEPA (Joint-Embedding Predictive Architecture)**：I-JEPA、V-JEPA、V-JEPA2

下面我们逐个算法拆解原理。

### 五、生成式方法详解

#### 5.1 自编码器家族（AE → DAE → MAE）

最朴素的自编码器：Encoder 把输入 x 压缩成低维 z，Decoder 再把 z 还原成 x̂，损失是重建误差 ‖x − x̂‖²。问题是模型可能只学会"复制"，学不到语义。

**去噪自编码器（Denoising AE）**：故意给输入加噪声/遮挡，强迫模型学习更鲁棒的表示。

**MAE (Masked Autoencoder, He et al. 2021)** 是这一脉络在 ViT 时代的巅峰之作：
- 把图像切成 patch，**随机遮住 75% 的 patch**（遮挡比例很高，这是关键设计）；
- 只把**可见的 25% patch** 送入一个较大的 Encoder（ViT）；
- 一个**轻量级 Decoder** 接收 Encoder 输出 + 掩码 token，重建被遮挡区域的像素；
- 训练完成后，**只保留 Encoder** 用于下游任务，Decoder 直接丢弃。

直觉：图像具有很强的空间冗余性，遮住 75% 依然可以靠上下文推断，这个"推断"过程迫使模型学习图像的整体结构和语义，而不是简单插值。

**BEiT** 与之类似，但重建的不是像素，而是一个预训练好的图像 tokenizer（如 dVAE）生成的离散视觉词元，思路上更接近 BERT。

#### 5.2 NLP 的自监督：BERT 与 GPT

- **BERT**：Masked Language Model（MLM），随机遮住 15% 的词，让模型根据上下文双向预测被遮住的词；额外还有 Next Sentence Prediction 任务。这本质上和 MAE 是同一族思想在文本上的实现。
- **GPT 系列**：用自回归的 Next Token Prediction 作为 pretext task——给定前面所有词，预测下一个词。这是最简单也最"暴力"的自监督形式，却是当今大语言模型的基石。

**语音领域**：wav2vec / wav2vec2.0 采用类似 CPC + 掩码预测的组合，对音频片段做遮挡后预测其量化表示。

### 六、对比式学习详解

#### 6.1 核心数学：InfoNCE Loss

对比学习的通用损失函数是 **InfoNCE**：

```
L = -log [ exp(sim(z_i, z_i^+)/τ) / Σ_j exp(sim(z_i, z_j)/τ) ]
```

其中 z_i 和 z_i^+ 是同一样本的两个增强视角（正样本对），z_j 遍历所有负样本，sim 通常是余弦相似度，τ 是温度系数（控制分布的尖锐程度）。

直觉：这其实是一个"在一堆干扰项里认出正确答案"的多分类问题（类似 softmax 分类），做对了就说明模型能区分"这是同一个物体的不同视角"和"这是不同物体"。

#### 6.2 SimCLR（Chen et al., 2020）

流程非常简洁，是理解对比学习最好的入门算法：

1. 对一张图片 x，用两种随机数据增强（裁剪、颜色抖动、高斯模糊、翻转等）生成两个视角 x_i, x_j；
2. 用同一个 Encoder f(·)（如 ResNet）分别编码得到 h_i, h_j；
3. 再通过一个小的 MLP 投影头 g(·) 得到 z_i, z_j（**投影头是关键 trick**，实验发现在投影后的空间算 loss，效果远好于直接在 encoder 输出上算）；
4. 一个 batch 内所有其他样本（及其增强）都作为负样本，计算 InfoNCE loss；
5. 预训练完成后，**扔掉投影头 g**，只保留 encoder f 做下游任务。

**SimCLR 最大的痛点**：负样本数量强烈依赖 batch size（原论文用了 4096 甚至更大的 batch），普通实验室很难复现。

#### 6.3 MoCo（Momentum Contrast, He et al., 2020）

为了解决 SimCLR 依赖超大 batch 的问题，MoCo 提出：
- 维护一个**队列（Queue）** 作为负样本库，不需要一个 batch 里塞下所有负样本；
- 用一个**动量编码器（Momentum Encoder）** θ_k = m·θ_k + (1-m)·θ_q 缓慢更新，保证队列里的负样本特征的"一致性"（因为编码器如果变化太快，队列里旧的负样本特征就和新样本不可比了）。

MoCo v2/v3 进一步融合了 SimCLR 的投影头、更强的数据增强等技巧。

#### 6.4 CPC（Contrastive Predictive Coding）

更早的对比学习思路，常用于序列数据（音频、文本、视频）：用过去的上下文预测未来的表征，通过 InfoNCE 区分"真实未来"和"随机采样的负样本未来"。

### 七、非对比式 / 自蒸馏方法详解（这是目前最主流、效果最好的一条路线）

对比学习依赖大量负样本，工程复杂。研究者发现：**其实不需要负样本，只要架构设计得当，也能防止模型学到平凡解（塌缩）。**

#### 7.1 为什么会"塌缩"（Collapse）？

如果只是简单地让两个视角的特征尽量接近（minimize ‖z_i - z_j‖²），模型最简单的"作弊"解法就是让 encoder 对所有输入都输出同一个常数向量——这样损失永远是 0，但学不到任何有用信息。所有非对比方法的核心，就是**设计机制来防止这种塌缩**。

#### 7.2 BYOL（Bootstrap Your Own Latent, Grill et al., 2020）

BYOL demonstrated that an EMA target network combined with a predictor head suffices to prevent representational collapse without any negative pairs。具体结构：

- **在线网络（Online）**：Encoder + 投影头 + **预测器（Predictor）**，参数 θ 用梯度下降更新；
- **目标网络（Target）**：结构和在线网络一样（除了没有 predictor），但参数 ξ 是在线网络参数的**指数滑动平均（EMA）**，不接收梯度（**stop-gradient**）；
- 损失：让在线网络对视角 A 的预测输出，去逼近目标网络对视角 B 的输出（余弦距离），反之亦然（对称计算）。

**为什么这样不会塌缩？** 直觉解释有几种，比较主流的是：predictor + stop-gradient 打破了"两个分支完全对称"的结构，使得梯度更新不会简单地把两边同时拉向常数；同时 EMA 目标网络提供了一个缓慢变化、相对稳定的"锚点"。（这个问题至今仍有理论工作在深入研究）

#### 7.3 SimSiam（Chen & He, 2021）

进一步做减法：**连动量编码器都不要了**，两个分支共享同一组权重，唯一的关键设计只剩：
1. Predictor（只加在一个分支上，制造不对称）
2. **Stop-gradient**（另一个分支的梯度不回传）

结论令人惊讶：仅凭 stop-gradient + 不对称结构就足以防止塌缩，说明 BYOL 里的动量编码器可能不是防塌缩的必要条件，而更多是稳定训练/提升效果的因素。

#### 7.4 Barlow Twins 与 VICReg（信息论/正则化流派）

这两个方法完全抛弃了"预测器 + stop-gradient"的技巧，转而**直接在损失函数里加正则项**来防止塌缩：

- **Barlow Twins**：让两个视角特征的**互相关矩阵尽量接近单位矩阵**——对角线元素（同一维度的相关性）逼近1（保证不变性），非对角线元素（不同维度之间的相关性）逼近0（去除冗余，鼓励特征各维度独立，这样才不会所有维度都塌缩成一样的值）。

- **VICReg (Variance-Invariance-Covariance Regularization)**：Variance-Invariance-Covariance Regularization (VICReg) provides an alternative collapse-prevention mechanism via explicit regularization of the embedding covariance matrix, making the whitening objective differentiable and interpretable。它的损失由三项组成：
  - **Invariance（不变性）**：两个视角特征的均方误差要小（保证语义一致）；
  - **Variance（方差）**：强制每个特征维度在 batch 内的标准差不能太小（直接防止所有样本坍缩到一个点）；
  - **Covariance（协方差）**：惩罚不同维度之间的协方差，鼓励特征去冗余。

这类方法的好处是：不需要负样本，不需要动量编码器，不需要 predictor，**完全靠显式的统计正则项**保证表示的多样性，数学上也更容易分析。

#### 7.5 聚类式方法：DeepCluster、SwAV

思路是把对比学习的"实例判别"换成"聚类分配"：先对特征做聚类（如 K-means）得到伪标签，再用这些伪标签训练分类器，交替迭代。SwAV 进一步用 Sinkhorn-Knopp 算法在线做"聚类分配的一致性"对比，避免了传统两阶段方法的低效。

#### 7.6 DINO / DINOv2 / DINOv3（自蒸馏 + Vision Transformer 的巅峰）

**DINO (self-**DI**stillation with **NO** labels)** 结构类似 BYOL，但用 **teacher-student 自蒸馏**框架，并引入了：
- **Multi-crop 策略**：生成多个大尺度全局视角和多个小尺度局部视角，让 student 从局部预测 teacher 的全局输出，强化"局部到全局"的语义一致性；
- **Centering + Sharpening**：对 teacher 的输出做中心化和温度锐化，代替 Barlow Twins/VICReg 式的显式正则，来防止塌缩。

**DINOv2**（Meta, 2023）把这一套方法**规模化**：DINOv2's robustness is attributed to curated dataset construction and multi-crop augmentation。它的架构是两个同步运行的 Vision Transformer 网络：学生和教师，两者都接受图像（或图像 patch），但在掩码方式和权重更新机制上不同：教师始终接收未掩码的完整图像视角，学生输入可以包含随机掩码的 patch；每个编码器包含 patch 级投影头生成逐patch特征，以及作用于 CLS token 的图像级"原型"头；每次学生更新后，教师权重按 EMA 规则更新，这一架构确保只有学生网络接收梯度，教师作为缓慢变化的目标网络，稳定自监督训练。通过在 1.42 亿张精选图片（LVD-142M）上训练，DINOv2 with registers 是目前图像自监督学习领域的最先进模型。

到了 2025 年，Meta 又推出 **DINOv3**，在计算机视觉领域，基础模型已成为通过单一可复用模型实现跨任务跨领域泛化的核心构件，而自监督学习(SSL)是训练此类模型的强大方法，它直接从原始像素数据学习，利用图像中模式的自然共现关系；与需要图像配对高质量元数据的弱监督和全监督预训练方法不同，SSL能够在海量原始图像集合上进行训练。DINOv3 目前和 DINOv2 一起被用作图像编码器基线来做密集特征评估。

### 八、JEPA：LeCun 力推的下一代自监督架构

#### 8.1 为什么要提出 JEPA？

Yann LeCun 认为，生成式方法（如像素级重建 MAE）有个问题：**强迫模型在像素空间做精确重建，会浪费大量算力在预测不重要的细节（如具体纹理、光照噪声）上**，而对比学习又依赖数据增强的设计技巧和负样本工程。他提出了统一框架 **JEPA (Joint-Embedding Predictive Architecture)**：不在原始像素空间做预测，而是**在抽象的表示空间里做预测**——用一部分输入的表示，去预测另一部分输入的表示（而非重建原始像素），这样模型可以自动忽略不可预测的细节，只保留可预测的高层语义。

#### 8.2 I-JEPA（图像版）与 V-JEPA（视频版）

- **I-JEPA**：把图像切成 patch，用 context encoder 编码可见区域，用 target encoder（EMA 更新，类似 BYOL/DINO）编码目标区域，然后用一个 predictor **在特征空间**预测目标区域的表示，而不是重建像素。
- **V-JEPA / V-JEPA 2**：把这个思想扩展到视频。该工作在自监督假设的基础上，学习能够主要通过观察捕捉世界背景知识的世界模型，具体而言，利用联合嵌入预测架构(JEPA)，通过在学习到的表示空间中进行预测来学习。与完全从交互数据中学习的方法不同，自监督学习使得可以利用互联网规模的视频——这些视频描绘了状态序列但没有直接观察到动作——来学习表示视频观察并学习世界动态的预测模型。

V-JEPA 2 的效果非常亮眼：V-JEPA 2 在冻结设置下表现出有竞争力的性能，在所有测试基准上都优于 DINOv2、SigLIP 和 Perception Encoder (PE)，唯独在 PerceptionTest 上略逊于 SigLIP 和 PE；这种提升在专注于时间理解的基准 MVP、TemporalBench 和 TVBench 上尤为明显。更进一步，它甚至可以直接用于机器人控制：研究者在两个不同实验室的 Franka 机械臂上零样本部署了 V-JEPA 2-AC，利用图像目标规划实现了物体的抓取和放置，且完全没有采集这些环境下的机器人数据，也没有任何任务特定训练或奖励，这项工作证明了基于网络规模数据的自监督学习结合少量机器人交互数据，可以产生能够在物理世界中进行规划的世界模型。

最新的 **V-JEPA 2.1**（2026年初）进一步聚焦于密集特征：尽管进展迅速，学习既能同时保留密集时空结构（用于定位、几何和跟踪）又能捕捉动态并支持高层理解（用于高级识别）的表示，仍然是一个开放挑战。

#### 8.3 最新理论进展：LeJEPA

2025 年底，LeCun 团队进一步推出 **LeJEPA**，试图从理论上简化并统一非对比自监督学习的设计：Lejepa: Provable and scalable self-supervised learning without the heuristics，目标是去掉动量编码器、stop-gradient、centering 等各种"经验性trick"，用更简洁、有理论保证的方式训练 JEPA 类模型。这代表了这个领域正在从"炼丹式的技巧堆叠"走向"理论驱动的简化设计"。

### 九、多模态自监督：CLIP 及其之后

CLIP（Radford et al., 2021）用图文对比学习（图片和其对应的文本描述互为正样本，其他图文对为负样本）训练，本质上也是对比式自监督的一种（虽然用了"弱监督"的图文配对信息，而非纯无标签数据）。这类图文对比预训练模型（CLIP、SigLIP2 等）如今也是视觉基础模型的重要一支，常和 DINOv2/V-JEPA 等纯自监督模型做对比评测。

多模态的进一步拓展还包括 **AM-RADIO** 等蒸馏融合方法：AM-RADIO 将完全监督的 SAM、弱监督的 CLIP 和自监督的 DINOv2 结合成一个统一骨干网络，代表了"多种监督信号融合"的新趋势。

---

### 十、防止塌缩机制大总结（面试高频考点）

| 方法 | 防塌缩机制 |
|---|---|
| SimCLR / MoCo | 显式负样本（InfoNCE） |
| BYOL | Predictor + Stop-gradient + 动量编码器（不对称结构） |
| SimSiam | Predictor + Stop-gradient（无动量编码器） |
| Barlow Twins | 互相关矩阵逼近单位矩阵 |
| VICReg | 显式方差正则项 + 协方差正则项 |
| DINO/DINOv2 | Teacher centering + Sharpening + 动量更新 |
| SwAV | 在线聚类分配 + Sinkhorn 平衡约束 |
| MAE/BERT | 天然不存在塌缩问题（重建任务本身有明确目标） |

### 十一、实践入门建议（如何真正上手）

1. **先跑通最简单的代码**：建议从 SimSiam 或 SimCLR 的开源实现开始（结构最简单，几十行伪代码就能讲清楚），CIFAR-10/STL-10 上小规模复现。
2. **理解数据增强的重要性**：对比学习/自蒸馏方法对数据增强策略极其敏感（随机裁剪、颜色抖动的强度直接决定效果好坏），这是最容易被忽视的细节。
3. **注意 batch size 与学习率的关系**：对比学习通常需要较大 batch，配合 LARS 优化器和 warmup + cosine 学习率调度。
4. **评估时优先用 linear probing / kNN**：这样能最快判断预训练特征质量，而不用等到下游微调全部收敛。
5. **动手做一次"消融实验"**：比如去掉 predictor 或去掉 stop-gradient，亲眼看到模型 collapse（所有输出方差骤降为0），这是理解这个领域最好的方式。

### 总结

自监督表征学习的本质，就是**"用数据自己给自己出考题"**——通过设计巧妙的代理任务（掩码重建、视角对比、表示空间预测等），让模型在没有人工标签的情况下学到有用的语义特征。整个领域的发展脉络清晰可循：从早期依赖负样本的对比学习，走向不需要负样本但需要精巧架构设计的自蒸馏方法，再到如今更强调"在抽象表示空间做预测"而非"在像素空间做重建"的 JEPA 范式，以及试图去除经验性 trick、走向理论化的最新工作（如 LeJEPA）。理解了这条主线，再去看具体论文的公式和消融实验，会容易很多。

## 第〇章：坐标系——这个谱系在整个机器学习地图里的位置

回顾前几轮我们确立的划分：静态数据集上，先问"y是不是外部人工语义标注"，是则监督学习；不是的话，再问"任务目标是不是重建/生成原始信号x本身"，是则DGM，不是则本讲义的主角——**联合嵌入类自监督表征学习（Joint-Embedding Self-Supervised Learning, JE-SSL）**，JEPA是这个谱系晚近、也是目前理论上最干净的一个成员。

这个谱系的所有成员共享一个共同祖先——**孪生网络（Siamese Network）**这一架构思想：用共享权重的编码器分别处理一对相关的输入，比较它们的输出。90年代LeCun等人最早用孪生网络做签名验证，这个"比较两个视图在表征空间里是否一致"的思路，一路演化到今天的DINO和JEPA，是贯穿整个谱系的一根主线。

---

## 第一章：统一目标——精确的数学规范

### 1.1 输入输出是什么

给定一个**无标注**数据集 $\{\omega_i\}_{i=1}^N \sim p(\omega)$（图片、视频、句子……），定义两个**视图提取函数**（可以是人工设计的数据增强，也可以是从同一原始数据里天然切分出的两部分）：

$$x = a(\omega), \quad y = b(\omega)$$

例如：SimCLR里a、b是两种随机数据增强；SimCLR通过一个随机数据增强模块把任意给定的数据样本随机变换，产生同一个样本的两个相关视图，记作正样本对。CPC里x是过去的片段、y是未来的片段；I-JEPA里x是图像的context block、y是被遮盖的target block。**注意：这里(x,y)都来自同一份无标注数据ω，不存在任何外部语义标注。**

### 1.2 要学什么——编码器 f，而不是完整的生成模型

目标是学一个编码器（也叫backbone）：

$$f_\theta: \mathcal{X} \to \mathbb{R}^d, \quad s_x = f_\theta(x)$$

**训练完成后，我们要的产出物只有 $f_\theta$ 这一个函数**，训练时用到的projector、predictor、negative samples、聚类原型等等辅助结构在下游应用时全部被丢弃——这是和DGM最大的操作性区别：DGM训练完要保留整个生成过程（解码器/去噪网络/流），JE-SSL训练完只保留一个"特征提取器"。

### 1.3 什么叫"好的表征"——评估协议，而非似然

DGM用对数似然/FID/生成样本质量来评估好坏；JE-SSL没有这些概念，用的是**下游任务代理评估**：

- **线性探针（Linear Probing）**：冻结 $f_\theta$，只在其输出上训练一个线性分类器，看能达到多高的下游分类准确率——这是最常用、最重要的评估指标
- **k近邻（k-NN）评估**：直接在表征空间里用最近邻分类，不训练任何新参数，衡量表征空间本身的几何质量
- **微调（Fine-tuning）迁移**：把 $f_\theta$ 当作下游任务（检测、分割等）的初始化权重
- **半监督/低数据量场景**：只用1%的标签微调，衡量表征的数据效率——SimCLR就是用这个指标秀实力的：在只用1%标签微调时达到85.8%的top-5准确率，用少了100倍的标签超过了AlexNet。

### 1.4 总体架构模板——一个通用的"填空题"

几乎所有JE-SSL方法都可以塞进下面这个统一模板，区别只在于每个空怎么填：

$$\mathcal{L}(\theta,\phi) = D\big(\,g_\phi(P_1(f_{\theta_1}(x))),\; \text{sg}[P_2(f_{\theta_2}(y))]\,\big) + \lambda R(\cdot)$$

- $f_{\theta_1}, f_{\theta_2}$：两支编码器，可以共享权重（孪生），也可以一支是另一支的EMA（动量/教师-学生）
- $P_1, P_2$：projector（把backbone特征投影到做loss的空间），SimCLR明确指出：在表征和对比损失之间引入一个可学习的非线性变换，能显著提升表征质量。
- $g_\phi$：predictor（可选，用于打破架构对称性）
- $\text{sg}[\cdot]$：stop-gradient（可选，只在部分分支上使用）
- $D(\cdot,\cdot)$：距离/相似度度量，可以是余弦相似度、L2距离，也可以是交叉熵（把相似度当logits）
- $R(\cdot)$：显式防坍缩正则项（可选）

**这个通用模板里到底该怎么填空，就是整个谱系历史演化要讲的故事。**

---

## 第二章：统一难点——表征坍缩（Representational Collapse）

### 2.1 为什么会坍缩——数学上的"作弊解"

考虑最朴素的目标：让正样本对的表征尽量接近，即最小化 $\|s_x - s_y\|^2$。这个损失函数存在一个全局最优的**平凡解（trivial solution）**：

$$f_\theta(\cdot) \equiv c \quad (\text{常数})$$

任何输入都被映射到同一个点，损失恒为0，但模型没有学到任何关于输入内容的信息——这就是**完全坍缩（complete collapse）**。SwAV的官方实现里明确记录了这个现象：坍缩会在训练开始时发生，无法收敛，当所有样本被映射到同一个表征时就会发生坍缩，此时卷积网络无论输入是什么都输出相同结果，变成了一个常数函数。

### 2.2 坍缩的隐蔽变体——维度坍缩（Dimensional Collapse）

比完全坍缩更隐蔽的问题是：即使表征向量看起来"不同"，它们也可能全部躺在一个低维子空间里（比如d维输出实际只用了3个有效维度），这同样会让下游线性探针的表现大打折扣，因为大部分坐标轴都是冗余的、不携带独立信息。这正是VICReg、Barlow Twins这类方法要专门用协方差正则化去对付的问题。

### 2.3 这就是JE-SSL的"配分函数"

在DGM谱系里，所有困难最终都归结到"配分函数不可计算"；在JE-SSL谱系里，所有困难最终都归结到"如何在不塌陷到平凡解的前提下让正样本对靠近"。**这条难题贯穿整个历史，每一代方法的核心创新点几乎都可以概括为"用一种新方式防止坍缩"**，这正是下面要按历史脉络展开的主线。

---

## 第三章：史前时代——从生成式重建到人工设计的"伪标签"任务

### 3.1 自编码器：过渡形态

经典（确定性）自编码器让编码器-解码器对重建输入本身：$\hat x = \text{Dec}(\text{Enc}(x))$，$y=x$。它严格来说属于DGM谱系的边界成员（VAE是它的概率化版本），但它同时也是表征学习最早的雏形——因为瓶颈层的编码本身就可以被当作特征使用。它的问题是：像素级重建会强迫模型花费大量容量去刻画与语义无关的细节（纹理、光照、噪声），这正是后来JEPA要刻意避免"在像素空间做预测"的历史根源。

### 3.2 Pretext Task时代（约2014-2018）

这一代方法的思路是：既然没有人工标签，那就**用一条确定性规则从数据本身自动生成一个"伪标签"**，把自监督问题伪装成一个标准的监督分类问题去解。典型代表：

- **旋转预测（RotNet）**：把图片随机旋转0°/90°/180°/270°，让网络做四分类，"标签"就是旋转角度本身
- **拼图任务（Jigsaw Puzzle）**：把图片切成九宫格打乱，让网络预测排列方式
- **上下文预测（Context Prediction）**：给定一个图像patch和它周围的一个patch，预测两者的相对位置——MoCo论文把这个思路明确归入其对比工作的历史脉络，指出定义损失函数的常见方式是衡量模型预测与固定目标之间的差异，比如按预先定义的类别（如八个方位、颜色分类）用交叉熵或基于边界的损失进行分类。
- **图像上色（Colorization）**：从灰度图预测颜色

**这一代方法的根本局限**：伪标签任务是人工设计的、和最终想要的语义表征之间隔着一层"代理"，模型很容易学到一些能解决伪任务、但对下游任务无用的捷径特征（比如判断旋转角度只需要看边缘纹理，不需要理解物体是什么）。这直接催生了下一代——**不再依赖具体人工任务，而是直接在表征空间里定义"相似/不相似"这一更本质目标**的对比学习。

---

## 第四章：对比学习时代——用"负样本"对抗坍缩

### 4.1 核心思路：InfoNCE

对比学习解决坍缩问题的核心武器是**负样本**：不仅要求正样本对表征接近，还显式地要求它和一批"负样本"的表征疏远，这样"把所有输入映射到同一点"就不再是零损失的解（因为正负样本会被映射到同一点，负样本项的损失飙升）。

数学上，最有影响力的损失函数是CPC提出的**InfoNCE**：这一目标函数被称为InfoNCE，其优化过程本质上是在做正样本的分类正确率意义下的交叉熵损失，即从一组包含1个正样本和N-1个来自"提议"分布的负样本构成的集合中，正确挑出正样本。CPC的原始动机是通过强大的自回归模型在潜在空间中预测未来来学习表征，用一个概率性对比损失迫使潜在空间去捕获对预测未来样本最有用的信息，同时这个负采样机制也让模型在计算上变得可行。

InfoNCE的标准形式（以SimCLR记号为例）：
$$\mathcal{L}_{\text{InfoNCE}}^{(i,j)} = -\log \frac{\exp(\text{sim}(z_i,z_j)/\tau)}{\sum_{k=1}^{2N}\mathbb{1}_{[k\neq i]}\exp(\text{sim}(z_i,z_k)/\tau)}$$

这就是把"最大化互信息下界"问题转化成了"在一堆候选里做N+1分类"的交叉熵问题——van den Oord等人后来指出InfoNCE目标可以用来评估互信息，将其解释为互信息的一个变分下界。

### 4.2 SimCLR——把对比学习做到极简

SimCLR的贡献不在于提出新的loss，而在于系统性地做消融实验，找出了让对比学习真正work的三个关键要素：数据增强的组合方式对定义有效的预测任务起到关键作用；在表征和对比损失之间引入一个可学习的非线性变换（即projector）能大幅提升表征质量；对比学习相比监督学习更依赖大batch size和更长的训练时间。这三点直接来自于对InfoNCE负样本机制本身特性的深刻理解：batch越大，负样本越多、越难，对比信号越强；而projector的作用是让backbone特征本身不必被迫去满足对比损失这个略显"粗暴"的几何约束，从而保留更丰富的语义信息——一个耐人寻味的细节是，projector之前的表征质量总是优于projector之后。

### 4.3 MoCo——用队列和动量解耦负样本数量与batch size

SimCLR的负样本数量被死死绑定在batch size上（batch越大，显存开销越大），MoCo提出了另一条路：把对比学习看成一个查字典的过程,用一个队列和一个动量更新的编码器构建了一个动态字典，从而能够即时构建一个大且一致的字典,以促进对比无监督学习。具体来说，MoCo维护一个队列存储历史批次编码过的key，key编码器的参数不通过反向传播更新，而是用query编码器参数的指数滑动平均来更新——**这个"EMA更新的target/teacher网络"的设计，正是日后BYOL、DINO、I-JEPA的target encoder的直接祖先**，这条线索非常重要，请记住它。

### 4.4 对比学习的根本局限

对比学习虽然巧妙地用负样本解决了坍缩问题，但代价高昂：需要大量负样本才能获得好的效果，且负样本数量随所需表征维度大致呈指数增长（这是LeCun在批评对比方法时反复强调的一点）。此外还存在"假负样本"问题（两张不同图片碰巧语义相同，却被强行推远）。**这就逼出了下一代方法的核心问题：能不能完全不要负样本、只靠正样本对就避免坍缩？**

---

## 第五章：聚类路线——用"分配的一致性"替代逐点对比

### 5.1 DeepCluster——离线交替优化

DeepCluster换了一个角度看问题：不去比较单个样本对，而是先对整个数据集的特征做一次**k-means聚类**，把聚类得到的类别当作"伪标签"，再用这些伪标签训练一个标准分类器，如此交替迭代：DeepCluster迭代地用标准聚类算法k-means对特征分组，并将得到的分配结果作为监督信号来更新网络权重。这个"交替聚类-分类"的过程天然地存在坍缔到平凡解的风险——判别式聚类即使在线性模型上也会出现这个问题，通常需要靠限制或惩罚每个簇的最小样本数来解决。DeepCluster的局限是它是离线的：需要定期对全数据集重新做一遍前向传播和聚类，效率低，难以scale到超大数据集。

### 5.2 SwAV——把聚类做成在线的、可对比的

SwAV把DeepCluster的思路改造成了在线版本，同时巧妙地绕开了显式负样本比较：对比方法通常在计算上很吃力，因为需要做大量显式的成对特征比较，而SwAV提出了一种替代算法，通过对数据聚类、同时增强不同视图之间聚类分配的一致性来避免这个问题。具体做法是"交换预测"：先把每个视图的特征分配到一组可学习的原型（prototype）向量上得到编码（code），再用一个视图的表征去预测另一个视图的编码：具体来说是提出一个简单的"交换"预测问题：用一个视图的表征去预测另一个视图的编码。为了防止所有样本坍缩到同一个编码，SwAV加入了**equipartition（等分）约束**（用Sinkhorn-Knopp算法在线求解最优传输问题），强制一个batch内的样本被均匀地分配到各个簇：这个等分约束确保一个batch内不同图片的编码是不同的，从而防止了坍缔。SwAV还引入了multi-crop技巧，用更多、更小的裁剪视图在几乎不增加计算量的情况下提升性能。

**技术脉络总结**：聚类路线用"batch内编码必须均匀分布在K个原型上"这个**结构性约束**替代了对比学习里"必须显式推开负样本"这个**逐点约束**——这是防坍缩手段第一次从"负样本"进化到"结构性约束"，为下一代彻底抛弃负样本的方法铺平了道路。

---

## 第六章：非对比路线——打破架构对称性，彻底抛弃负样本

这一代方法要回答的问题是："如果只用正样本对、完全不用负样本、也不聚类，会不会必然坍缩？"答案出人意料：**不一定**，只要在架构上引入恰当的不对称性。

### 6.1 BYOL（Bootstrap Your Own Latent）

BYOL的结构：一个**在线网络（online network）**由encoder+projector+**predictor**组成；一个**目标网络（target network）**结构相同但没有predictor，参数是在线网络参数的EMA（这条设计血统直接继承自MoCo的动量编码器）。损失是让在线网络通过predictor预测出的表征去逼近目标网络（梯度被stop-gradient截断，不反传）的输出表征。**这里没有任何负样本**，理论上"平凡常数解"仍然是损失为零的解，但实践中BYOL通过predictor+stop-gradient+EMA target这套不对称组合，观测上稳定地避免了坍缩（这一现象为什么成立在学术界引发过大量后续分析，比如与batch normalization、predictor的隐式贡献相关的讨论，至今仍不算是被彻底、干净地从第一性原理证明的问题）。

### 6.2 SimSiam——做减法，找出真正必要的成分

SimSiam的贡献是消融实验：它证明了BYOL里的动量编码器（EMA target）其实不是防止坍缩的必要条件，**只要有stop-gradient和predictor这两个不对称性组件，即使target网络和online网络实时共享全部权重，也不会坍缩**。这把BYOL的"配方"精简到了极致，也让研究者意识到：stop-gradient这个看似简单的操作，本质上是在把一个联合优化问题转化成一种类似EM算法的交替优化，从而避开了平凡解。

---

## 第七章：自蒸馏路线——DINO家族，与JEPA血缘最近的分支

### 7.1 DINO

DINO把BYOL的"在线-目标"架构改造成了显式的"学生-教师（student-teacher）"自蒸馏框架：学生网络和教师网络（EMA更新，同MoCo/BYOL血统）分别处理同一张图的不同裁剪视图，输出经过softmax归一化成一个概率分布，损失是两者输出分布之间的交叉熵（跟知识蒸馏的形式一样，只是"教师"和"学生"是同一个网络的不同历史平均版本）。DINO防止坍缩靠两个技巧：**centering**（把教师的输出减去一个滑动平均的中心，防止某一维度独占输出）和**sharpening**（教师侧用更低的softmax温度，让输出分布更尖锐、更有区分度），二者共同起到了类似"batch normalization + equipartition约束"的平衡作用。DINO最大的意外发现是：用ViT做backbone训练出的自注意力图，无监督地涌现出了清晰的物体分割边界，这是它区别于此前所有方法的标志性成果。

**这正是你说"JEPA架构像DINO"的根源**：I-JEPA的context encoder/target encoder结构，与DINO的student/teacher结构，都直接继承自MoCo开创的"在线网络+EMA教师网络+stop-gradient"这套骨架，只是DINO是在**同一张图的不同增强视图**之间做自蒸馏，而I-JEPA是在**同一张图的不同空间区域**（context block预测target block）之间做latent空间的回归，二者是同一套防坍缩工程学在不同任务设定下的两次应用。

### 7.2 DINOv2

DINOv2是DINO在数据规模、模型规模、训练工程上的一次系统性升级：更大规模、更精心筛选去重的数据pipeline，结合了DINO的自蒸馏损失、iBOT式的patch级掩码预测损失，以及KoLeo正则化（鼓励一个batch内的特征分布更均匀地铺开，进一步对抗维度坍缩）等多种技术的组合拳，目标是不经过任何微调就能产出通用的、可直接当作下游任务冻结特征使用的视觉backbone。

## 第八章：显式正则化路线——把"防坍缩"这件事直接写进损失函数里

前面几代方法（负样本、聚类约束、stop-gradient+EMA、centering+sharpening）都是**用架构或工程技巧隐式地防止坍缩**。这一代方法换了个哲学：**直接对表征本身的统计性质（方差、协方差）写一个显式的正则项**，不需要负样本，不需要任何不对称的动量/predictor结构。

### 8.1 Barlow Twins

灵感来自神经科学家Horace Barlow提出的"冗余消除原理"：Barlow Twins计算两个孪生分支输出特征之间的**互相关矩阵（cross-correlation matrix）**，让这个矩阵尽量接近单位矩阵——对角线元素（同一维度在两个视图间的相关性）逼近1（保证不变性/一致性），非对角线元素（不同维度之间的相关性）逼近0（保证各维度互不冗余，直接对抗维度坍缩）。这个损失天然地同时防止了完全坍缩（对角线为1排除了常数解）和维度坍缩（非对角线为0排除了低秩解），而且不需要大batch、不需要负样本、不需要动量编码器、不需要非对称predictor——是这个谱系里"配方"最简洁的方法之一。

### 8.2 VICReg（Variance-Invariance-Covariance Regularization）

VICReg把这个思路写得更加显式，直接用三个独立的loss项对准坍缇问题的三个侧面：
- **Variance项**：对每个特征维度，鼓励其在batch内的标准差不低于某个阈值——这是防止完全坍缩最直接的手术刀
- **Invariance项**：让正样本对的表征尽量接近（这是"有用信息"这一目标本身）
- **Covariance项**：鼓励特征不同维度之间的协方差趋近于0——这是防止维度坍缩的手术刀

VICReg的意义在于：它把此前所有方法里"隐式地、靠架构技巧侥幸避免的坍缩"，转化成了"显式地、可以直接验证是否满足的数学约束"，这也正是后来LeJEPA的SIGReg正则化项在I-JEPA框架里所延续、并从理论上进一步严格化的思路（用各向同性高斯分布作为可证明的最优嵌入分布目标）。

## 第九章：JEPA——从像素预测到"表征空间"预测的最终一跃

### 9.1 为什么放弃在像素空间做预测

这个谱系最后一次范式跳跃的动机，是意识到：如果预测目标是原始像素（比如Masked Autoencoder，MAE，直接重建被遮住的像素块），模型会被迫花费大量容量去刻画与语义理解无关的低层细节（纹理噪声、光照微小变化），JEPA适用于那些像素级细节确实无关紧要、需要抽象化的领域，正因如此才选择在潜在表征空间里做预测，而不是在输入空间。这个思路和自编码器的历史局限（第3.1节）遥相呼应，只是这次给出的答案不是"回到对比学习"，而是"预测目标本身也用一个编码器抽象化"。

### 9.2 I-JEPA架构——把DINO的骨架接到"masked prediction"这个任务上

I-JEPA由三部分组成：**上下文编码器**处理可见的context block；**目标编码器**（参数是上下文编码器的EMA，不通过反向传播更新——这正是MoCo/BYOL/DINO一脉相承下来的target网络设计）处理完整图像并抽取出多个被遮盖的target block的表征；**预测器**从上下文表征加上位置信息，预测各个target block的表征。损失是预测表征和目标编码器给出的真实表征之间的L2距离，目标编码器一侧全程stop-gradient。它采用了multi-block masking策略：遮盖若干个较大的、信息丰富的目标区域，同时提供一个足够大的上下文区域，避免了任务因过于容易而学不到语义、或过于困难而无法优化。

### 9.3 V-JEPA / V-JEPA 2——扩展到时空维度

V-JEPA把同样的思路扩展到视频：通过在潜在空间预测被遮盖的时空区域的表征来学习视频表征，本质上是把I-JEPA的"空间掩码"换成了"时空联合掩码"（同时遮盖若干帧里的若干空间区域），迫使模型学习既包含语义又包含运动/时序动态的表征。

### 9.4 LeJEPA/SIGReg——理论收官

JEPA系方法此前一直依赖若干经验性的启发式技巧（stop-gradient、EMA target、mask策略的精心调参）才能稳定训练。LeJEPA的贡献是提出SIGReg正则化，从理论上证明各向同性高斯分布是嵌入空间的最优分布形态，并据此设计出一个不再需要stop-gradient、不再需要teacher-student网络、不再需要memory queue这类启发式组件的单一训练目标——这是这条历史脉络里，"防坍缩机制"从纯工程直觉走向理论可证明性的最新一步，呼应了VICReg当年"把防坍缩显式写进loss"的思路，但给出了更强的理论保证。

### 9.5 一张图看清JEPA的"混血"身份

| JEPA继承自谁 | 继承了什么 |
|---|---|
| MoCo | EMA动量target编码器、stop-gradient |
| BYOL/SimSiam | predictor+非对称结构防坍缩 |
| DINO | student(context)-teacher(target)自蒸馏骨架 |
| Masked modeling（BERT/MAE一脉） | "遮盖一部分、预测另一部分"的任务形式 |
| VICReg/LeJEPA | 显式统计正则化确保表征多样性、理论上的最优分布刻画 |

**这就完整回答了你最初的直觉：JEPA像DINO不是巧合，而是同一条"用EMA教师+stop-gradient防坍缩"技术路线的两次不同任务上的应用；但JEPA同时也是对比学习、聚类、非对比、正则化这四条防坍缩技术路线在历史尽头的一次集大成。**

## 第十章：统一总表——四条防坍缩技术路线，及其历史演化关系

| 技术路线 | 防坍缩机制 | 代表方法 | 是否需要负样本 | 是否需要非对称结构/动量 |
|---|---|---|---|---|
| ① 对比学习 | 显式推开负样本，坍缩会使负样本项loss爆炸 | InstDisc, CPC, SimCLR, MoCo | 需要，且需求量大 | MoCo需要动量队列 |
| ② 在线聚类 | 强制batch内簇分配均匀（equipartition约束） | DeepCluster, SwAV | 不需要显式负样本 | 不需要动量，但SwAV维护可学习原型 |
| ③ 非对称结构+自蒸馏 | stop-gradient+predictor打破对称，配合EMA target阻止trivial解 | BYOL, SimSiam, DINO, DINOv2 | 不需要 | 需要（EMA target/predictor/centering-sharpening） |
| ④ 显式统计正则化 | 直接约束方差不能太小、协方差不能太大 | Barlow Twins, VICReg, LeJEPA(SIGReg) | 不需要 | 不需要（VICReg/LeJEPA尤其"干净"） |
| **JEPA (I/V-JEPA)** | **③+④的混合**：EMA target+stop-gradient，任务从"同图不同增强"换成"同图不同区域"，损失从像素空间搬到表征空间 | I-JEPA, V-JEPA, LeJEPA | 不需要 | 需要（EMA target encoder） |

历史演化的主线可以概括为一句话：**防坍缩的手段，经历了"用负样本硬推"→"用聚类约束软性引导"→"用架构不对称性侥幸回避"→"用显式统计正则化从理论上根治"这样一条从蛮力到精巧、从经验主义到可证明性的演化路径**，这和《Principles of Diffusion》里"配分函数从蒙特卡洛硬算，到变分近似，到分数匹配绕开归一化"的演化逻辑，在方法论层面是完全同构的。

## 第十一章：理论视角——这些方法到底在优化什么

### 11.1 InfoMax视角

对比学习一支的理论解释是**互信息最大化（InfoMax）**：InfoNCE被解释为互信息的一个变分下界，也就是说最大化InfoNCE等价于（近似地）最大化 $I(s_x; s_y)$——学到的表征应该尽可能多地保留"预测另一视图"所需要的信息。但这个下界很松，用InfoNCE来精确估计互信息数值并不可靠，InfoNCE通常被认为是一个低方差、但高偏差的互信息估计器。

### 11.2 对齐性与均匀性（Alignment & Uniformity）

一个被广泛引用的分析框架把对比学习的效果拆解成两个可以独立衡量、且相互制衡的几何性质：**alignment**（正样本对的表征应该足够接近）和**uniformity**（所有表征应该在超球面上尽量均匀分布，不扎堆）——这其实是把"坍缩"这件事从"是否为常数"这个二元判断，升级成了一个连续的、可以量化优化程度的几何指标，为VICReg、Barlow Twins这类"直接对准统计性质开刀"的方法提供了理论依据。

### 11.3 能量模型（EBM）视角——回到最初的问题

如同上一轮所讨论的，LeCun把整个第③④路线（以及JEPA）纳入了能量模型这个更大的框架：能量函数衡量兼容性，对比方法通过增加负样本的能量来避免坍缩；stop-gradient和EMA技术打破对称性；基于正则化的方法在不使用负样本的情况下维持表征多样性。**这句话本身，就是对本讲义第四到第八章全部内容最精炼的理论总结**——三种防坍缩手段（负样本、结构不对称、显式正则化）本质上都是在解决同一个能量模型视角下的问题：如何让能量函数只在"兼容"的(x,y)对上取低值，而不塌陷成对所有(x,y)都输出同一个能量。

## 第十二章：与DGM的终极对照

| | DGM谱系 | JE-SSL / JEPA谱系 |
|---|---|---|
| 任务目标 | 建模p(x)，能生成新样本 | 学习一个通用编码器f，产出对下游任务有用、紧凑的表征 |

## 结语：JEPA之后，往哪走

LeCun把JEPA看作构建更大的世界模型（Hierarchical JEPA, H-JEPA）的基本构件——用同一套"在抽象表征空间预测被遮盖/未来部分"的原则，层层嵌套，去建模更长时间尺度、更抽象层级的世界结构，这也是Dawid与LeCun合写的教程把能量模型与潜变量模型结合、以H-JEPA作为核心提案组件的方向。至此，你手上应该已经有了一份与《Principles of Diffusion》同构的地图：两条谱系分别从各自的"统一难点"出发，走出了两条看似完全不同、内核逻辑却高度相似的技术演化路径。
